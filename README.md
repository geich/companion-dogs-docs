# Companion Dogs: player documentation

Static site for the player manuals of
[Companion Dogs](https://steamcommunity.com/sharedfiles/filedetails/?id=3740052292),
a companion dog mod for Project Zomboid Build 42.

Written in Brazilian Portuguese and English. The other languages are machine translated
from the Portuguese and are labelled as such, both in the language menu and at the top of
every page.

| Page | Covers |
|---|---|
| `<lang>/features.html` | commands, modes, combat, care, skills and sandbox options |
| `<lang>/breeds.html` | the 9 breeds, moodles, genes and crossbreeds |

## These files are generated

Do not edit the HTML. It is produced by a script from two markdown manuals kept alongside
the mod source. Every correction goes into the markdown and the site is rebuilt over the
top, so an edit made here is lost on the next build.

Found a mistake? Open an issue, or say so on [Discord](https://discord.gg/ndyTBFSuAT).

## Português

Site estático dos manuais do jogador do
[Companion Dogs](https://steamcommunity.com/sharedfiles/filedetails/?id=3740052292),
mod de cães companheiros para Project Zomboid Build 42.

Escrito em português do Brasil e inglês. Os outros idiomas são tradução automática do
português e estão marcados como tal, no menu de idiomas e no topo de cada página.

**Estes arquivos são gerados.** Não edite o HTML: ele sai de dois manuais em markdown que
ficam junto do código do mod. Toda correção entra no markdown e o site é refeito por cima.
