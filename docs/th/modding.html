Companion Dogs: คู่มือการม็อด

วิธีสร้างส่วนเสริมของคุณเอง ไม่ว่าจะเป็นสายพันธุ์ใหม่ หรือสัตว์ชนิดใหม่ทั้งชนิด ในรูปของม็อดแยกบน Workshop ที่เสียบเข้ากับ Companion Dogs

คู่มือเล่มนี้สำหรับคนที่เขียนม็อด ถ้าคุณแค่อยากเล่น อีกสองเล่มต่างหากที่คุณต้องการ ฟีเจอร์ สำหรับสิ่งที่สุนัขทำได้ และ สายพันธุ์ สำหรับตัวสายพันธุ์เอง

คู่มือนี้ถือว่าคุณอ่าน Lua ได้แล้ว และมีโมเดลที่ริกและใส่แอนิเมชันไว้แล้วสำหรับสัตว์ของคุณ ส่วนสายงานศิลป์ ไม่ได้อยู่ในนี้ หัวข้อ 3 จะบอกว่าไฟล์โมเดลต้องผ่านเงื่อนไขอะไรบ้าง และไม่มากไปกว่านั้น

นี่คือสัญญาสาธารณะ ทุกอย่างที่คู่มือนี้เอ่ยชื่อไว้ มีไว้ให้เรียกจากนอกม็อด สิ่งที่ไม่ได้เอ่ยชื่อไว้ที่นี่ เป็นของภายใน และเปลี่ยนได้ในเวอร์ชันไหนก็ได้โดยไม่แจ้งล่วงหน้า

1. ส่วนเสริมคืออะไร

ส่วนเสริมคือม็อด Workshop ธรรมดาที่ประกาศ require=CompanionDogs แล้วเรียกฟังก์ชันหนึ่งตัวตอนโหลด มันเพิ่ม สายพันธุ์เดียว (หรือหลายสายพันธุ์ ถ้าใช้ร่างเดียวกัน) และไม่มีอย่างอื่นอีก ทุกอย่างที่ทำให้สัตว์ ประพฤติตัวเหมือนเพื่อนร่วมทางนั้นอยู่ในม็อดฐานอยู่แล้ว และถูกใช้ร่วมกัน

ฐานเป็นเจ้าของ:

  • เครื่องสถานะของแอนิเมชัน ชุดแอนิเมชัน และโครงกระดูก
  • การเดินตาม การหาเส้นทาง การต่อสู้ การล่า การดูแลปศุสัตว์ การเฝ้าระวัง ความต้องการ และการบำรุงรักษา
  • อินเทอร์เฟซทั้งหมด หน้าต่างสุนัข เมนูวงกลม เมนูคลิกขวา คอกสุนัข หมุดบนแผนที่
  • การทำให้เชื่อง ความผูกพัน การผสมพันธุ์ ลูกสุนัข และลูกผสม
  • ตัวเลือกแซนด์บ็อกซ์ และการซิงก์ในมัลติเพลเยอร์

ส่วนเสริมของคุณเป็นเจ้าของ:

  • ตัวเลขที่ทำให้สัตว์ของคุณต่างจาก Caramelo
  • โมเดลร่างกาย เท็กซ์เจอร์ ภาพเหมือน และไอคอน moodle ถ้ามี
  • ว่าจะเจอมันที่ไหนในโลก
  • ชื่อและคำบรรยาย ในทุกภาษาที่คุณแนบไปด้วย

การแบ่งงานแบบนี้คือหัวใจทั้งหมด แพ็กสายพันธุ์คือ Lua ไม่กี่ร้อยบรรทัด เพราะส่วนที่ยากทำงานอยู่แล้ว

หนึ่งสายพันธุ์ หนึ่งหน้าตา สายพันธุ์คือชุดตัวเลขบวกกับหน้าตาหนึ่งแบบ ถ้าคุณอยากให้สัตว์ตัวเดียวกันสองสี ประพฤติต่างกัน นั่นคือสองสายพันธุ์ ถ้าคุณอยากได้สองสีที่ประพฤติเหมือนกัน สำหรับฐานมันก็ยังเป็นสองสายพันธุ์ (สองชื่อ สองรายการในคอก) และคุณเขียนมันขึ้นจากตารางที่ใช้ร่วมกัน แบบเดียวกับที่ CD: Cats ทำกับขนทั้งห้าแบบ

2. เวอร์ชันของ API

CD.API_VERSION เป็นแค่ตัวเลข มันโตขึ้นด้วยการเพิ่มของเท่านั้น ส่วนเสริมที่เขียนไว้กับเวอร์ชันเก่าจึงยังโหลด บนฐานที่ใหม่กว่าได้โดยไม่ต้องแก้แม้แต่บรรทัดเดียว

API เวอร์ชันของฐาน สิ่งที่เพิ่มเข้ามา
1 0.6.3 CD.registerBreed ทะเบียนการเกิด และ moodle ของสายพันธุ์
2 0.6.6 huntFetchLevel huntDeliverTimeoutMin และฮุก CD.onHuntDelivered
3 0.6.8 sentinelMult barkNoiseMult loyaltyDecayMult และฮุก CD.onUpkeepStress
4 0.6.9 alertModeLocked
5 0.7.0 skills canBreed huntMaxPrey descKey voices CD.registerVoices

ตัวเลขที่ใช้ตรวจคือ API ต่ำสุดที่ส่วนเสริมของคุณต้องใช้จริง และเวอร์ชันของฐานในตารางนั้นคือเวอร์ชันที่คุณ ประกาศบนหน้า Workshop ของคุณ เอามาจากตารางนี้ ไม่ใช่จากว่าฐานเป็นเวอร์ชันอะไรตอนที่คุณกำลังเขียน ฟิลด์ที่มี อยู่เฉพาะในบิลด์สำหรับพัฒนา คือฟิลด์ที่ผู้เล่นของคุณไม่มี

ฟิลด์ที่ขาดหายจะถูกเมินอย่างเงียบ ๆ แบบนั้นไม่เป็นไรถ้าฟิลด์นั้นเป็นตัวเลข บนฐานที่เก่ากว่า สัตว์ของคุณก็แค่ เห่าด้วยความดังปกติ แต่ไม่โอเคถ้าฟิลด์นั้นเป็นการปิดกั้น เพราะแมวที่ไม่ควรสู้เลยจะออกไปสู้อย่างสบายใจ สรุปคือ ตัวเลขลดทอนได้ การปิดกั้นลดทอนไม่ได้ ถ้าสัตว์ของคุณพึ่งพาการปิดกั้น ให้ตรวจกับ API ที่นำมันเข้ามา แล้วปล่อยให้ ส่วนเสริมนิ่งสนิทบนทุกอย่างที่เก่ากว่านั้น

3. สิ่งที่ต้องมีก่อนเริ่ม

โมเดลที่สกินแล้ว สัตว์ของคุณต้องมี .glb ของตัวเองใต้ media/models_X/Skinned/ และไฟล์นั้นต้องมี ชุดคลิป Rac_* ครบทั้ง 21 คลิป คลิปไม่ได้สืบทอดข้ามไฟล์โมเดล โมเดลที่มีสิบห้าคลิปจะให้สัตว์ที่ค้างทันทีที่ ถูกสั่งให้ทำหนึ่งในหกคลิปที่เหลือ นอกจากนี้โมเดลต้องมีกระดูกไม่เกิน 60 ชิ้น และมีโหนดบนสุดเป็นเอกลักษณ์ ไม่อย่างนั้นเอนจินจะโยนข้อผิดพลาดทุกเฟรม และสัตว์จะถูกวาดออกมาเป็นรอยเปื้อนสีดำ

ถ้ายังไม่มีโมเดล คุณก็ยังเขียนและทดสอบทุกอย่างที่เหลือได้ โดยชี้ CD.applyDogModel ไปที่ร่างใดร่างหนึ่งของฐาน สัตว์จะหน้าตาเหมือน Caramelo แต่ทุกระบบในคู่มือนี้ทำงาน

เท็กซ์เจอร์ สำหรับร่างกาย และ ภาพเหมือน สำหรับหน้าต่างคอกสุนัข

ตัดสินใจข้อหนึ่งก่อนเขียนโค้ด สัตว์ของคุณเป็น สายพันธุ์ หรือ ชนิด สายพันธุ์คือสุนัขที่มีตัวเลขต่างออกไป ชนิดคือสัตว์ที่ไม่มีงานบางอย่างเลยตั้งแต่ต้น ความต่างนี้ไม่ใช่เรื่องเปลือกนอก มันเปลี่ยนว่าคุณต้องเขียนฟิลด์ไหน และหัวข้อ 7 ว่าด้วยเรื่องนี้

5. ด่านตรวจเวอร์ชัน

วางสิ่งนี้ไว้บนสุดของทุกไฟล์ Lua ในส่วนเสริมของคุณ ด้วยตัวเลขที่ส่วนเสริมของคุณต้องใช้จริง

local CD = CompanionDogs
if not (CD and CD.registerBreed and (CD.API_VERSION or 0) >= 3) then return end

ถ้าไม่มีฐาน หรือฐานเก่าเกินไป ไฟล์จะคืนค่าตั้งแต่บรรทัดที่สอง ส่วนเสริมจะไม่ทำอะไรเลย ไม่มีสายพันธุ์ ไม่มีการเกิด ไม่มี moodle ไม่มีแม้แต่บรรทัดเดียวในล็อก ความเงียบนี้ตั้งใจไว้แล้ว ส่วนเสริมที่โหลดครึ่ง ๆ แย่กว่าส่วนเสริมที่ไม่ โหลดเลย เพราะผู้เล่นจะได้สัตว์ที่มีชื่อแต่ไม่มีพฤติกรรม

ด่านตรวจเป็นรายไฟล์ และแต่ละไฟล์ตรวจสิ่งที่ตัวเองใช้ PugDefinitions.lua ต้องใช้ตัวช่วยของโมเดล มันจึงตรวจ พวกนั้นแทน

if not (CompanionDogs and CompanionDogs.applyDogModel and CompanionDogs.DOG_SOUNDS) then return end

อย่าสร้างตัวแปรกลางเอง CompanionDogs = CompanionDogs or {} ในส่วนเสริมจะเปลี่ยนฐานที่ไม่มีอยู่ให้กลายเป็น ตารางที่สร้างค้างครึ่งทาง แล้วด่านตรวจทุกอันที่อยู่ถัดไปก็จะผ่านทั้งที่ไม่ควรผ่าน อ่านตัวแปรกลางอย่างเดียว อย่าเขียน ลงไปเด็ดขาด

6. การลงทะเบียนสายพันธุ์

เรียกครั้งเดียว ในไฟล์ shared

CD.registerBreed({
    key = "pug",
    engineBreed = "pug",
    typePrefix = "pug",
    nameKey = "IGUI_PD_Breed_pug",
    litter = { 1, 2 },
    xpMult = { scent = 1.5, combat = 1, obedience = 2.0, hunt = 1.2, herding = 1.0 },
    combatPower = 0.15,
    lethalityCurve = { min = 0.40, max = 1.3 },
    canKill = false,
    canKnockdown = false,
    combatStressMult = 0.9,
    panicThreshold = 0.70,
    bagMult = 0.6,
    sentinelMult = 1.35,
    barkNoiseMult = 1.5,
    alertModeLocked = true,
    loyaltyDecayMult = 0,
    geneRange = {
        strength       = { 0.00, 0.10 },
        aggressiveness = { 0.05, 0.20 },
        resistance     = { 0.00, 0.15 },
        stress         = { 0.55, 0.85 },
    },
    spawns = {
        { id = "pughouse", class = "house", suffix = "|pg", breed = "pug",
          chance = function() return CD.strayChancePerHouse() / CD.PUG_HOUSE_RARITY end },
    },
})

การเรียกนั้นจะใส่สายพันธุ์เข้าไป ลงทะเบียนชนิดสัตว์ทั้งสามของมัน สร้างลำดับการผสมพันธุ์ใหม่เพื่อให้สัตว์ของคุณ เข้าร่วมการผสมข้ามสายพันธุ์ และลงทะเบียนขั้นตอนการเกิด

นิยามที่ผิดจะคืน nil แทนที่จะโยนข้อผิดพลาด ความผิดพลาดจึงไม่เคยลากการโหลดล้มไปด้วย ทุกการปฏิเสธจะพิมพ์ บรรทัดที่ระบุชื่อไว้ ดังนั้น อ่านล็อก ในครั้งแรกที่คุณลงทะเบียนสายพันธุ์

ฟิลด์ที่จำเป็น

ฟิลด์ คืออะไร
key ตัวระบุสายพันธุ์ของคุณ ไม่ซ้ำกับม็อดใดในโลก และไม่เปลี่ยนอีกเลยหลังปล่อย
typePrefix คำนำหน้าของชนิดสัตว์ทั้งสาม <คำนำหน้า>pup <คำนำหน้า>female <คำนำหน้า>male เป็นตัวเลือก เมชของร่างกาย
nameKey คีย์การแปลของชื่อที่แสดง
xpMult ความเร็วในการเรียนรู้ต่อทักษะ scent combat obedience hunt herding โดย 1.0 คือปกติ
combatPower มันตีแรงแค่ไหน Caramelo อยู่ที่ 0.20 สายพันธุ์นักสู้เกิน 1.0
lethalityCurve { min, max } ความเสียหายโตอย่างไรจากการต่อสู้ระดับ 0 ถึง 10
geneRange ช่วงตอนเกิดของยีนทั้งสี่ strength aggressiveness resistance stress แต่ละตัวคือ { ต่ำสุด, สูงสุด } ภายในช่วง 0 ถึง 1

ฟิลด์ทางเลือก

ฟิลด์ ค่าเริ่มต้น ทำอะไร
engineBreed ค่าเดียวกับ key ชื่อสายพันธุ์ที่ส่งให้เอนจิน ซึ่งเป็นตัวเลือก เท็กซ์เจอร์ ไม่ซ้ำในแต่ละสายพันธุ์
descKey IGUI_PD_BreedDesc_<key> คีย์ของคำบรรยาย ชี้หลายสายพันธุ์มาที่คีย์เดียวได้ เมื่อพวกมันใช้คำบรรยายร่วมกัน
litter ค่าของฐาน { ต่ำสุด, สูงสุด } ลูกต่อครอก
canKill true false แปลว่ามันบั่นทอนซอมบี้ได้ แต่ไม่เคยลงดาบสังหาร
canKnockdown false true ให้มันผลักซอมบี้ล้มได้
combatStressMult 1 การต่อสู้หนึ่งครั้งทำให้มันเครียดมากแค่ไหน
panicThreshold ค่าของฐาน ระดับความเครียดที่มันเลิกสู้ panicImmune = true แปลว่าไม่เลิกเลย
bagMult 1 ตัวคูณความจุของถุงข้าง
puppySize 0.6 ขนาดที่มองเห็นแบบสัมบูรณ์ของลูกสัตว์ สายพันธุ์ตัวเล็กต้องตั้งค่านี้ ไม่อย่างนั้นลูกจะเกิดมาตัวเท่าตัวเต็มวัย
sentinelMult 1 คูณรัศมีการเฝ้าระวังขั้นสุดท้าย
barkNoiseMult 1 ปรับรัศมีและความดังของเสียงเห่าเตือน มันปรับขนาดของเสียง ไม่ได้สร้างเสียง ถ้าปิดตัวเลือกเสียงในแซนด์บ็อกซ์ ไม่มีสายพันธุ์ไหนดึงซอมบี้ด้วยการเห่า
loyaltyDecayMult 1 คูณอัตราการลดความภักดีต่อวัน 0 แปลว่าความผูกพันไม่จางเลย
alertModeLocked false สัตว์ติดอยู่ในโหมดเตือนภัยเต็มที่ เจ้าของสั่งให้เงียบหรือให้ไร้เสียงไม่ได้จากที่ไหนเลย ใช้เมื่อเสียงเตือนดัง คือ ตัวการออกแบบ
huntFetchLevel 6 ระดับการล่าที่มันจะเริ่มคาบเหยื่อกลับมาให้เจ้าของ
huntDeliverTimeoutMin 5 นาทีในเกมที่มันจะพยายามส่งของต่อไปก่อนยอมแพ้
idleAnimMs ค่าของฐาน ความยาวของช่วงแอนิเมชันตอนอยู่เฉย เป็นมิลลิวินาที ตั้งค่าเมื่อคลิปของคุณสั้นกว่าของสุนัข ไม่อย่างนั้นลูปจะเริ่มใหม่แล้วถูกตัดกลางท่า
restAnim true false ทำให้สัตว์ยืนอยู่ตอนสั่งให้อยู่กับที่และตอนเฝ้า แทนที่จะหมอบลง
voices เสียงสุนัข { bark, growl, idle, wildbark, pet } ดูข้างล่าง
skills canBreed huntMaxPrey เปิดทั้งหมด การปิดกั้นเชิงโครงสร้าง หัวข้อ 7

ตัวเลขและแฟล็กที่คุณเพิ่มลงในนิยาม อ่านกลับได้ด้วย CD.breedNumber(animal, ฟิลด์) และ CD.breedFlag(animal, ฟิลด์) ใช้สองตัวนี้ดีกว่าไปอ่าน CD.getBreedDef(animal).ฟิลด์ เอง เพราะมันจัดการฟิลด์ที่ ขาดหายให้คุณ และยังทำงานต่อไปเมื่อฐานขยับ

ชนิดที่ต่างกันไม่ได้พูดภาษาเดียวกัน ถ้าไม่มี voices แมวของคุณจะเห่า

CD.registerVoices({

    CDCatPet = "fx", CDCatMeowAmbient = "ambient",
})
voices = { bark = "CDCatMeow", growl = "CDCatGrowl", idle = "CDCatPurr",
           wildbark = "CDCatMeowAmbient", pet = "CDCatPet" },

CD.registerVoices ไม่ใช่ของประดับที่จะใส่หรือไม่ใส่ก็ได้ ถ้าไม่มีมัน เสียงยังดังอยู่ แต่จะเมินแถบเลื่อนหมวดหมู่ ของผู้เล่นและระดับเสียงเอฟเฟกต์ของตัวเกม เป็นความเสียหายที่ไม่มีใครแจ้ง เพราะไม่มีอะไรดูพังเลย คีย์ที่คุณไม่ได้ ใส่ไว้ใน voices จะตกกลับไปใช้เสียงสุนัข ซึ่งเป็นสิ่งที่คุณต้องการในสายพันธุ์สุนัข และไม่ใช่สิ่งที่คุณต้องการเลย ในชนิดอื่น

7. การปิดทั้งระบบ

ทักษะทั้งห้าคือระบบทั้งห้า หนึ่งต่อหนึ่ง

ทักษะ มันคือระบบอะไร
scent การเฝ้าระวัง สังเกตเห็นซอมบี้และเตือนคุณ
combat การต่อสู้ โหมดเฝ้า และการป้องกันตัว
obedience ต้นไม้ท่ากล
hunt การล่า รวมถึงโบนัสการเก็บหาที่มันให้เจ้าของ
herding การดูแลปศุสัตว์ในคอก

ชนิดหนึ่งไม่ใช่สุนัขที่ตัวเลขแย่กว่า มันคือสัตว์ที่ไม่มีงานบางอย่างเลย ดังนั้นมันจึงประกาศสิ่งที่มันไม่มี

skills = { combat = false, herding = false },
canBreed = false,
huntMaxPrey = "tiny",

ไม่ระบุหรือ true แปลว่าสัตว์มีทักษะนั้น คุณจึงเขียนเฉพาะทักษะที่กำลังเอาออก

การปิดทักษะหนึ่งทำ สามอย่างพร้อมกัน ระบบจะไม่ทำงานเลย ทักษะจะไม่ได้รับค่าประสบการณ์เลย และแถบกับคำสั่ง ของมันจะหายไปจากอินเทอร์เฟซ ทั้งสามอย่างพร้อมกัน ถ้าซ่อนแค่แถบ ทักษะก็จะโตอยู่ในที่ที่ไม่มีใครเห็น ถ้าล็อกแค่ ระบบ แถบก็จะค้างอยู่ที่ศูนย์ตลอดไป

canBreed = false อยู่นอกตาราง เพราะการผสมพันธุ์ไม่มีแถบและไม่มีค่าประสบการณ์ และมันเด็ดขาด สัตว์ตัวนั้นจะ ไม่ตั้งท้อง ไม่ถูกเลือกเป็นคู่ และไม่ผสมแม้กระทั่งกับสายพันธุ์เดียวกัน

huntMaxPrey คือ เพดานภายในการล่าที่มีอยู่ ซึ่งเป็นคนละเรื่องกับ hunt = false มันรับ "tiny" (หนู หนูใหญ่ กระรอก) "small" (กระต่าย แรคคูน) หรือ "large" (กวาง เป็นค่าเริ่มต้น ไม่มีเพดาน) เหยื่อที่เกินเพดานจะมองไม่เห็น สำหรับสัตว์ของคุณ มันไม่ไล่ และไม่ชี้ให้ด้วยซ้ำ ค่าที่อยู่นอกบันไดนี้จะตกไปเป็น "large" และพิมพ์บรรทัดที่ระบุชื่อ ลงในล็อก

สัตว์ที่ถูกปิดกั้นจะไม่ได้ปุ่มที่กดไม่ได้ ตัวเลือกนั้นจะหายไปจากเมนูวงกลม เมนูคลิกขวา และหน้าต่าง ส่วนการ ปฏิเสธที่ฝั่งเซิร์ฟเวอร์ก็เงียบ วงรัศมีที่บอกว่ามันเมินคำสั่งจะเป็นการโกหก เพราะนี่ไม่ใช่การไม่เชื่อฟัง ให้อธิบายการ ออกแบบไว้ในคำบรรยายสายพันธุ์ของคุณแทน นั่นคือเหตุผลที่ฟิลด์เหล่านี้ไม่พาคีย์การแปลใหม่มาด้วยเลย

8. นิยามของสัตว์

เอนจินผูกเมชไว้กับ ชนิดของสัตว์ ไม่ใช่กับสายพันธุ์ สายพันธุ์ของคุณจึงต้องมีชนิดของตัวเองสามชนิด นี่คือส่วนที่ เป็นกลไกของส่วนเสริม และทางที่สั้นที่สุดคือคัดลอกไฟล์ของส่วนเสริมที่มีอยู่แล้วมาเปลี่ยนชื่อ

สามชิ้นนี้ อยู่ในไฟล์ shared ใต้ Definitions/animal/

AnimalDefinitions.stages["pug"] = {}
AnimalDefinitions.stages["pug"].stages = {}
AnimalDefinitions.stages["pug"].stages["pugpup"] = {}
AnimalDefinitions.stages["pug"].stages["pugpup"].ageToGrow = 3 * 30

pugfemale.female = true

ตัวช่วยที่ฐานมีให้

ตัวช่วย มันเติมอะไรให้
CD.applyDogModel(t, "Body_Model") โมเดลร่างกาย โครงกระดูก เท็กซ์เจอร์ตอนชำแหละ และชุดแอนิเมชัน
CD.applyDogBehaviour(t) ทุกแฟล็กพฤติกรรมของเอนจินที่เพื่อนร่วมทางต้องมี
CD.applyDogAvatar(t) กล้องภาพเหมือนสำหรับหน้าต่างสัตว์
CD.DOG_SOUNDS ตารางเสียงฝีเท้าและเสียงประกอบที่ใช้ร่วมกัน
CD.STRAY_NO_BLEEDOUT ค่าที่กันไม่ให้สัตว์จรจัดที่ตกใจเลือดไหลจนตาย
CD.defineDogParts(typePrefix, engineBreed) ชิ้นส่วนจากการชำแหละของทั้งสามช่วงวัย

กฎสี่ข้อที่ไม่ชัดในตัวเอง

ชุดแอนิเมชันต้องเป็น "raccoon" ต่อไป CD.applyDogModel ตั้งค่านี้ให้ ชุดแอนิเมชันที่แยกสายออกไปจะไม่โหลด เครื่องสถานะของมัน และสัตว์ที่ไม่มีเครื่องสถานะคือสัตว์ที่ค้างอยู่กับที่

ใช้จีโนมเดิม AnimalDefinitions.genome["dog"].genes อย่าเขียนของตัวเอง

อย่าประกาศ mate เด็ดขาด ถ้ามีมัน เอนจินจะรันการผสมพันธุ์ดั้งเดิมของตัวเองภายในโซนสัตว์ใด ๆ ซึ่งเมินทั้งการ ปิดกั้นการผสมพันธุ์ของม็อดและตัวเลือกแซนด์บ็อกซ์ แล้วให้ลูกที่ไม่มีความผูกพัน ฐานจะล้างฟิลด์นี้ตอนบูตเป็นตาข่าย นิรภัย แต่อย่าไปพึ่งสิ่งนั้น

ชิ้นส่วนเป็นสิ่งบังคับ สามบรรทัดในไฟล์ของมันเอง

if CompanionDogs and CompanionDogs.defineDogParts then
    CompanionDogs.defineDogParts("pug", "pug")
end

ถ้าไม่มี การชำแหละสัตว์ของคุณจะทำให้โค้ดดั้งเดิมของเกมพัง เพราะมันไปค้นนิยามชิ้นส่วนด้วยชนิดกับสายพันธุ์แล้ว เหยียบ nil

สัตว์ตัวเล็กต้องปรับกล้องภาพเหมือน ค่าซูมของภาพเหมือนใน CD.applyDogAvatar ถูกปรับเทียบกับสุนัข และซูม ของอวาตาร์คือกำลังขยาย ยิ่งสัตว์เล็ก ตัวเลขยิ่งใหญ่ ให้เอาซูมหารด้วยอัตราส่วนขนาดเทียบกับสุนัข แล้วเอาอัตราส่วน นั้นคูณกับค่าเลื่อน ไม่อย่างนั้นสัตว์ของคุณจะตัวจิ๋วอยู่ที่ก้นภาพเหมือนของตัวเอง

9. สคริปต์ของโมเดล

ไฟล์หนึ่งไฟล์ใต้ media/scripts/ ซึ่งเป็นสิ่งที่บอกเกมว่าโมเดลของคุณมีอยู่จริง

module Base
{
    model Pug_Body
    {
        mesh = Skinned/Pug_Body,
        shader = animalEffect,
        static = false,
        animationsMesh = PugAnim,
        attachment head
        {
            offset = -0.0061 0.1671 0.0507,
            rotate = -179.0 -5.0 95.0,
            bone = Dummy01,
        }
    }

    animationsMesh PugAnim
    {
        meshFile = Skinned/Pug_Body,
        keepMeshAnimations = true,
    }
}

keepMeshAnimations = true คือสิ่งที่ทำให้คลิปในไฟล์โมเดลของคุณยังใช้งานได้ ถ้าไม่มีบรรทัดนี้ โมเดลจะโหลดขึ้นมา แล้วไม่ขยับเลย

จุดต่อ head คือที่ที่หมวกและของทำนองนั้นวางอยู่ ถ้าคุณอยากให้ถุงข้างพอดีกับสัตว์ของคุณ ให้เพิ่ม saddlebags_l saddlebags_r และ saddlebags_c ด้วยวิธีเดียวกัน ที่กระดูกสันหลัง ตัวเลขเหล่านี้หาได้ด้วยการ มองสัตว์ในเกมแล้วขยับทีละนิด ไม่ใช่ด้วยการวัดโมเดล ถุงที่อยู่ตรงกลางตามคณิตศาสตร์ยังดูเบี้ยวอยู่ดีบนร่างที่มีขน

10. สัตว์ตัวนี้โผล่ที่ไหน

สัตว์จรจัดถูกสุ่มทีละอาคาร ทีละชังก์ ในครั้งแรกที่ชังก์นั้นถูกโหลด คุณอธิบายการสุ่มของคุณเป็นรายการขั้นตอน ไม่ในนิยามสายพันธุ์ในชื่อ spawns ก็ด้วย CD.registerStraySpawns(รายการ)

spawns = {
    { id = "pughouse", class = "house", suffix = "|pg", breed = "pug", indoor = 85,
      chance = function() return CD.strayChancePerHouse() / CD.PUG_HOUSE_RARITY end },
    { id = "pugpetvet", class = "petvet", suffix = "|pv", breed = "pug",
      chance = function() return CD.PUG_PETVET_CHANCE * CD.dogSpawnMultiplier() end },
},
คีย์ คืออะไร
id ชื่อของขั้นตอน สำหรับล็อกของคุณเอง
class คลาสอาคารที่มันสุ่มบนนั้น
chance ฟังก์ชัน ที่คืนค่าเป็นเปอร์เซ็นต์ เป็นฟังก์ชันไม่ใช่ตัวเลข เพื่อให้มันตามตัวคูณแซนด์บ็อกซ์ได้แบบสด
suffix คีย์ของที่เก็บถาวร ไม่ซ้ำในระบบนิเวศทั้งหมด และไม่เปลี่ยนเลย
breed คีย์สายพันธุ์ที่จะให้เกิด
gate ฟังก์ชันทางเลือกที่คืนค่าจริงเท็จ ตรวจก่อนการสุ่ม ฮัสกี้ใช้ CD.isWinter
indoor เปอร์เซ็นต์โอกาสที่จะเกิดในอาคารแทนที่จะเกิดบนถนน ค่าเริ่มต้น 35

คูณโอกาสของคุณด้วย CD.dogSpawnMultiplier() หรือหาร CD.strayChancePerHouse() ด้วยความหายากของคุณเอง ทางไหนก็ตาม การตั้งค่าแซนด์บ็อกซ์ของผู้เล่นยังทำงานอยู่ ซึ่งจะไม่เป็นเช่นนั้นถ้าคุณเขียนเป็นตัวเลขเปล่า

indoor เป็นความชอบ ไม่ใช่คำสัญญา อาคารที่ไม่มีช่องภายในว่างในชังก์นั้นจะตกกลับไปใช้ช่องข้างนอก

CD.registerBuildingClass("mineshaft", function(def) return def:isX() end,

ฟังก์ชันจับคู่จะได้รับนิยามของอาคาร และทำงานอยู่ในการเรียกแบบมีการป้องกัน ความผิดพลาดในนั้นจึงลากการโหลด ชังก์ล้มไม่ได้ skipUrbanGate ให้คลาสสุ่มในชังก์ที่ไม่ใช่เขตเมืองได้ ซึ่งเป็นสิ่งที่ฟาร์มหรือกระท่อมกลางป่าต้องการ ปล่อย exclusive ไว้เฉย ๆ คลาสของฐานกันเองแบบพิเศษอยู่แล้ว ส่วนคลาสของส่วนเสริมออกแบบมาให้เป็นแบบ บวกเพิ่ม คือจับคู่ทับลงไปบนคลาสเหล่านั้น

คำต่อท้ายที่มีคนใช้แล้ว

คำต่อท้ายเป็นส่วนหนึ่งของคีย์ที่ใช้บันทึกว่า "อาคารนี้สุ่มไปแล้ว" ม็อดสองตัวที่ใช้คำต่อท้ายเดียวกันจะทำลายผลการ สุ่มของกันและกัน

คำต่อท้ายทุกตัวขึ้นต้นด้วยขีดตั้ง ตัวเหล่านี้มีคนใช้แล้ว

  • ร็อตไวเลอร์: rw r
  • โดเบอร์แมน: db dm
  • ลาบราดอร์: lb lk
  • ปั๊ก: pg pv
  • แมว: ct cv ctw cvw cto cvo ctc cvc ctx cvx

เลือกตัวที่ไม่มีใครใช้ แล้วจากนั้นอย่าไปแตะมันอีกเลย

11. moodle ของสายพันธุ์

moodle เป็นไฟล์ฝั่ง client คุณเพิ่มตารางเข้าไปใน CD.DogMoodles แล้วฐานจะวาด ติดตาม และเก็บกวาดให้

CD.DogMoodles[#CD.DogMoodles + 1] = {
    id = "shadow",
    breed = "pug",
    nameKey = "IGUI_PD_Moodle_Shadow",
    descKey = "IGUI_PD_Moodle_Shadow_desc",
    icon = "CD_Moodle_Shadow",
    fg = "CD_MoodShadowFG",
    tintR = 0.92, tintG = 0.52, tintB = 0.68,
    condition = function(player, dog)
        if not dog or dog:isDead() then return 0 end
        if CD.getBreed(dog) ~= "pug" then return 0 end
        if CD.isDisloyal(dog) then return 0 end
        return 1
    end,
    apply = function(player, dog, elapsedMin)
        CD.relieveMood(player, CD.moodleReliefPerMin() * elapsedMin)
    end,
}

condition คืนค่าระดับ หรือ 0 เมื่อ "ไม่แสดง" ส่วน apply ถูกเรียกพร้อมจำนวนนาทีในเกมนับจากการเรียกครั้งก่อน ให้คูณผลของคุณด้วย elapsedMin แทนที่จะสมมติว่าติกคงที่

แนบไอคอนมาด้วย หกขนาด ตั้งแต่ 32 ถึง 128 พิกเซล อินเทอร์เฟซเลือกขนาดตามการปรับสเกลของผู้เล่น ขนาดที่ ขาดไปจะกลายเป็นสี่เหลี่ยมว่าง

moodle ที่ทำเองถูกวาดเป็นชั้นทับ ไม่ได้ผ่านระบบ moodle ของตัวเกม ซึ่งไม่รับรายการใหม่จากม็อด เรื่องนี้จัดการ ให้คุณแล้ว แต่นั่นคือเหตุผลที่ moodle ไปอยู่ในแถบของม็อดเอง ไม่ใช่ปะปนกับของดั้งเดิม

12. ฮุก

รายการฟังก์ชันสองชุดที่ฐานเรียกบน เซิร์ฟเวอร์ เพิ่มเข้าไปจากไฟล์ shared ตัวจัดการแต่ละตัวทำงานในการเรียก แบบมีการป้องกันของตัวเอง ส่วนเสริมที่พังจึงลากฐานล้มไปด้วยไม่ได้

CD.onHuntDelivered ตั้งแต่ API 2 ถูกเรียกทันทีหลังจากสัตว์วางเหยื่อลงที่เท้าของเจ้าของ

CD.onHuntDelivered[#CD.onHuntDelivered + 1] = function(animal, owner)
    -- server side, so this is the right place to write mod data
end

CD.onUpkeepStress ตั้งแต่ API 3 ถูกเรียกทุกรอบการบำรุงรักษา หลังจากฐานบวกความเครียดจากความต้องการที่ ไม่ได้รับการเติมเต็มแล้ว และก่อนที่จะเขียนลงไป คืนค่าเป็นตัวเลข แล้วมันจะถูกบวกเข้ากับยอดรวม

CD.onUpkeepStress[#CD.onUpkeepStress + 1] = function(animal, needsStress)
    return CD.pugHeatRatio(animal) * CD.PUG_HEAT_STRESS_MAX
end

นี่คือทาง เดียว ที่ส่วนเสริมจะมีอิทธิพลต่อความเครียดต่อเนื่องของสัตว์ได้ การบำรุงรักษาคำนวณใหม่และเขียนทับค่า ทุกรอบ อะไรก็ตามที่คุณเขียนจากข้างนอกจึงหายไปในติกถัดไป มันคือเครื่องมือที่ถูกต้องสำหรับสภาวะที่มาจาก สิ่งแวดล้อม ความร้อน ความหนาว ฝน

กฎของมัลติเพลเยอร์ บรรทัดเดียว ไคลเอนต์ไม่เขียนข้อมูลม็อดเด็ดขาด การเขียนฝั่งไคลเอนต์จะทับสำเนาของ เซิร์ฟเวอร์ในการซิงก์ครั้งถัดไป และอาการจะโผล่อีกหลายนาทีให้หลัง ในที่ที่ไม่เกี่ยวกันเลย ทำงานในไฟล์ฝั่ง เซิร์ฟเวอร์ หรือในฮุกพวกนี้ ซึ่งทำงานอยู่ตรงนั้นอยู่แล้ว

14. สิ่งที่เซฟจดจำไว้

ตัวระบุของคุณสามตัวถูกเขียนลงในไฟล์เซฟและถูกอ่านกลับตลอดไป

  • key ตัวระบุสายพันธุ์ที่เก็บอยู่บนสัตว์ทุกตัวของคุณ
  • typePrefix ซึ่งประกอบขึ้นเป็นชนิดสัตว์ที่เอนจินเก็บไว้
  • suffix คีย์ของที่เก็บ "สุ่มไปแล้ว" หนึ่งตัวต่อหนึ่งขั้นตอนการเกิด

ทั้งสามตัวเปลี่ยนชื่อไม่ได้เลยหลังปล่อยออกไปแล้ว การเปลี่ยนชื่อ key ทำให้สัตว์ที่ยังมีชีวิตทุกตัวของสายพันธุ์ นั้นกลายเป็นเด็กกำพร้า การเปลี่ยนชื่อ suffix ทำให้ทุกอาคารในทุกเซฟที่มีอยู่ถูกสุ่มใหม่ และโลกที่เล่นมาหลายเดือน ก็จะเต็มไปด้วยสัตว์ของคุณในทันที

ครั้งเดียวที่การสุ่มใหม่นั้นมีประโยชน์คือเมื่อมันคือเป้าหมายพอดี CD: Cats ตั้งใจให้ขนใหม่ทั้งสี่แบบมีคำต่อท้ายใหม่ ก็เพื่อให้พวกมันเริ่มโผล่ในโลกที่เดินอยู่แล้ว ขณะที่แมวดำตัวเดิมยังคงคำต่อท้ายเดิมไว้และไม่ถูกสุ่มใหม่

การถอดส่วนเสริมออกจากเซฟที่มีสัตว์ของสายพันธุ์นั้นยังมีชีวิตอยู่ เท่ากับทำมันหาย เอนจินจะทิ้งสัตว์ที่มันไม่รู้จัก ชนิดอีกต่อไป ฐานไม่พัง ความผูกพันและคอกลดทอนลงอย่างเรียบร้อย แต่สัตว์ตัวนั้นหายไปแล้ว เขียนเรื่องนี้ไว้บน หน้า Workshop ของคุณ เหมือนที่ส่วนเสริมที่เผยแพร่แล้วทุกตัวทำ

สายพันธุ์ที่ไม่รู้จักจะลดทอนแทนที่จะล้มเหลว ถ้าไม่มีส่วนเสริมของคุณ ฐานจะตกกลับไปใช้สายพันธุ์เริ่มต้นสำหรับ ทุกเรื่องที่ถูกถาม เซฟที่เปิดโดยไม่มีม็อดของคุณจึงยังอ่านได้

15. ก่อนเผยแพร่

  • ด่านตรวจอยู่ใน ทุก ไฟล์ Lua และระบุ API ที่คุณใช้จริง
  • ขั้นต่ำของเวอร์ชันฐานเขียนไว้เป็นคำพูดในคำบรรยายของคุณ versionMin บอกแทนไม่ได้
  • คุณอ่านล็อกในการโหลดครั้งแรกแล้ว ไม่อย่างนั้น CD.registerBreed จะปฏิเสธเงียบ ๆ และทุกการปฏิเสธจะพิมพ์ บรรทัดที่ระบุชื่อไว้
  • CD.defineDogParts ถูกเรียกอยู่ ลองชำแหละสัตว์ของคุณสักตัวแล้วดูว่าไม่พัง
  • key typePrefix และคำต่อท้ายการเกิดของคุณไม่ซ้ำใคร และคุณพอใจกับมันไปตลอด
  • สายพันธุ์ตัวเล็กตั้งค่า puppySize และคุณได้เห็นลูกสัตว์เพื่อยืนยันแล้ว
  • ถ้าเป็นชนิดอื่น CD.registerVoices ถูกเรียกและ voices ถูกเติมไว้ ไม่อย่างนั้นมันจะเห่า
  • ไอคอน moodle มีครบทั้งหกขนาด
  • ทุกโฟลเดอร์ภาษาที่คุณแนบไปมีคีย์ครบทุกตัว คีย์ที่ขาดจะแสดงคีย์ดิบบนหน้าจอ
  • คุณทดสอบในมัลติเพลเยอร์แล้ว ไม่ใช่แค่ผู้เล่นคนเดียว ตำแหน่ง ความเป็นเจ้าของ และข้อมูลม็อดทำงานต่างกัน ในนั้น
  • หน้า Workshop ของคุณเตือนไม่ให้ถอดส่วนเสริมออกจากเซฟที่มีสัตว์ยังมีชีวิต

16. ข้อผิดพลาดที่พบบ่อย

"สัตว์ของผมไม่โผล่มาสักที" เกือบทุกครั้งคือด่านตรวจ ส่วนเสริมของคุณต้องใช้ API ที่ฐานที่ติดตั้งอยู่ไม่มี มันจึง นิ่งสนิทตามที่ตั้งใจไว้ เทียบเลข API ของคุณกับตารางในหัวข้อ 2

"มันโผล่มา แต่ค้าง" ชุดแอนิเมชันไม่ใช่ "raccoon" หรือโมเดลของคุณขาดคลิป ทั้งสองอย่างออกมาเป็นสัตว์ที่ยืนนิ่ง ตลอดกาล

"มันถูกวาดเป็นรอยเปื้อนสีดำ และล็อกท่วม" โมเดลมีกระดูกเกิน 60 ชิ้น

"ชำแหละแล้วเกมพัง" ไม่ได้เรียก CD.defineDogParts

"ลูกเกิดมาตัวเท่าตัวเต็มวัย" สายพันธุ์ตัวเล็กที่ไม่ได้ตั้ง puppySize ค่านี้เป็นค่าสัมบูรณ์และถูกใส่ซ้ำทุกรอบการ กวาด ช่วงขนาดของชนิดจึงช่วยคุณไม่ได้

"สองสายพันธุ์ของผมกลายเป็นกันและกันอยู่เรื่อย" พวกมันใช้ engineBreed ร่วมกัน คำนำหน้าเป็นตัวเลือกเมช และแบ่งกันใช้ในตระกูลเดียวกันได้ ส่วน engineBreed เป็นตัวเลือกเท็กซ์เจอร์และเป็นตัวตัดสินภายในตระกูลนั้น มันจึงต้องไม่ซ้ำกันในแต่ละสายพันธุ์

"เสียงดังอยู่ แต่เมินแถบเลื่อนระดับเสียง" ไม่ได้เรียก CD.registerVoices สำหรับเสียงนั้น

"เล่นคนเดียวได้ แต่พอขึ้นเซิร์ฟเวอร์แล้วเพี้ยน" มีบางอย่างเขียนข้อมูลม็อดที่ฝั่งไคลเอนต์ ย้ายไปฝั่งเซิร์ฟเวอร์

"มันสู้กับซอมบี้ทั้งที่ผมปิดการต่อสู้แล้ว" ฐานที่มันทำงานอยู่เก่ากว่า API 5 ซึ่งตอนนั้นยังไม่มีฟิลด์นี้และมันถูกเมิน อย่างเงียบ ๆ นี่คือกรณีที่ด่านตรวจต้องปิดกั้น ไม่ใช่ลดทอน

มีอะไรในคู่มือนี้ผิด หรือขาดหายไปไหม บอกได้ที่ Discord
