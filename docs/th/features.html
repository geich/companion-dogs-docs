การติดตั้ง: เริ่มที่นี่
ติดตั้ง ถ้ามีเซฟอยู่แล้ว เซิร์ฟเวอร์เฉพาะ โฮสต์ co-op
1. ใน 5 นาที: จากหมาจรจัดสู่คู่หู
2. หาและรับเลี้ยงสุนัข
แต่ละสายพันธุ์โผล่ที่ไหน วิธีรับเลี้ยง ต้องใช้อาหารเท่าไร อาหารที่เป็นอันตราย เกิดอะไรขึ้นในวินาทีที่มันเป็นของคุณ ขีดจำกัดจำนวนสุนัข
3. วิธีสั่งงาน: สี่ทาง
ก) เมนูคลิกขวา (คลิกขวาที่สุนัข) ข) เมนูวงกลม (กด Q ค้าง) ค) ปุ่มลัด ง) ปุ่มในหน้าต่างสุนัข
4. สามโหมด: ตาม นิ่ง และป้องกัน
โหมดตาม โหมดนิ่ง โหมดป้องกัน สองคำสั่งเรียกกลับ
5. เฝ้าระวัง: สุนัขในฐานะสัญญาณเตือน
6. การต่อสู้
เมื่อไรที่มันสู้เอง มันไม่กัดทะลุกำแพง มันทำความเสียหายแค่ไหน ป้องกันอัตโนมัติ กระสุนของคุณไม่โดนมัน บาดเจ็บ ถอย และตื่นตระหนก จำนวนที่สังหารได้
7. สุขภาพและโรค
สุขภาพแบบเหลือบเดียว ยาหกชนิด การสมานแผล แผลและผ้าพันแผล การติดเชื้อ: ไข้ วิกฤต และความตาย เคล็ด ท้องเสียและพยาธิ ไข้หวัด พยาธิหนอนหัวใจ ภูมิแพ้ หมัด และเห็บ ยา: หาที่ไหนและให้ยังไง
8. ความต้องการและการดูแล
ความเครียดมาจากไหน โปรตีน: มันเป็นสัตว์กินเนื้อ ป้อนอาหาร ป้อนน้ำ และลูบ บันไดของการละเลย ความโศกเศร้า
9. ความซื่อสัตย์
เกณฑ์ขั้นต่ำของการไม่เชื่อฟัง เมื่อสุนัขปฏิเสธคำสั่ง
10. ชาม: อาหารและน้ำโดยไม่ต้องมีคุณ
วิธีใช้ อะไรใช้เป็นอาหารในชามได้บ้าง สุนัขใช้ชามอย่างไร
11. ทักษะ: ห้าทักษะของสุนัข
การขัดคำสั่ง
12. ท่าทางจากการเชื่อฟัง
ไปยังจุดที่กำหนด (การเชื่อฟัง 1) ล่อความสนใจ (การเชื่อฟัง 3) ดมหาไอเทม (การเชื่อฟัง 5) ตามหาไอเทมขณะคุณนอนหลับ (การเชื่อฟัง 10)
13. การล่าสัตว์
มันล่าอะไร ใช้งานจริงเป็นอย่างไร ข้อจำกัด โบนัสการหาของ
14. การดูแลปศุสัตว์
มอบหมายอย่างไร มันทำอะไรอยู่ตรงนั้น กฎสำคัญ
15. กระเป๋าอาน: สุนัขในฐานะสัตว์บรรทุก
ใส่อย่างไร มันบรรทุกได้เท่าไร เก็บอะไรได้บ้าง หน้าต่าง หาได้ที่ไหน
16. การผสมพันธุ์และลูกสุนัข
ไม่มีปุ่ม "ผสมพันธุ์" เงื่อนไข พิธีการและการตั้งท้อง การคลอด ลูกสุนัขได้อะไรมาจากพ่อแม่ การเลี้ยงลูกสุนัข
17. สุนัขหลายตัวพร้อมกัน
แท็บ "คู่หูของฉัน": ทะเบียน
18. หน้าต่างของสุนัข
แท็บ "ทักษะและสถานะ" แท็บ "คำสั่ง" แท็บ "คู่หูของฉัน" แท็บ "ตั้งค่า"
19. สิ่งที่ปรากฏบนหน้าจอ
Moodle ของสุนัข ข้อความเหนือหัว หมุดบนแผนที่
20. ไอเทมของม็อด
โอกาสพบของแต่ละชิ้น ชามอาหารคู่หู กระเป๋าอานคู่หู
21. ผู้เล่นหลายคน
สุนัขของคุณเป็นของคุณ เมื่อคุณหลุดออกจากเกม สำหรับแอดมิน
22. ตัวเลือกแซนด์บ็อกซ์
การทำให้เชื่องและการเกิด การต่อสู้ การดูแลและความผูกพัน การดูแลสัตวแพทย์ พฤติกรรม ทักษะและกิจกรรม กระเป๋าอาน ลูกสุนัข อินเทอร์เฟซและผู้เล่นหลายคน
23. ปัญหาที่พบบ่อย
24. การเอาม็อดออกจากเซฟ (อ่านตรงนี้ก่อน)
ทำไมถึงเกิดขึ้น ถ้าสัตว์หายไปแล้ว วิธีเอาออกอย่างปลอดภัย ล้างให้หมดจด (แอดมิน / โหมดดีบัก)
25. การปรับจูนเซิร์ฟเวอร์ (แอดมิน)
วิธีเปิดแผง สิ่งที่ใช้ได้กับทุกช่อง อ่านค่าที่วัดได้ก่อนจะไปแตะอะไร การปรับ: จังหวะของพาส การปรับ: ระยะเอื้อมและการต่อสู้ การปรับ: การดมกลิ่น การปรับ: การเกิดของสุนัขจรจัด การปรับ: เครือข่าย (เฉพาะผู้เล่นหลายคน) สูตรสำเร็จ: อาการและสิ่งที่ต้องปรับ

Companion Dogs: คู่มือการใช้งาน

คู่มือว่าสุนัขของคุณทำอะไรได้บ้าง สั่งมันยังไง และดูแลมันยังไง

เรื่องสายพันธุ์ (เลือกตัวไหนดี แต่ละพันธุ์เด่นอะไร moodle และคุณลักษณะ) อยู่ในคู่มืออีกเล่ม: สายพันธุ์

ข้อความในเครื่องหมายคำพูดทั้งหมดในคู่มือนี้คือสิ่งที่ขึ้นในเกมภาษาไทย ถ้าเล่นเป็นภาษาอังกฤษ ชื่อจะเปลี่ยนไป แต่ตำแหน่งในเมนูยังเหมือนเดิม

การติดตั้ง: เริ่มที่นี่

ม็อดนี้ต้องใช้ Project Zomboid 42.19 ขึ้นไป (Build 42) เวอร์ชันเก่ากว่านั้นจะไม่โหลด

จะรู้ว่าม็อดเข้าเซฟของคุณแล้วหรือยัง ให้มองหาปุ่มรูปอุ้งเท้าที่แถบด้านซ้าย:

ถ้าไม่มีปุ่มนั้น แปลว่า Companion Dogs ไม่ได้ทำงานในเซฟนั้น และจะไม่มีสุนัขเกิดขึ้นในโลกเลย

ติดตั้ง

  1. สมัครรับม็อดบน Steam: Companion Dogs
  2. ในเมนูของ Zomboid เข้า ม็อด แล้วเปิดใช้งาน Companion Dogs
  3. ปิดเกมให้สนิท (ออกไปจนถึงหน้าเดสก์ท็อป) แล้วเปิดใหม่

ถ้าไม่รีสตาร์ท สุนัขมักจะโผล่มาแบบไม่มีเท็กซ์เจอร์หรือตัวยับ เพราะเกมโหลดโมเดลไปก่อนที่ม็อด จะเข้ามา

ถ้ามีเซฟอยู่แล้ว

คุณเพิ่มม็อดเข้าเซฟที่เล่นค้างไว้ได้ เซฟที่มีอยู่แล้วเก็บรายการม็อดของตัวเองไว้ และต้องเพิ่ม Companion Dogs เข้าไปในรายการนั้น:

  1. เมนูหลัก > โหลด
  2. คลิกที่เซฟเพื่อเลือกมัน
  3. มุมขวาล่าง: เพิ่มเติม... > เลือกม็อด...
  4. ติ๊ก Companion Dogs (และแอดออนสายพันธุ์ที่คุณใช้) แล้วยืนยัน
  5. โหลดเซฟ แล้วเช็กปุ่มอุ้งเท้าก่อนออกไปตามหาสุนัข

ยังไม่มีอาคารไหนในโลกของคุณถูกสุ่ม สุนัขจึงจะเริ่มโผล่มาเรื่อย ๆ ตามที่คุณเดินไป รวมถึงในที่ ที่คุณสำรวจไปแล้ว

โฮสต์ co-op

co-op คือเซิร์ฟเวอร์ที่รันอยู่บนเครื่องคุณเอง และมันไม่ได้รับรายการม็อดจากเมนูหลักมาด้วย

ขั้นที่ 1: เปิดใช้งานม็อดในเกมของคุณเอง เมนูหลัก > ม็อด > ติ๊ก Companion Dogs และแอดออน สายพันธุ์ที่จะใช้ ปิดเกมให้สนิทแล้วเปิดใหม่

ขั้นที่ 2: ใส่ม็อดเข้าไปในการตั้งค่าของเซิร์ฟเวอร์:

  1. เมนูหลัก > สร้างเซิร์ฟเวอร์ > จัดการการตั้งค่า...
  2. เลือกการตั้งค่าที่จะใช้ แล้วคลิก แก้ไข
  3. ในรายการทางซ้าย เปิด SteamWorkshop (ชื่อนี้เป็นภาษาอังกฤษในทุกภาษา) ที่ช่อง เพิ่มเวิร์กชอปบน Steam ที่ต้องการใช้เข้าสู่รายการนี้: ให้เลือก Companion Dogs ถ้ายังไม่ได้ สมัครรับ ให้ใช้ เพิ่มเวิร์กชอปบน Steam ที่ต้องการใช้ด้วย Workshop ID: พิมพ์ 3740052292 แล้วกด Enter
  4. ยังอยู่ในรายการทางซ้าย เปิด Mods แล้วเพิ่ม CompanionDogs ด้วยวิธีเดียวกัน
  5. คลิก บันทึก

สองรายการนี้ก็คือ WorkshopItems= กับ Mods= ของเซิร์ฟเวอร์เฉพาะ เพียงแต่ทำผ่านหน้าจอ สิ่งที่แก้ จะไปลงที่ Zomboid\Server\<ชื่อการตั้งค่า>.ini ใช้ ID ชุดเดียวกับตารางในหัวข้อก่อนหน้า และลำดับ เดียวกัน คือม็อดหลักมาก่อนแอดออนสายพันธุ์

ขั้นที่ 3: เริ่มเซิร์ฟเวอร์ด้วยปุ่ม เริ่ม ใครเข้ามาก็จะดาวน์โหลดม็อดเอง

ถ้ามีอะไรผิดพลาด: สุนัขไม่มีเท็กซ์เจอร์หรือตัวยับ แปลว่าข้ามขั้นที่ 1 ไป ส่วนไม่มีปุ่มอุ้งเท้าและ ไม่มีสุนัขในโลกเลยสักตัว สำหรับทุกคน แปลว่าข้ามขั้นที่ 2 ไป

1. ใน 5 นาที: จากหมาจรจัดสู่คู่หู

  1. หาสุนัขให้เจอ หมาจรจัดพันธุ์ Caramelo เดินอยู่ตามเมืองและย่านที่พักอาศัย
  2. มีอาหารติดตัวไว้ อาหารอะไรก็ได้ ขอแค่ไม่เน่าและแก้หิวได้
  3. คลิกขวาที่สุนัขแล้วเลือก ให้อาหาร (เพิ่มค่าความไว้ใจ)
  4. ทำซ้ำจนมันไว้ใจคุณ ถุงอาหารสุนัขใบใหญ่เกือบจบในครั้งเดียว ขนมชิ้นเล็กต้องให้ราว สี่รอบ
  5. ตั้งชื่อให้มัน จากนั้นมันจะตามคุณไปเอง

หลังจากนั้นก็เป็นเรื่องประจำวัน:

  • ให้อาหารและน้ำทุกวัน โดยค่าเริ่มต้น การละเลยจะลดพลังชีวิตลงถึง 10% แล้วหยุดอยู่แค่นั้น ถ้าเปิด ตัวเลือกแซนด์บ็อกซ์ โรคและการละเลยอาจถึงตาย สุนัขจะตายและไม่กลับมาอีก
  • ลูบมันบ้าง ช่วยรักษาความซื่อสัตย์ไว้ และยังบรรเทาความเบื่อหน่ายกับความเศร้าของคุณเองด้วย
  • เปิดหน้าต่างของมันที่ปุ่มอุ้งเท้า ใต้แผงมือของคุณ ทุกอย่างเกี่ยวกับสุนัขอยู่ในนั้น ทั้งหมด

2. หาและรับเลี้ยงสุนัข

วิธีรับเลี้ยง

คลิกขวาที่สุนัขจรจัด ตัวเลือกเดียวที่ขึ้นมาคือ ให้อาหาร (เพิ่มค่าความไว้ใจ)

  • ใช้แค่อาหาร ไม่ต้องมีทักษะขั้นต่ำ คุณลักษณะ ปลอกคอ หรือเครื่องมืออะไรทั้งนั้น
  • อาหารจะอยู่ในกระเป๋าก็ได้ ม็อดหาเจอเอง
  • ถ้ามีอาหารหลายชนิด จะมีเมนูย่อยขึ้นมาพร้อมไอคอนและจำนวนของแต่ละอย่าง
  • ถ้าไม่มีอาหารเลย ตัวเลือกจะเป็นสีเทา: ไม่มีไอเท็มอาหารอยู่ในตัว

ต้องใช้อาหารเท่าไร

อาหารแต่ละมื้อให้ความไว้ใจเท่ากับค่าความหิวที่อาหารนั้นแก้ได้ ไอเทมที่ลดความหิวไป 60 หน่วย จะให้ ความไว้ใจ 60 ค่าเริ่มต้นคือต้องมีความไว้ใจ 100 จึงจะรับเลี้ยงได้ (ตัวเลือกแซนด์บ็อกซ์ ความไว้ใจสำหรับรับเลี้ยง)

ม็อดจะกินเฉพาะส่วนที่จำเป็น แล้วคืนไอเทมที่เหลือกลับเข้าช่องเก็บของคุณ

ขั้นตอนนี้ไม่ขึ้นกับดวง

ระหว่างที่แถบยังไม่เต็ม จะขึ้นว่า: Caramelo เริ่มไว้ใจคุณ พอเต็ม: ยินดีด้วย Caramelo เป็นคู่หูของคุณแล้ว! แล้วกล่องตั้งชื่อจะเปิดขึ้นมา

อาหารที่เป็นอันตราย

อาหารที่ไม่ดีจะขึ้นเป็นสีแดงในเมนู พร้อมคำเตือน ไม่ดีต่อสัตว์ หากให้สิ่งนี้จะทำให้มันป่วย และ ไว้ใจคุณน้อยลง

  • ตามชนิด: ลูกอม น้ำตาล กาแฟ ชา โกโก้ ช็อกโกแลต พริกไทย ถั่วเปลือกแข็ง
  • ตามชื่อ: หัวหอม กระเทียม ต้นกระเทียม ต้นหอม หอมแดง องุ่น ลูกเกด ช็อกโกแลต โกโก้ กาแฟ ถั่วลิสง ส่วนเกรปฟรุตให้ได้

ให้อาหารที่เป็นอันตรายกับสุนัขจรจัด จะหักความไว้ใจ 15 และไม่บวกอะไรเลย ถ้าเป็นคู่หู จะหักความ ซื่อสัตย์ 20 เพิ่มความเครียด และทำให้มันเมาไป 120 นาทีในเกม

เกิดอะไรขึ้นในวินาทีที่มันเป็นของคุณ

  • มันเข้าโหมดตาม โดยเปิดป้องกันอัตโนมัติไว้
  • ความหิว ความกระหาย และความเครียดกลับไปเป็นศูนย์
  • คุณลักษณะทางพันธุกรรมถูกสุ่มตอนนั้น และไม่เปลี่ยนอีกเลย
  • มันกลายเป็นอมตะ: ซอมบี้ รถ กระสุน และไฟ ฆ่ามันไม่ได้ การละเลยและแผลติดเชื้อที่ไม่ได้รักษา (ดูหัวข้อแผลและผ้าพันแผล ในหัวข้อ 7) จะฆ่าได้ก็ต่อเมื่อเปิดตัวเลือกแซนด์บ็อกซ์ โรคและการละเลยอาจถึงตาย ไว้เท่านั้น ค่าเริ่มต้นคือพลังชีวิตหยุดที่ 10%
  • มันเข้าไปอยู่ในทะเบียน คู่หูของฉัน และเริ่มขึ้นบนแผนที่

การรับเลี้ยงสุนัขตัวใหม่ไม่ได้ปล่อยตัวเก่าไป ตัวใหม่จะกลายเป็นสุนัขตัวหลัก ส่วนตัวเก่ากลายเป็น ตัวสำรองในโหมดนิ่ง ดูที่ สุนัขหลายตัวพร้อมกัน

ขีดจำกัดจำนวนสุนัข

ตัวเลือกแซนด์บ็อกซ์ จำนวนสุนัขที่รับเลี้ยงได้สูงสุด มาที่ 0 ซึ่งแปลว่าไม่จำกัด ถ้า เซิร์ฟเวอร์ตั้งเพดานไว้ พอถึงเพดานแล้วตัวเลือกผูกมิตรจะกลายเป็นสีแดงและกดไม่ได้: สุนัขคู่หูของคุณเต็มแล้ว (5) (ตัวเลขคือเพดานที่ตั้งไว้) ปล่อยหรือเสียสุนัขไปหนึ่งตัวจะได้ ช่องคืนมา

4. สามโหมด: ตาม นิ่ง และป้องกัน

สุนัขอยู่ในหนึ่งในสามโหมดนี้เสมอ ส่วนการเฝ้าระวัง การล่าสัตว์ และป้องกันอัตโนมัติ เป็นการปรับซ้อนบนโหมด

โหมดตาม

เป็นค่าเริ่มต้น มันเดินตามหลังคุณ: เริ่มเดินเมื่อคุณห่างออกไป 2 ช่อง และเปลี่ยนเป็นวิ่งเมื่อเกิน 6 ช่อง หรือทันทีที่คุณออกวิ่ง

  • สู้กับซอมบี้ในรัศมี 5 ช่องรอบตัวคุณ (ไม่ใช่รอบตัวมัน) และปล่อยเป้าหมายที่ 8 ช่อง
  • กระโดดข้ามรั้วเตี้ย ขึ้นบันได และเปลี่ยนชั้นตามคุณไป
  • เป็นโหมดเดียวที่มันขึ้นรถไปกับคุณ
  • ถ้าคุณห่างออกไปเกิน 24 ช่อง มันจะถูกดึงมาไว้ข้างหลังคุณ เพื่อไม่ให้ไปติดอยู่อีกฝั่งของ อาคาร

แถบ ระยะการตาม ในแท็บคำสั่ง ปรับได้ตั้งแต่ 2 ถึง 8 ช่อง ทีละครึ่งช่อง ค่าเริ่มต้นคือ 2 ซึ่งทำให้สุนัขติดส้นเท้าคุณ ระยะที่กว้างขึ้นจะพามันพ้นทางเดินของคุณในครัว ในทางเดิน และในช่อง ประตู ซึ่งเป็นที่ที่สุนัขตัวใหญ่ขวางมากที่สุด ค่านี้ตั้งแยกต่อตัว และบันทึกไว้กับตัวสัตว์: อยู่รอดข้ามการออกและเข้าเกมใหม่ ข้ามการฝากไว้ในคอก และข้ามการย้ายโลก ถ้าเปิดระยะไว้กว้าง มันจะเริ่มออกวิ่งจากไกลกว่าเดิม และใช้เวลานานกว่าจะไปถึงซอมบี้

"Caramelo จะเดินตามหลังคุณและเข้าปะทะซอมบี้ที่เข้ามาใกล้ ระบบเฝ้าระวังยังทำงานต่อไป เป็นค่าเริ่มต้น คู่หูของคุณระหว่างเดินทาง"

โหมดนิ่ง

  • ยังคงดมกลิ่นและเตือนเรื่องซอมบี้อยู่
  • ไม่ไล่และไม่สู้ แม้จะมีซอมบี้มาจ่อหน้า
  • มันจะอยู่ข้างหลังเมื่อคุณขึ้นรถ

ใช้ เรียกกลับมา ตอนที่สุนัขติดอยู่หลังรั้ว ติดอยู่ในอาคาร หรืออยู่ไกลเกินกว่าจะเดินกลับมาเอง ส่วนการใช้งานทั่วไป ใช้ มานี่

5. เฝ้าระวัง: สุนัขในฐานะสัญญาณเตือน

สุนัขรับรู้ซอมบี้ที่คุณยังมองไม่เห็น แล้วเตือนคุณ

การเฝ้าระวังทำงานในทั้งสามโหมด แต่ไม่ทำงานระหว่างการเร่งเวลา และไม่ทำงานตอนที่คุณ นอนหลับ

โหมด ระยะ เตือนยังไง
ระวังภัยขั้นสุด 18 ช่อง (ถึง 27 ช่องเมื่อดมกลิ่นเต็มขั้น) ขู่เบา ๆ ใส่ซอมบี้ที่อยู่ไกลหรือมีไม่กี่ตัว เห่าเสียงดังใส่ซอมบี้ที่อยู่ใกล้ มากันเป็นกลุ่ม หรืออยู่ในสายตา เสียงเห่าดึงดูดซอมบี้จริง ๆ
ส่งเสียงเบาๆ 10 ช่อง ตายตัว ขู่อย่างเดียว ไม่เห่าเลย ไม่ดึงดูดอะไรทั้งนั้น
ระวังภัยแบบเงียบ ไม่มี ไม่เตือนเรื่องซอมบี้เลย

สุนัขจะเปลี่ยนจาก ได้กลิ่นอะไรบางอย่าง เป็น เตือนภัย เมื่อซอมบี้อยู่ห่าง 6 ช่องหรือน้อยกว่า เมื่อมีซอมบี้ตั้งแต่ 3 ตัวขึ้นไป หรือเมื่อมีแนวสายตาโล่งถึง 12 ช่อง

ข้อความจะลอยขึ้นเหนือหัวของมัน:

  • Caramelo สัมผัสได้ว่ามีซอมบี้อยู่ใกล้
  • Caramelo คำราม ซอมบี้อยู่ใกล้มาก!

ปั๊ก (แอดออน) ติดอยู่ที่ระวังภัยขั้นสุดอย่างเดียว ส่งเสียงเบาๆ กับระวังภัยแบบเงียบจะขึ้นเป็นสีเทา ในหน้าต่างของมัน และหายไปจากเมนูวงกลม ตัวเลือกแซนด์บ็อกซ์เรื่องเสียงใช้กับทุกสายพันธุ์ ถ้าปิดไว้ เสียงเห่าจะไม่ดึงดูดซอมบี้เลยสักเสียง

ความเครียดไม่ได้ทำให้สุนัขเห่า ถ้าสุนัขของคุณกำลังเรียกซอมบี้เข้ามา ต้นเหตุมาจากสี่อย่างนี้: การเฝ้าระวังที่ระวังภัยขั้นสุด ท่า ล่อความสนใจ การไล่ล่าตอนออกล่าสัตว์ หรือการต่อสู้

6. การต่อสู้

เมื่อไรที่มันสู้เอง

สุนัขไม่ได้ออกไปไล่โจมตีเองตามใจ มันรอตัวกระตุ้น:

  • ในโหมดตาม จะสู้ก็ต่อเมื่อเปิดป้องกันอัตโนมัติไว้ และเฉพาะตอนที่ซอมบี้เล็งคุณหรือเล็งสุนัข หรือ ตอนที่คุณกำลังสู้อยู่แล้ว ซอมบี้ต้องอยู่ห่างจากคุณ 5 ช่องหรือน้อยกว่า
  • ในโหมดป้องกัน สู้เสมอ ภายใน 10 ช่องจากตำแหน่งประจำ
  • ด้วยคำสั่ง โจมตีตัวที่ใกล้ที่สุด มันจะค้นหาในรัศมี 12 ช่อง และไล่ล่านาน 2 นาที ในเกม

มันโจมตีเฉพาะซอมบี้ที่เป็นศัตรู NPC ฝ่ายเดียวกันจากม็อดอื่น (Bandits, A-Life) จะถูกเว้นไว้

มันไม่กัดทะลุกำแพง

สุนัขจะเข้าปะทะเฉพาะซอมบี้ที่มันเดินไปถึงได้เท่านั้น ซอมบี้ที่อยู่อีกฝั่งของรั้ว หรืออยู่ในห้องปิด จะถูกมองข้าม ถ้ามันลองแล้วติดอยู่กับที่สองวินาทีครึ่งโดยไม่คืบหน้า มันจะทิ้งเป้าหมายนั้น แล้วเมิน มันไป 12 วินาที

มันทำความเสียหายแค่ไหน

ความเสียหายเป็นผลคูณของสี่อย่าง: พลังตามธรรมชาติของสายพันธุ์ เลเวลการต่อสู้ ยีนพลัง และ ตัวคูณจากแซนด์บ็อกซ์

  • Caramelo ฆ่าซอมบี้เองไม่ได้ มันทิ้งซอมบี้ไว้ที่พลังชีวิต 10% แล้วหยุด และไม่มีการตั้งค่า แซนด์บ็อกซ์ไหนเปลี่ยนเรื่องนี้ได้
  • สายพันธุ์อื่นทั้งหมดปิดงานได้
  • สุนัขอ่อนแรง ที่ไม่ได้กินโปรตีนมาสามวัน จะตีได้แค่ครึ่งเดียว ทำให้ มันมักปิดงานไม่ได้ แล้วไปติดอยู่กับซอมบี้

ตารางความเสียหายแยกตามสายพันธุ์อยู่ในคู่มือสายพันธุ์

การตีแต่ละครั้งมีโอกาสทำให้ซอมบี้ล้ม เริ่มที่ 10% และขึ้นถึง 50% เมื่อการต่อสู้เต็มขั้น

ป้องกันอัตโนมัติ

เปิดและปิดแยกต่อตัว เมื่อเปิดไว้ สุนัขจะทำหน้าที่ยามในตอนที่คุณป้องกันตัวเองไม่ได้:

  • กำลังนอนหลับ
  • กำลังอ่านหนังสือ
  • กำลังนั่งอยู่กับพื้น
  • กำลังกิน
  • กำลังตกปลา

มันจะปักหลักอยู่ข้างตัวคุณและรับมือทุกอย่างที่เข้ามา ถ้าคุณเดิน จุดปักหลักก็ขยับตาม พอคุณ ทำสิ่งนั้นเสร็จ มันก็กลับไปเดินตามคุณเอง

  • สุนัขที่อยู่ในตำแหน่งประจำของโหมดป้องกันจะไม่ทิ้งตำแหน่งเพราะเรื่องนี้
  • การสู้แบบนี้ทำให้สุนัขเครียด และไม่ได้ความซื่อสัตย์เพิ่ม

มันเปิดไว้ให้อยู่แล้วตั้งแต่ตอนที่คุณรับเลี้ยงสุนัข

กระสุนของคุณไม่โดนมัน

สุนัขคู่หูไม่เสียพลังชีวิตจากกระสุน ไม่ว่าของคุณหรือของผู้เล่นคนอื่น ในทุกสถานการณ์

  • มันอยู่นอกระบบเล็งอัตโนมัติ การเล็งของคุณจึงไม่ไปติดที่ตัวมันเวลายกปืนขึ้น
  • ในโหมดเล่นคนเดียว ณ วินาทีที่ยิง ม็อดจะเอาสุนัขออกจากการคิดวิถีกระสุน และกระสุนจะวิ่งตรงไปหา ซอมบี้ที่อยู่ข้างหลังมัน

สุนัขไม่ต้องขยับหลบเพื่อให้เรื่องนี้เกิดขึ้น และมันไม่เคยหันมาเล่นงานคุณ

ในโหมดผู้เล่นหลายคน ถ้าคุณยิงจากระยะไกล สุนัขของผู้เล่นคนอื่นอาจดูเหมือนมีปฏิกิริยาบนจอของคุณ แต่มันไม่เสียพลังชีวิต

บาดเจ็บ ถอย และตื่นตระหนก

  • การสู้ไม่ได้หักพลังชีวิตของสุนัขทันที แค่ทำให้เครียด การกัดแต่ละครั้งมีโอกาสเล็กน้อยที่จะ ทำให้มันเลือดออก
  • พลังชีวิตของมันลดจากการละเลย (ความหิวหรือความกระหายเกิน 0.8) จากอาหารเป็นพิษ จากกวางที่ โต้กลับตอนล่าสัตว์ และจากอาการต่าง ๆ ในหัวข้อสุขภาพ การละเลยและการติดเชื้อที่ไม่ได้รักษาจะฆ่าได้ ก็ต่อเมื่อเปิด โรคและการละเลยอาจถึงตาย ในแซนด์บ็อกซ์ ถ้าปิดไว้ซึ่งเป็นค่าเริ่มต้น พลังชีวิตจะหยุดที่ 10%
  • สถานะบาดเจ็บ: บาดเจ็บ เมื่อพลังชีวิตต่ำกว่า 30% และ บาดเจ็บหนัก เมื่อต่ำกว่า 10% สุนัขที่บาดเจ็บหนักจะแค่ตามคุณ ไม่สู้
  • มันจะถอยมาอยู่หลังคุณเมื่อพลังชีวิตลงมาที่ 10% หรือต่ำกว่า
  • พอเครียดมากมันจะตื่นตระหนก: ไม่สู้ ไม่เฝ้า และไม่ทำท่าทางตามคำสั่ง แต่ยังวิ่งมาหาคุณเมื่อถูก เรียก มันจะหายตื่นตระหนกก็ต่อเมื่อความเครียดลดลงต่ำกว่าเส้นแบ่งไปมาก

จำนวนที่สังหารได้

สุนัขแต่ละตัวมีตัวนับของตัวเอง ดูได้ในหน้าต่างของมัน: สังหาร: ซอมบี้ 14 ตัว, สัตว์ป่า 3 ตัว

ซอมบี้ที่มันฆ่าจะนับรวมเข้าตัวนับของคุณในหน้าจอตัวละครด้วย

7. สุขภาพและโรค

ทุกอย่างที่ทำให้สุนัขป่วยได้ และวิธีดูแลมัน สองตารางข้างล่างคือบทสรุป ส่วนรายละเอียด ของแต่ละอาการอยู่ถัดจากนั้น หัวข้อละเรื่อง

สุขภาพแบบเหลือบเดียว

สิบสี่สถานะที่สุนัขเป็นได้ ไอคอนเป็นอันเดียวกับที่ขึ้นในแถว moodle คุณจึงหาสิ่งที่เห็นบนจอได้ จากตรงนี้ รายละเอียดของแต่ละอันอยู่ในหัวข้อถัด ๆ ไป

ไอคอน สถานะ ติดได้ยังไง ทำอะไร หายยังไง
เลือดออก 0.4% ต่อการกัดซอมบี้หนึ่งครั้ง เสียพลังชีวิตและเดินกะเผลก หยุดเองใน 12 ชม. หรือหยุดทันทีเมื่อพันแผล
แผลปิดแล้ว หลังเลือดหยุดไหล เดินกะเผลก ปิดสนิทใน 2 วัน เหลือ 1 วันถ้าพันแผล
ขาหัก สู้ต่อทั้งที่ขาบาดเจ็บอยู่แล้ว วิ่งและสู้ไม่ได้ ราว 3 วันของการพันแผลและพักฟื้น
เคล็ด 0.5% ต่อการกระโดดรั้วหนึ่งครั้ง เดินช้าลง แต่ยังสู้ได้ 12 ชม. ถ้าอยู่นิ่ง 24 ชม. ถ้าตามคุณไปด้วย
ติดเชื้อ แผลที่ไม่ได้พัน เสียพลังชีวิต แผลไม่สมาน 2 วันถ้าปล่อยไว้ 12 ชม. ถ้าใช้ยาปฏิชีวนะ
มีไข้ ติดเชื้อ ไข้หวัด หรือพยาธิหนอนหัวใจครบ 12 ชม. กระหายน้ำมากขึ้น ก้าวสั้นลง หายไปพร้อมต้นเหตุ
วิกฤต ติดเชื้อโดยพลังชีวิตต่ำกว่า 10% หมอบแล้วไม่ยอมลุก ยาปฏิชีวนะ ด่วน
ท้องเสีย อาหารเน่าเสมอ อาหารใกล้เสียและน้ำสกปรกอย่างละ 25% หิวและกระหายเป็นสองเท่า 1 ถึง 2 วันโดยให้ดื่มน้ำสะอาด
พยาธิ 10% ทุก 6 ชม. ที่ท้องเสีย หิวมากขึ้น ต้องใช้ยาถ่ายพยาธิเท่านั้น
ไข้หวัด หิวจัด หรืออยู่ห่างสุนัขที่เป็นไข้หวัดหนึ่งช่อง มีไข้ ก้าวสั้นลง กระหายน้ำมากขึ้น 2 ถึง 4 วัน หรือ 1 วันถ้าฉีดวัคซีน
พยาธิหนอนหัวใจ 1.5% ทุก 6 ชม. ที่อยู่กลางแจ้งติดต่อกัน เสียพลังชีวิต ไม่ยอมสู้และไม่ยอมทำงาน 3 ถึง 6 วัน หรือ 18 ชม. ถ้าใช้ยา
ภูมิแพ้ผิวหนัง เนื้อชนิดที่สุนัขตัวนั้นแพ้ หรือปรสิตบนผิวหนัง เดินช้าลงและเครียด 12 ถึง 24 ชม. ถ้าปล่อยไว้ 6 ชม. ถ้าใช้ยาแก้แพ้
หมัด 0.2% ต่อการกัดหนึ่งครั้งในการต่อสู้ ทำให้เครียดและอาจกลายเป็นภูมิแพ้ ต้องใช้ยากำจัดหมัดเท่านั้น หายใน 12 ชม.
เห็บ 0.2% ต่อการกัดหนึ่งครั้งในการต่อสู้ เหมือนหมัด แต่แรงเกือบสองเท่า ต้องใช้ยากำจัดหมัดเท่านั้น หายใน 12 ชม.

การสมานแผล

สุนัขรักษาตัวเองได้: พลังชีวิตเต็มแถบในราว 8 ชั่วโมงในเกม การสมานจะหยุดเมื่อแถบความหิวหรือ ความกระหายเลยครึ่งไป

แผลและผ้าพันแผล

  • ทุกครั้งที่สุนัขกัดซอมบี้ มีโอกาส 0.4% ที่มันจะได้แผลเปิดกลับมา เลเวลการต่อสู้แต่ละเลเวลจะลดโอกาสนี้ ลง 0.02 จุด ที่เลเวล 10 โอกาสจะเหลือครึ่งหนึ่ง คือ 0.2% โอกาสจะสูงขึ้นถ้าสุนัข บาดเจ็บหรือเครียดอยู่แล้ว และจะไม่มีแผลใหม่ถี่กว่าทุก 2 ชั่วโมงในเกม
  • สุนัขทุกสายพันธุ์จะเดินกะเผลกและช้าลงเล็กน้อย: เดินช้าลง 10% และวิ่งช้าลง 25% ป้าย เลือดออก จะขึ้นที่ชื่อ ในหน้าต่าง และใน moodle แล้วเปลี่ยนเป็น บาดเจ็บ ทันทีที่ พันแผลเสร็จ แท็บ สุขภาพ ของหน้าต่างสุนัขจะแสดงเงาตัวมันโดยระบายสีขาที่บาดเจ็บไว้ พร้อมรายการส่วนต่าง ๆ ของร่างกายและอาการที่กำลังเป็นอยู่ คลิกขวาตรงนั้นจะเปิดเมนูรักษา ส่วนหัวข้อสุขภาพในแท็บสถานะจะบอกอาการ ผ้าพันแผล และสิ่งที่ต้องทำ ถ้าการเลี้ยงสัตว์ ถึงเลเวล 5 ขึ้นไป ทั้งสองที่จะแสดงความคืบหน้าของการรักษาด้วย
  • ตอนบาดเจ็บ มันจะปฏิเสธการล่าสัตว์และการป้องกันจนกว่าจะหาย ส่วนตาม นิ่ง และโจมตี ยังทำได้ตามปกติ
  • ถ้าสุนัขยังสู้ต่อทั้งที่แผลยังเปิดอยู่ การกัดแต่ละครั้งอาจทำให้ขาหักได้ ด้วยโอกาสเท่ากับ โอกาสเกิดแผล จะมีคำเตือน Caramelo ขาหัก! ป้ายและ moodle ขาหัก แล้วสุนัขจะเดินด้วย ก้าวครึ่งเดียวและไม่วิ่งอีกเลยในทุกสถานการณ์ การรักษาจะกินเวลา 3 วัน แม้จะ พันแผลไว้แล้ว
  • ถ้าเลือดออกและไม่ได้พันแผล พลังชีวิตจะลดลง (90% ของแถบต่อวัน เต็มแถบในเวลาเกินหนึ่งวันนิดเดียว) และจะไม่ฟื้นจนกว่าคุณจะพันแผลให้ ถ้าลงถึงศูนย์ สุนัขจะตาย ใช้ได้กับทุกระยะ: แผลติดเชื้อที่ไม่ได้ พันจะทั้งเลือดออกและติดเชื้อไปพร้อมกัน
  • ถ้าไม่พันแผล เลือดจะหยุดเองใน 12 ชั่วโมง แล้วข้อมูลจะเปลี่ยนเป็น แผลเปิด แผลยังเปิดอยู่ และยังติดเชื้อได้ ผ้าพันแผลหยุดเลือดได้ทันที
  • แผลที่ไม่ได้พันมีโอกาสติดเชื้อ 20% ต่อชั่วโมงในเกม ถ้าพันด้วย ผ้าสกปรก 5% ถ้าพันด้วยผ้าสะอาดหรือผ้าปลอดเชื้อ เป็นศูนย์ แผลที่ติดเชื้อจะขึ้นว่า ติดเชื้อ และล็อกทั้ง การฟื้นพลังชีวิตและการผสมพันธุ์ไว้ตลอดที่ยังเป็นอยู่
  • จะรักษา ให้ใช้ รักษาแผล จากการคลิกขวาที่สุนัข หรือคลิกขวาที่อาการในหัวข้อสุขภาพ ของหน้าข้อมูล โดยมีผ้าพันแผลหรือผ้าปูที่นอนฉีกอยู่ในตัว ผ้าที่พันจะเป็นแบบปลอดเชื้อถ้าใช้ ผ้าพันแผลชุบแอลกอฮอล์ หรือถ้าคุณมียาฆ่าเชื้อ ผ้าเช็ด หรือสำลีชุบแอลกอฮอล์อยู่ในตัว (จะถูกใช้ไปด้วย) การปฐมพยาบาลช่วยย่นเวลาของการกระทำนี้ การรักษาให้ความซื่อสัตย์ ผ้าพันแผล จะติดอยู่กับสุนัข และกลับเข้าช่องเก็บของคุณในสภาพสกปรก เมื่อคุณใช้ แกะผ้าพันแผล หรือ เมื่อแผลปิดสนิท ขาที่บาดเจ็บจะเห็นรอยแผลสีแดงตอนที่ เลือดออก และเห็นแถบผ้าก๊อซเมื่อพันไว้ ทั้งในทุกสายพันธุ์ของม็อดหลักและในแอดออนสายพันธุ์ ซึ่งเดินกะเผลกจากขาที่บาดเจ็บเหมือนกัน ผ้าพันแผลสกปรกก็ใช้ได้
  • แผลสะอาดปิดสนิทใน 2 วัน เหลือ 1 วันถ้าพันแผล สุนัขที่อยู่นิ่ง (โหมดนิ่ง หรือเป็นตัวสำรองอยู่บ้าน) จะหายเต็มอัตรา สุนัขที่ทำงานอยู่หายครึ่งอัตรา และสุนัขที่กำลังสู้ไม่หายเลย สุนัขที่ดูแลฟาร์มหายเท่า ตัวสำรองที่อยู่บ้าน มีแต่สุนัขที่เก็บไว้ในคอกที่หยุดนิ่ง เพราะมันออกไปจากโลก
  • ในแซนด์บ็อกซ์ การดูแลสัตวแพทย์ เปิดและปิดทั้งหมดนี้ (ปิดกลางคันจะปลดล็อกสุนัขทันที) ส่วน โรคและการละเลยอาจถึงตาย (ค่าเริ่มต้นคือปิด) ตัดสินว่าพลังชีวิตจะลงถึงศูนย์ได้ไหม ทั้งจากโรคและจากความหิวกับความกระหาย ถ้าปิดไว้ การลดทั้งหมดจะหยุดที่ 10%
  • แต่ละโรคมีค่าโอกาสเป็นเปอร์เซ็นต์ของตัวเอง และตั้งเป็นศูนย์จะปิดโรคนั้นไปโรคเดียว: โอกาสบาดเจ็บต่อการกัด (เปอร์เซ็นต์) (ค่าเริ่มต้น 0.4), โอกาสเคล็ดต่อการกระโดดรั้ว (เปอร์เซ็นต์) (ค่าเริ่มต้น 0.5), โอกาสเป็นพยาธิต่อการท้องเสีย 6 ชม. (เปอร์เซ็นต์) (ค่าเริ่มต้น 10), โอกาสท้องเสีย (เปอร์เซ็นต์) (ค่าเริ่มต้น 25), โอกาสเป็นไข้หวัด (เปอร์เซ็นต์) (ค่าเริ่มต้น 15 ใช้ ทั้งกับการสุ่มรายวันของสุนัขที่หิวจัด และกับทุกชั่วโมงที่อยู่ข้างสุนัขที่ป่วย), โอกาสเป็นพยาธิหนอนหัวใจ (เปอร์เซ็นต์) (ค่าเริ่มต้น 1.5), โอกาสแพ้อาหาร (เปอร์เซ็นต์) (ค่าเริ่มต้น 5) และ โอกาสติดหมัดหรือเห็บต่อการกัดหนึ่งครั้ง (เปอร์เซ็นต์) (ค่าเริ่มต้น 0.2)

การติดเชื้อ: ไข้ วิกฤต และความตาย

  • การติดเชื้อแย่ลงได้เอง หลังติดเชื้อครบ 12 ชั่วโมง จะพันแผลหรือไม่ก็ตาม ไข้จะตามมา: ป้าย มีไข้ สุนัขเดินช้าลง 20% และพลังชีวิตลดเร็วขึ้น (ตอนติดเชื้อ หนึ่งในสี่ของแถบต่อวัน ตอนมีไข้ ครึ่งแถบ) ส่วนสถานะวิกฤตขึ้นกับพลังชีวิตอย่างเดียว: ติดเชื้อและพลังชีวิต ต่ำกว่า 10% สุนัขจะหมอบลง ไม่ลุก และปฏิเสธคำสั่งตาม มานี่ และโจมตี ถ้าพลังชีวิตถึงศูนย์ มันจะตาย ถ้าปิด โรคและการละเลยอาจถึงตาย ไว้ ซึ่งเป็นค่าเริ่มต้น ทั้งโรค ความหิว และความกระหาย จะไม่ดึงพลังชีวิตลงต่ำกว่า 10%
  • ผ้าพันแผลไม่ได้รักษาการติดเชื้อ และไม่ได้กันไข้ ถ้าปล่อยไว้เอง การติดเชื้อจะหายใน 2 วันนับจาก วันที่ติด Companion Dogs ยาปฏิชีวนะ ย่นให้เหลือ 12 ชั่วโมง ส่วนยาปฏิชีวนะของเกมหลักรักษา ได้ในเวลาเท่ากัน: เป็นโมเลกุลเดียวกัน สิ่งที่ขาดไปคือโดสที่พอดีกับน้ำหนักสุนัข ยาของคนจึง มีโอกาส 25% ที่จะทำให้ท้องเสียทันทีที่ได้รับโดส (สุนัขที่ฉีดวัคซีนแล้วไม่เสี่ยงเรื่องนี้) ระหว่างที่ ยาปฏิชีวนะออกฤทธิ์ ไข้จะไม่ลุกลาม พอรักษาการติดเชื้อหายแล้ว แผลยังเปิดอยู่ และปิดตามจังหวะปกติ
  • Companion Dogs วัคซีน ให้เวลา 90 วันที่แผลจะไม่ติดเชื้อ อาหารเสียหรือน้ำปนเปื้อนไม่ทำให้ ท้องเสีย และสุนัขไม่ติดไข้หวัด moodle ฉีดวัคซีนแล้ว

เคล็ด

  • การกระโดดรั้วแต่ละครั้งมีโอกาส 0.5% ที่สุนัขจะขาเคล็ด (มากขึ้นถ้าสุนัขบาดเจ็บหรือเครียดอยู่) มันจะเดินกะเผลกและช้าเหมือนตอนมีแผล (เดิน -10%, วิ่ง -25%) แต่ยังสู้ได้ ส่วนการล่าสัตว์ และการป้องกันมันจะปฏิเสธ
  • หายได้ด้วยการพักเท่านั้น: ครึ่งวันถ้าสุนัขอยู่ในโหมดนิ่งหรือเป็นตัวสำรอง หนึ่งวันเต็มถ้ามันยัง ตามคุณไปด้วย ถ้าเข้าสู้ การฟื้นตัวจะหยุด ส่วนขาหักเป็นอีกเรื่อง: กระโดดรั้วไม่ได้และ สู้ไม่ได้

ท้องเสียและพยาธิ

  • อาหารเน่าที่ป้อนด้วยมือทำให้ท้องเสียเสมอ อาหารใกล้เสียและน้ำปนเปื้อนของเกม (แบบที่ทำให้คุณ เป็นพิษ) มีอย่างละ 25% และน้ำนับทั้งในชามและที่ป้อนด้วยมือ โดยสุ่มทุก 12 ชั่วโมงต่อสุนัขหนึ่งตัว เติมน้ำสะอาดแล้วจะหาย
  • เป็นอยู่ 1 ถึง 2 วัน และนาฬิกาจะเดินเฉพาะตอนที่สุนัขได้ดื่มน้ำ (ความกระหายต่ำกว่าครึ่ง) ระหว่าง นั้นความหิวและความกระหายลดเร็วเป็นสองเท่า พลังชีวิตไม่ฟื้น มันไม่ผสมพันธุ์ และปฏิเสธการล่าสัตว์ กับการป้องกัน ป้าย ท้องเสีย
  • หญ้ากอหนึ่งของเกมที่ให้ผ่านเมนู รักษาแผล ตัดเวลาท้องเสียออกไป 8 ชั่วโมง และยังย่นอาการเมา จากการกินอาหารผิดด้วย
  • พยาธิเป็นขั้นต่อไปของอาการท้องเสีย ไม่ใช่ผลข้างเคียงของมัน ทุก 6 ชั่วโมงที่สุนัขท้องเสีย มีโอกาส 10% ที่พยาธิจะเข้าไปอยู่ การรักษาแต่เนิ่น ๆ ด้วยหญ้าจึงตัดขั้นต่อไปนี้ออกได้ พอมีพยาธิ ความหิวจะลดเร็วขึ้น 40% และไม่หายเองเลย: Companion Dogs ยาถ่ายพยาธิ หนึ่งโดสจบ ยาเม็ดใช้เวลา 4 ชั่วโมงกว่าจะออกฤทธิ์ แล้วป้องกันต่ออีก 30 วัน ซึ่งจะไม่มีพยาธิตัวใหม่เข้าไปอยู่ แม้ท้องจะยังเสียอยู่ก็ตาม ให้ก่อนที่สุนัขจะมีพยาธิ ในฐานะการป้องกันก็ได้ ตราบใดที่การป้องกันยังอยู่ สุนัขจะแสดง moodle ถ่ายพยาธิแล้ว พร้อมจำนวนวันที่เหลือ และหน้าข้อมูลก็บอกจำนวนวันเดียวกัน

ไข้หวัด

  • ติดได้สองทาง: สุนัขที่หิวรุนแรง (เกิน 0.8) มีโอกาส 15% ต่อวันที่จะป่วย และสุนัขปกติที่อยู่ห่าง สุนัขเป็นไข้หวัดหนึ่งช่อง มีโอกาส 15% ต่อทุกชั่วโมงที่สัมผัสกัน สุนัขที่ฉีดวัคซีนแล้วไม่ติดและไม่แพร่ต่อ
  • เป็นอยู่ 2 ถึง 4 วันแล้วหายเอง มีไข้ตลอดเวลา: สุนัขดื่มน้ำมากขึ้น 20% เดินช้าลง 20% พลังชีวิตไม่ฟื้น ไม่ผสมพันธุ์ และปฏิเสธการล่าสัตว์กับการป้องกัน ป้ายและ moodle มีไข้ พร้อม moodle ไข้หวัด
  • Companion Dogs วัคซีน ที่ให้กับสุนัขซึ่งเป็นไข้หวัดอยู่แล้ว ตัดการแพร่เชื้อทันทีและรักษาหายใน หนึ่งวัน ส่วนยาปฏิชีวนะย่นไข้หวัดลง 40% เมื่อจบคอร์ส ทั้งของสัตวแพทย์และของคน การพักไม่ช่วย: นาฬิกา ของไข้หวัดเดินเท่ากันทั้งตอนสุนัขอยู่นิ่งและตอนตามคุณไป แต่น้ำช่วย เพราะไข้ทำให้กระหายมากขึ้น

พยาธิหนอนหัวใจ

  • ยุงกัดได้เฉพาะกลางแจ้ง: ทุก 6 ชั่วโมงติดต่อกันที่อยู่นอกหลังคา สุนัขจะสุ่มโอกาส 1.5% ที่จะติด และการเข้าในบ้านจะรีเซ็ตการนับ นี่คือโรคที่หนักที่สุดในม็อด
  • เป็นอยู่ 3 ถึง 6 วันแล้วหายเอง ระหว่างนั้นดึงพลังชีวิตหนึ่งในสี่ของแถบต่อวัน ทำให้มีไข้ ลดความเร็วเดินเหลือ 65% และวิ่งเหลือ 45% และสุนัขจะปฏิเสธการโจมตี การทำท่าทาง การล่าสัตว์ และการป้องกัน มันทิ้งการล่า และการเฝ้าทันทีที่ป่วย moodle พยาธิหนอนหัวใจ
  • Companion Dogs ยาพยาธิหนอนหัวใจ ช่วยให้หายใน 18 ชั่วโมง โดสเดียวกันนั้น ป้องกันต่ออีก 30 วัน และให้กับสุนัขที่ยังปกติดีได้ ซึ่งเป็นวิธีที่ทำกันในชีวิตจริง

ภูมิแพ้ หมัด และเห็บ

  • สุนัขแต่ละตัวอาจมีเนื้อสักตระกูลที่มันแพ้ สุ่มครั้งเดียวตลอดชีวิตของสุนัข: มีโอกาส 5% ที่มันจะเกิดมาแพ้ไก่ วัว ปลา หรือเนื้อชนิดอื่น จากนั้นทุกมื้อของเนื้อชนิดนั้น จะทำให้อาการกำเริบ หน้าข้อมูลบอกว่าเป็นอาหารอะไร
  • อาการกำเริบอยู่ 12 ถึง 24 ชั่วโมง: สุนัขจะเกา เครียด และเดินเหมือนตอนบาดเจ็บ (เดิน -10%, วิ่ง -25%) แล้วหายเอง Companion Dogs ยาแก้แพ้ ตัดเหลือ 6 ชั่วโมงและ ป้องกันต่ออีก 2 วัน ป้ายและ moodle ภูมิแพ้
  • หมัดและเห็บติดตอนประชิดตัว: การกัดที่สุนัขทำได้แต่ละครั้งมีโอกาส 0.2% ที่จะพาตัวใดตัวหนึ่ง กลับมา (มากขึ้นถ้าสุนัขบาดเจ็บหรือเครียด) เป็นเวลา 2 วันที่ตัวมันจะกวนทุกชั่วโมง ทำให้เครียด และมีโอกาส 3% ที่จะกลายเป็นภูมิแพ้ในแต่ละครั้ง ส่วนเห็บเกือบสองเท่าของนั้น หลังจากนั้นมันจะเงียบ แต่ไม่ได้หายไปเอง
  • Companion Dogs ยากำจัดหมัดและเห็บ เคลียร์ทั้งสองอย่างใน 12 ชั่วโมงและป้องกันต่ออีก 30 วัน ป้ายและ moodle หมัด กับ เห็บ

ยา: หาที่ไหนและให้ยังไง

  • มีหกชนิด ทุกชนิดมีหลายโดสต่อกล่อง: ยาปฏิชีวนะได้ 12 โดส ยาถ่ายพยาธิ 8 วัคซีน 6 ยาแก้แพ้ 24 ยากำจัดหมัด 12 และยาพยาธิหนอนหัวใจ 6 การรักษาแต่ละครั้งใช้ไปหนึ่งโดส
  • เจอได้ในตู้ยา ร้านขายยา โรงพยาบาล ชั้นวางของในร้าน คลังทหาร ร้านขายสัตว์เลี้ยง กล่องของใช้สัตว์เลี้ยง ห้องน้ำในบ้าน โรงรถ และฟาร์ม ส่วนที่คลินิกสัตวแพทย์ วัคซีนกับยาพยาธิหนอนหัวใจ ยังเจอได้ในโต๊ะ (4.8%) และในบ้านสุนัขแต่ละหลัง (2.4%)
  • ทั้งหมดให้ผ่านเมนูย่อย รักษาแผล อันเดียวกัน หรือผ่านหัวข้อสุขภาพของหน้าข้อมูล: คลิกขวาที่ อาการ แล้วจะขึ้นว่าทำอะไรได้บ้างกับของที่คุณพกอยู่
  • ยาไม่ได้รักษาหายในอึกเดียว: มันเปิดคอร์สที่เดินไปเป็นชั่วโมง แล้วโรคจะหายตอนจบคอร์ส หน้าข้อมูล จะแสดงบรรทัด กำลังรักษา ระหว่างนั้น และ ป้องกัน พร้อมจำนวนวันที่เหลือ เมื่อยานั้นป้องกันให้ด้วย
  • การปฐมพยาบาลและการเลี้ยงสัตว์ของเจ้าของย่นคอร์สรักษาลง 5% ต่อเลเวลรวมกัน และ ยืดการป้องกันออกไป 2.5% ต่อเลเวล การรักษาสุนัขที่ป่วยให้ค่าประสบการณ์การปฐมพยาบาล ส่วนโดส ป้องกันในสุนัขที่ปกติดีไม่ให้
  • เจ้าของที่นอนหลับอยู่ใกล้ ๆ ทำให้สุนัขที่ปกติดีฟื้นพลังชีวิตเร็วเป็นสองเท่า แต่ไม่ช่วยอะไรกับ สุนัขที่ติดเชื้อ

8. ความต้องการและการดูแล

มีสี่แถบ บวกกับความซื่อสัตย์ ม็อดคุมทั้งหมดด้วยตัวเอง เพราะสุนัขคู่หูเป็นอมตะ และความเป็นอมตะนั้นทำให้ระบบความหิวของเกมหยุดทำงาน

แถบ ขึ้น / ลง จังหวะ เมื่อไรจึงกวนใจ
ความหิว เพิ่มขึ้นตามเวลา จากว่างจนเต็มในราว 3 วัน เกิน 0.6
ความกระหาย เพิ่มขึ้นตามเวลา จากว่างจนเต็มในราว 1.7 วัน เกิน 0.6
พลังชีวิต ลดลงจากการละเลย บาดแผล และโรค เต็มแถบในราว 8 ชั่วโมง เมื่อความหิวหรือความกระหายเกิน 0.8 ต่ำกว่า 30%
ความเครียด คำนวณจากค่าอื่น ไม่มี เกิน 50%
ไม่มีการนอนและไม่มีความสะอาด

ตัวเลือกแซนด์บ็อกซ์ อัตราความหิวและความกระหายน้ำ ปรับสองค่านี้ไปพร้อมกัน ที่ 0 ทั้งคู่หยุดนิ่ง ความซื่อสัตย์ยังลดลงต่อไป มันจึงยังต้องการการดูแลอยู่ดี

ความเครียดมาจากไหน

ความเครียดเพิ่มขึ้นจากความหิว ความกระหาย พลังชีวิตต่ำ ความซื่อสัตย์ต่ำ และทุกครั้งที่แลกหมัดกันในการต่อสู้

ระดับ เริ่มที่
ตื่นเต้น 50%
ตกใจ 80%
กลัว 100%

นอกการต่อสู้ ความเครียดจากการสู้ลดเร็วมาก แถบที่เต็มจะว่างลงในราว 2 ชั่วโมงในเกม การลูบ อาหาร และน้ำ ช่วยเร่งให้ลดเร็วขึ้นอีก

โปรตีน: มันเป็นสัตว์กินเนื้อ

นอกจากความหิวแล้ว ม็อดยังนับชั่วโมงนับจากโปรตีนมื้อล่าสุด เมื่อผ่านไปสามวันในเกมโดยไม่ได้โปรตีน สุนัขจะกลายเป็นอ่อนแรง มี moodle ของตัวเองขึ้นบนหน้าจอคุณ พร้อมบทลงโทษสองข้อ:

  • พลังกัดเหลือครึ่งเดียว สุนัขที่เคยฆ่าซอมบี้ได้ในสี่ครั้ง ต้องใช้ถึงแปดครั้ง
  • โอกาสไม่สนใจคำสั่ง +25% บวกทับโอกาสปกติจากการเชื่อฟัง แม้แต่สุนัขที่การเชื่อฟัง 10 ซึ่งไม่เคยขัดคำสั่ง ก็กลับมาดื้อขณะที่อ่อนแรง

นับเป็นโปรตีน: เนื้อของสัตว์ทุกชนิด สัตว์ปีก สัตว์ป่า ปลาและอาหารทะเล ไข่ ไส้กรอก เบคอน และอาหารสุนัข (ทั้งถุงแบบแห้งและกระป๋องที่เปิดแล้ว) ที่ไม่นับคือผัก ผลไม้ ขนมปัง เส้นพาสตา ผลิตภัณฑ์นม รวมถึงอาหารที่เป็นพิษหรือเน่าเสีย

มื้อยิ่งใหญ่ ยิ่งหักชั่วโมงที่ขาดโปรตีนได้มาก:

คุณให้อะไรไป หักนาฬิกาไปเท่าไร

เนื้อสัตว์เล็ก 54 ชั่วโมง
เบคอน ~42 ชั่วโมง
ไข่ ~25 ชั่วโมง
เบคอนแผ่น ~15 ชั่วโมง
เบคอนสับชิ้นเล็ก ~3 ชั่วโมงครึ่ง

ตัวเลือกแซนด์บ็อกซ์ ชั่วโมงที่อยู่ได้โดยไม่มีโปรตีน ไล่จาก 6 ถึง 168 ชั่วโมงในเกม โดยค่าเริ่มต้นคือ 72 (สามวัน) การเปลี่ยนค่านี้ปรับสเกลของตารางทั้งตาราง

โปรตีนนับได้ทั้งสี่ทาง: จากมือคุณ จากชาม จากคอกสุนัข (สุนัขที่เก็บไว้) และเหยื่อที่มันล่าและกินเอง การป้อนจากมือนับทั้งชิ้น แม้สุนัขจะแทะไปแค่คำเดียว

ชั่วโมงจะเดินก็ต่อเมื่อสุนัขยังมีชีวิตอยู่ในโลก สุนัขที่อยู่ในคอก อยู่ในอ้อมแขน อยู่ในรถ มีเจ้าของออฟไลน์ หรือประจำการดูแลฟาร์ม จะไม่สะสมอะไรเลยขณะที่อยู่ตรงนั้น เหมือนกับที่ความหิวและความกระหายไม่เพิ่มขึ้น

ปิดได้ที่ตัวเลือกแซนด์บ็อกซ์ สุนัขต้องการโปรตีน เมื่อปิดแล้ว เหลือแค่ความหิวกับความกระหายที่มีผล

สุนัขที่กินแต่ผักไม่ตาย แต่กัดได้แค่ครึ่งแรงและไม่ฟังคำสั่ง ถ้าคุณเล่นแบบวางชามไว้ ให้ทิ้งถุงอาหารสุนัขไว้ในชามด้วย

ป้อนอาหาร ป้อนน้ำ และลูบ

คลิกขวาที่สุนัข → ป้อนอาหาร, ป้อนน้ำ หรือ ลูบ

การกระทำ ผลที่ได้ ข้อความ
ป้อนอาหาร ลดความหิว เติมน้ำให้ถ้าไอเทมนั้นฉ่ำ พลังชีวิต +0.10 คลายความเครียด และเพิ่มความซื่อสัตย์ตามสัดส่วนความหิวที่มื้อนั้นดับไป Caramelo พอใจในอาหารของคุณ
ป้อนน้ำ ลดแถบความกระหายลงครึ่งหนึ่ง คลายความเครียด และเพิ่มความซื่อสัตย์ +2 ให้น้ำ Caramelo แล้ว
ลูบ คลายความเครียด และเพิ่มความซื่อสัตย์ +2 ส่วนตัวละครของคุณคลายความเบื่อและความเศร้า ระหว่างคูลดาวน์: Caramelo ของคุณได้รับความรักมากพอแล้วในตอนนี้
  • การป้อนอาหารรับอาหารทุกอย่างที่ยังไม่เน่าและดับความหิวได้ ห้ามเฉพาะรายการอาหารที่เป็นพิษ สำหรับชั่วโมงที่ขาดโปรตีน ชนิดของอาหารมีผล และถูกกินไปแค่คำที่จำเป็นเท่านั้น
  • การป้อนน้ำต้องมีภาชนะบรรจุน้ำอยู่ในช่องเก็บของ (ม็อดค้นในกระเป๋าเป้ให้ด้วย)
  • การลูบมีคูลดาวน์ 90 นาทีในเกม

บันไดของการละเลย

ถ้าคุณปล่อยสุนัขไว้แบบนั้น:

  1. ความหิวและความกระหายเกิน 0.6 moodle หิว / กระหายน้ำ ขึ้นบนหน้าจอคุณ
  2. ความซื่อสัตย์เริ่มลดเร็วขึ้นสามเท่า
  3. เมื่อเกินครึ่งแถบ การฟื้นฟูตามธรรมชาติหยุดลง
  4. เมื่อเกิน 0.8 พลังชีวิตไหลลงในราว 8 ชั่วโมงในเกม: ลดได้ถึง 10% โดยค่าเริ่มต้น และลดถึงศูนย์ เมื่อเปิด โรคและการละเลยอาจถึงตาย
  5. ความซื่อสัตย์ลดต่ำกว่าเกณฑ์ขั้นต่ำ และสุนัขกลายเป็น ไม่เชื่อฟัง
  6. ความเครียดพุ่งขึ้นจนมันตกใจ: เลิกสู้ เลิกเฝ้าระวัง และเลิกทำท่าทาง
  7. เมื่อเปิดตัวเลือกนั้นไว้ พลังชีวิตถึงศูนย์และมันตาย

ความตายเป็นการถาวร Caramelo เสียชีวิตแล้ว กระเป๋าอานและทุกอย่างที่อยู่ข้างในร่วงลงพื้น ถ้าคุณมีสุนัขอีกตัว มันจะกลายเป็นตัวหลักโดยอัตโนมัติ

ความโศกเศร้า

เมื่อสุนัขที่ผูกพันกับคุณตาย ตัวละครเข้าสู่ความโศกเศร้า: moodle โศกเศร้า ขึ้นพร้อมชื่อของมัน และความเศร้าพุ่งขึ้นทีเดียว ไม่มีตัวเลือกให้ปิดเรื่องนี้

9. ความซื่อสัตย์

ความซื่อสัตย์ไล่จาก 0 ถึง 100 และวัดว่าสุนัขไว้ใจคุณมากแค่ไหน

  • ลดลงเอง ราว 12 แต้มต่อวัน และลดเร็วขึ้นสามเท่าถ้ามันหิวหรือกระหายน้ำ
  • ขึ้นได้จากการป้อนอาหาร ป้อนน้ำ (+2) และลูบ (+2) เท่านั้น
  • การป้อนอาหารเป็นทางที่เร็วที่สุด แต่ค่าที่ได้เป็นสัดส่วนกับความหิวที่มื้อนั้นดับไป การป้อนสุนัขที่หิวจัดคืนความซื่อสัตย์ได้หลายสิบแต้มในครั้งเดียว ถ้าความซื่อสัตย์ตกลงมา ให้ปล่อยมันหิวก่อนแล้วค่อยป้อน
  • การกินจากชามไม่เพิ่มความซื่อสัตย์

เกณฑ์ขั้นต่ำของการไม่เชื่อฟัง

เมื่อต่ำกว่าจุดหนึ่ง สุนัขกลายเป็น ไม่เชื่อฟัง และปฏิเสธที่จะตาม สู้ และทำท่าทาง: Caramelo ไม่ซื่อสัตย์กับคุณแล้ว

เกณฑ์นี้ต่ำลงเมื่อการเชื่อฟังสูงขึ้น: เริ่มที่ 30 และลดลง 1.5 ต่อหนึ่งเลเวล แต่ไม่เคยต่ำกว่า 10 สุนัขที่การเชื่อฟัง 10 จะไม่เชื่อฟังก็ต่อเมื่อความซื่อสัตย์ต่ำกว่า 15

10. ชาม: อาหารและน้ำโดยไม่ต้องมีคุณ

มีชามแล้วสุนัขตัวหลักกินและดื่มได้เอง

มีแต่สุนัขตัวหลักที่รู้สึกหิวและกระหาย ดูที่ หลายตัวพร้อมกัน

วิธีใช้

  1. หาชามมาให้ได้ (คราฟต์หรือเก็บจากของในโลก ดู ไอเทมของม็อด)
  2. ในช่องเก็บของ คลิกขวา → วางชามอาหารลง จะเปิดเคอร์เซอร์สำหรับวางอิสระขึ้นมา และปุ่ม R หมุนชาม
  3. คลิกขวาที่ชาม → เอาอาหารใส่ในชาม หรือ เอาน้ำใส่ในชามข้าว

ชามเก็บอาหารหรือน้ำ ไม่เคยเก็บทั้งสองอย่างพร้อมกัน ถ้าจะสลับ ให้ใช้ เทชามข้าวทิ้ง

โมเดลแสดงสิ่งที่อยู่ข้างใน: สีเทาคือว่าง สีน้ำตาลคือมีอาหารเม็ด สีฟ้าคือมีน้ำ

อะไรใช้เป็นอาหารในชามได้บ้าง

อาหารเกือบทุกอย่างที่ดับความหิวได้และยังไม่เสีย: เนื้อ อาหารกระป๋อง อาหารปรุงสุก ผัก ผลไม้ ไข่ อาหารสุนัข รวมถึงหญ้าและฟางด้วย

ที่ไม่รวมคือรายการของที่ทำร้ายสุนัข ซึ่งขึ้นเป็นสีแดงในเมนู

อาหารสุนัขกระป๋องที่ยังไม่เปิดจะไม่ขึ้นในรายการ ให้เปิดกระป๋องก่อน

ถ้าไอเทมใหญ่กว่าที่ว่างที่เหลือ ชามเต็มถึงขอบแล้วคืนส่วนที่เหลือให้คุณ ชามที่มีอยู่ 80 แต้ม เมื่อใส่ถุงอาหารสุนัขลงไปจะเต็ม 100 แล้วถุงนั้นกลับเข้าช่องเก็บของคุณโดยเหลือค่า 40 ข้อความ ในชามไม่มีพื้นที่สำหรับใส่อาหารแล้ว ขึ้นก็ต่อเมื่อชามเต็มจริง ๆ เท่านั้น

สุนัขใช้ชามอย่างไร

  • มันไปเองเมื่อความหิวหรือความกระหายถึง 0.5 (ปรับได้ทีละตัวละครที่สไลเดอร์ กินอัตโนมัติเมื่อหิวหรือกระหาย ในแท็บตั้งค่า)
  • มันมองหาชามในรัศมี 16 ช่อง ใช้ได้ทั้งชามของม็อด และรางอาหารของตัวเกมเอง
  • การไปแต่ละครั้งดับแถบไปครึ่งหนึ่ง มันใช้เวลากินราว 3 นาทีในเกม
  • ขณะกำลังเดินไปที่ชามหรือกำลังกิน มันไม่สนใจซอมบี้และทุกอย่างรอบตัว มีแต่คำสั่งของคุณ ที่ขัดจังหวะได้ สุนัขที่ตกใจเพราะความหิวจะหายตกใจเมื่อได้กิน

เหนือหัวของมันขึ้นว่า กำลังไปกินข้าว, กำลังกินข้าว, กำลังไปดื่มน้ำ, กำลังดื่มน้ำ

การกินจากชามไม่ให้ความซื่อสัตย์

ชามใช้เป็นแหล่งน้ำดื่มของคุณไม่ได้ และฝนก็ไม่เติมน้ำให้ คุณเติมที่อ่างล้างจานหรือก๊อกน้ำก็ไม่ได้เหมือนกัน: ตัวเลือกเติมน้ำที่เกมมีให้ตรงนั้นใช้กับชามนี้ไม่ได้ น้ำเข้าได้ทางเดียวคือ เอาน้ำใส่ในชามข้าว โดยมีภาชนะที่มีน้ำอยู่ในช่องเก็บของ

11. ทักษะ: ห้าทักษะของสุนัข

สุนัขทุกตัวมีห้าทักษะ ไล่จาก 0 ถึง 10 และขึ้นได้ด้วยการใช้งาน

ทักษะ ขึ้นอย่างไร ช่วยเรื่องอะไร
การดมกลิ่น ทุกครั้งที่การเฝ้าระวังเจอเป้าหมายใหม่ และการใช้ท่าดมหาไอเทม ระยะเฝ้าระวัง (18 → 27 ช่อง) และระยะของกลิ่นที่จำไว้
การต่อสู้ ทุกครั้งที่ฟาดและทุกครั้งที่ฆ่าได้ ความเสียหาย โอกาสทำให้ล้ม (10% → 50%) และความทนต่อความเครียดจากการสู้
การเชื่อฟัง ทุกคำสั่งที่ทำตาม (มีคูลดาวน์) ขึ้นเร็วกว่า 4 เท่าเมื่อยังต่ำกว่าเลเวล 3 เกณฑ์ความซื่อสัตย์ต่ำลง ท่าทางทั้งสี่ และโอกาสขัดคำสั่งน้อยลง
การล่าสัตว์ ชี้เป้าสัตว์ป่า ดมกลิ่น ล่าสำเร็จ และตอนที่คุณฆ่าสัตว์ป่าใกล้ ๆ มัน เลเวล 3: ล่าสัตว์เล็กได้ เลเวล 6: สู้กับกวางและคาบเหยื่อกลับมา ทั้งยังขยายรัศมีการหาของของคุณ
การต้อนฝูงสัตว์ ดูแลคอกสัตว์ กันไม่ให้ฝูงตื่นตระหนก ไล่ซอมบี้ออกจากคอก ความแรงของออร่าที่ทำให้ฝูงสัตว์สงบ

ส่วนคุณลักษณะ (ความแข็งแกร่ง ความก้าวร้าว ความอดทน) เป็นคนละเรื่อง: สุ่มตอนที่คุณทำให้สุนัขเชื่อง แล้วอยู่คงที่ตลอดไป

คุณลักษณะ หน้าที่ของแต่ละตัว และช่วงค่าของแต่ละสายพันธุ์ อยู่ใน คู่มือสายพันธุ์

ตัวเลือกแซนด์บ็อกซ์ ตัวคูณค่าประสบการณ์ทักษะ คุมความเร็วของทั้งหมดนี้

ค่าเริ่มต้นของตัวเลือกนี้ในไฟล์คือ 0.5 ซึ่งเป็นครึ่งหนึ่งของความเร็ว ถึงแม้ข้อความช่วยเหลือจะบอกว่า 1.0 คือปกติ ถ้าสุนัขดูเหมือนเรียนรู้ช้า ให้ดันขึ้นเป็น 1.0 หรือมากกว่า

การขัดคำสั่ง

สุนัขที่ยังไม่ได้ฝึกบางครั้งไม่สนใจคำสั่ง: Caramelo Rex วอกแวกและไม่สนใจคุณ

  • โอกาสเริ่มที่ 30% เมื่อการเชื่อฟังอยู่ที่ 0 และลงไปถึง 0% เมื่อการเชื่อฟังอยู่ที่ 10
  • สุนัขที่อ่อนแรง บวกเพิ่มอีก +25% จากนั้น
  • การสั่งซ้ำทันทีได้ผลเสมอ
  • คำสั่งที่ถูกเมินก็ยังให้ XP การเชื่อฟังเหมือนกัน
  • ใช้กับคำสั่งตรงเท่านั้น: ตามมา อยู่นิ่ง ป้องกัน มานี่ โจมตี และท่าทาง ไม่มีผลกับการป้อนอาหาร ป้อนน้ำ ลูบ กระเป๋าอาน การเรียกกลับมา หรือสวิตช์พฤติกรรมต่าง ๆ (การเฝ้าระวัง การป้องกันอัตโนมัติ การล่าสัตว์ การดูแลฟาร์ม)

12. ท่าทางจากการเชื่อฟัง

มีสี่ท่า ปลดล็อกตามระดับการเชื่อฟัง ทุกท่าขึ้นในเมนูตั้งแต่ต้น ท่าที่ยังล็อกอยู่เป็นสีแดง พร้อมบอกระดับที่ยังขาด: ปลดล็อกที่ระดับการเชื่อฟัง 3 (ปัจจุบัน: 1)

ไปยังจุดที่กำหนด (การเชื่อฟัง 1)

เปิดเคอร์เซอร์บนพื้น: สีเขียวคือไปได้ สีแดงคือไปไม่ได้ คลิกซ้ายเพื่อเลือกจุด คลิกขวาเพื่อยกเลิก

  • ระยะไกลสุด 30 ช่อง นับจากตัวคุณ ไม่ใช่จากตัวสุนัข
  • มันเดินไปที่นั่นแล้วยึดจุดนั้นไว้ (เข้าโหมดอยู่นิ่งเมื่อไปถึง)
  • คำสั่งใหม่ใด ๆ ยกเลิกการเดินทางนี้

ล่อความสนใจ (การเชื่อฟัง 3)

สุนัขเห่าดังในรัศมี 24 ช่อง แล้วฝูงซอมบี้จะมุ่งไปที่มัน จากนั้นมันถอยกลับมาหาคุณ

  • ท่านี้เห่าแม้จะปิดตัวเลือก เสียงสุนัขจะดึงดูดซอมบี้ ไว้
  • มีค่าใช้จ่ายเป็นความเครียด
  • ป้ายสีแดงเหนือหัวมัน: กำลังล่อซอมบี้
  • คูลดาวน์ 10 นาทีในเกม

ใช้เพื่อเปิดทางผ่าน

ดมหาไอเทม (การเชื่อฟัง 5)

ถือไอเทมไว้ในมือแล้วใช้ท่านี้ สุนัขจะจำกลิ่นของไอเทมชนิดนั้นไว้: Caramelo จำกลิ่นของค้อนหงอนได้แล้ว

จากนั้นมันจะกวาดพื้นที่รอบตัวอยู่เบื้องหลัง (12 ช่อง ไปได้ถึง 20 ช่องเมื่อการดมกลิ่นเต็มระดับ) เพื่อหาไอเทมชิ้นนั้นในตู้และบนพื้น เมื่อเจอ:

  1. มันเห่า
  2. มันเดินไปที่นั่นแล้วชี้
  3. ไอเทมนั้นถูกไฮไลต์สีเขียวในโลก

ข้อความ: Caramelo ได้กลิ่นค้อนหงอนอยู่ใกล้ๆ และ Caramelo ชี้ไปที่ค้อนหงอน

สุนัขเก็บกลิ่นไว้ได้กลิ่นเดียว ถ้าจะยกเลิก ให้ใช้ หยุดตามหาค้อนหงอน (พร้อมชื่อไอเทมที่มันจำไว้) การยกเลิกได้ผลเสมอ

ถ้าไม่มีไอเทมในมือ: ถือสิ่งของที่อยากให้สุนัขดมไว้ในมือ

ตามหาไอเทมขณะคุณนอนหลับ (การเชื่อฟัง 10)

สุนัขต้องใส่กระเป๋าอานไว้

ถือไอเทมไว้ในมือแล้วสั่งไว้: Caramelo จะตามหาค้อนหงอนขณะคุณนอนหลับ จะมีป้ายถาวร ติดอยู่เหนือหัวมัน: กำลังหา: ค้อนหงอน

  • วันละครั้งในเกม ทำงานทันทีหลังคุณตื่นนอน โดยมีสุนัขอยู่ใกล้ ๆ
  • โอกาสสำเร็จขึ้นกับว่าไอเทมนั้นหายากแค่ไหน และไม่เคยถึง 100% ไอเทมที่ธรรมดาที่สุดในเกม ได้สูงสุด 50% ต่อคืน (รอราว 2 วันโดยเฉลี่ย) ไอเทมที่ไม่ค่อยพบอย่างขวานอยู่ราว 15% ส่วนของหายากอย่างคาตานะอยู่ราว 2%
  • ถ้าสำเร็จ: Caramelo นำค้อนหงอนกลับมาขณะคุณนอนหลับ ไอเทมโผล่อยู่ในกระเป๋าอาน พร้อมป้ายสีเขียว นำกลับมา: ค้อนหงอน
  • ถ้าไม่สำเร็จ: Caramelo กลับมาโดยไม่มีค้อนหงอน และป้ายสีแดง กลับมามือเปล่า

มีสองอย่างที่บล็อกตอนสั่ง:

  • ไอเทมหนักเกินไป: Caramelo ไม่สามารถขนทั่งตีเหล็กได้
  • ไอเทมที่ไม่มีอยู่ในตารางของดรอปของเกม: Caramelo ไม่รู้ว่าจะหาสิ่งนั้นได้ที่ไหน

ที่ระดับ 0, 1 และ 2 มันได้แค่ชี้และไม่แตะตัวเหยื่อ มันเห่าหนึ่งครั้ง วิ่งเหยาะไปใกล้ ๆ ตัวสัตว์ หยุด ทำท่าดมกลิ่น แล้วยืนชี้อยู่ตรงนั้นสองสามนาที จากนั้นก็เลิกแล้วกลับมา ข้อความเตือน: สุนัขของคุณเจอสัตว์ป่าที่อยู่ใกล้ ๆ

นี่คือวิธีที่มันฝึกการล่าสัตว์ในช่วงแรก

ที่ระดับ 3 มันเริ่มฆ่าสัตว์เล็กได้

  • ถ้ามันหิว มันจะกินเหยื่อ คุณไม่ได้อะไรเลย แต่มันดับความหิวได้ และเพราะเป็นสัตว์ทั้งตัวที่เนื้อยังสด นั่นจึงล้างนาฬิกาโปรตีนให้เป็นศูนย์
  • ถ้ามันไม่หิว มันจะฆ่าโดยเครดิตให้คุณ และทิ้งซากที่ชำแหละได้ไว้บนพื้นตรงจุดที่การล่าจบลง มันบอกคุณว่า: สุนัขของคุณล่าสัตว์ป่าได้แล้ว!

ที่ระดับ 6 มันเริ่มเอาเหยื่อที่ล่าได้มาส่งถึงตัวคุณ พร้อมป้าย กำลังเอาเหยื่อกลับมา และข้อความ สุนัขของคุณลากสัตว์ที่ล่าได้มาให้แล้ว

กับกวางกฎต่างออกไป: กวางมันไม่ลากมาให้ ไม่ว่าระดับไหนและสายพันธุ์ไหน มันจะกัดกวางจนเกือบตาย แล้วคาบเหยื่อไว้รอให้คุณลงมือจบ: สุนัขของคุณทำให้กวางบาดเจ็บแล้ว จัดการมันซะ! พร้อมป้าย กำลังคาบเหยื่อ ถ้าคุณไม่ไปภายใน 20 นาทีในเกม มันจะจบเองและคุณยังได้เครดิตอยู่ดี ถ้ากวางหนีไป มันจะตามรอย: สุนัขของคุณกำลังค้นหาสัตว์ที่กำลังบาดเจ็บ

ลาบราดอร์ส่งเหยื่อให้ตั้งแต่ระดับ 3 และยื้อนานกว่าก่อนจะทิ้งไว้ระหว่างทาง รายละเอียดอยู่ในคู่มือสายพันธุ์

กวางสู้กลับ: ราวหนึ่งในสี่ของการพุ่งเข้าใส่ทำให้สุนัขบาดเจ็บและความเครียดของมันสูงขึ้น แต่ไม่ถึงกับทำให้ตาย

ข้อจำกัด

  • สัตว์ป่าอยู่ในป่าและในชนบท ไม่ใช่ในเมือง
  • ใช้ได้เฉพาะในโหมดตามมาเท่านั้น
  • รัศมี 32 ช่อง ถ้ามันห่างออกไปเกินนั้น มันจะเลิก กลับมา และพัก 20 นาทีในเกม (ป้าย การล่า: กำลังพัก)
  • ไม่ล่าระหว่างการเร่งเวลา ตอนคุณนอนหลับ ตอนอยู่ในรถ หรือในช่วง 5 นาทีหลังจากที่คุณสั่งอะไรไป
  • ถ้ามันกำลังสู้กับซอมบี้อยู่แล้ว มันจะไม่คิดออกล่า ส่วนซอมบี้ที่เดินผ่านมาใกล้ ๆ ไม่ดึงสุนัข ออกจากการล่า มันจะทิ้งเหยื่อถ้าคุณเข้าสู่การต่อสู้หรือการป้องกันอัตโนมัติทำงาน คำสั่งใด ๆ ของคุณยกเลิกการล่าทันที
  • การล่าทำให้มันหิว
  • เสียงเห่าระหว่างไล่ล่าดึงดูดซอมบี้ และปิดไม่ได้

โบนัสการหาของ

โบนัสทั้งสองจะมีก็ต่อเมื่อเปิดโหมดค้นหาของเกมไว้

a) มันหาจุดเก็บของให้ (เฉพาะในโหมดการล่าสัตว์) เมื่อไม่มีเหยื่ออยู่ใกล้ สุนัขจะมองหาจุดหาของ ประเภทสัตว์ เดินไปที่นั่น เห่า แล้วชี้ตำแหน่ง: สุนัขของคุณเจออะไรบางอย่าง! เปิดโหมดค้นหาเพื่อดู ป้าย: กำลังดมกลิ่นเพื่อหาของ

คนที่เก็บไอเทมคือคุณ

b) มันเพิ่มระยะการค้นหาของคุณ (ทุกสายพันธุ์ และตลอดเวลา) แค่มีสุนัขของคุณอยู่ใกล้ ยังภักดี และไม่หิวหรือกระหายมากเกินไป:

  • +6 ช่องเมื่อการล่าสัตว์อยู่ที่ 0 ไปได้ถึง +12 ช่องเมื่อการล่าสัตว์อยู่ที่ 10
  • หมวดสัตว์ แมลง รอยเท้า และซาก หาเจอง่ายขึ้นมาก

Golden Retriever บวกเพิ่มอีก 4 ช่องจากนั้น

14. การดูแลปศุสัตว์

ในโหมดนี้สุนัขจะอยู่ในคอกและดูแลฝูงสัตว์ด้วยตัวเอง

มอบหมายอย่างไร

  1. สร้างโซนปศุสัตว์ที่กำหนดไว้ (คอกของตัวเกมเอง)
  2. พาสุนัขเข้าไปข้างใน
  3. คลิกขวา → ให้ดูแลปศุสัตว์ที่นี่
  4. ยืนยัน ม็อดจะเตือนว่าสุนัขจะเลิกเป็นตัวหลักและจะไม่ตามคุณอีก

ถ้าไม่มีคอก: Caramelo Rex ต้องมีคอกสัตว์ที่กำหนดไว้ที่นี่จึงจะดูแลปศุสัตว์ได้

มันทำอะไรอยู่ตรงนั้น

  • ลาดตระเวนรอบคอก
  • ทำให้ฝูงสัตว์สงบ ซึ่งเป็นงานหลักของมัน: กดความเครียดไว้ใต้จุดวิกฤต สัตว์ที่เครียดไม่ให้นมไม่ให้ขน แท้งลูก และแตกฝูงเมื่อมีซอมบี้โผล่มา
  • จัดการซอมบี้อย่างเงียบ ๆ ในรัศมี 12 ช่อง
  • ทำงานต่อแม้คุณจะอยู่อีกฟากของแผนที่

ข้อความเตือน: Caramelo Rex รู้สึกได้ว่ามีซอมบี้อยู่ใกล้คอก! และ ฝูงสัตว์ของ Caramelo Rex กำลังเครียด! ป้ายเหนือหัว: กำลังดูแลปศุสัตว์

กฎสำคัญ

  • ขณะรับหน้าที่อยู่ ความหิว ความกระหาย และการเสียความซื่อสัตย์ จะถูกแช่แข็งไว้
  • มันอยู่นอกทุกอย่างที่เหลือ: ไม่สู้ให้คุณ ไม่ล่าสัตว์ ไม่เฝ้าระวัง และไม่ใช้ชาม
  • สุนัขที่ไม่ได้ฝึก ไม่ภักดี หรือกำลังตกใจ จะทำให้ฝูงสัตว์เครียดแทนที่จะสงบ
  • การเลือกสุนัขอีกครั้งยกเลิกโหมดนี้

Border Collie เรียนรู้การต้อนฝูงสัตว์เร็วกว่าสายพันธุ์อื่นสองเท่า แต่ทุกสายพันธุ์ ทำงานนี้ได้

15. กระเป๋าอาน: สุนัขในฐานะสัตว์บรรทุก

ใส่อย่างไร

  1. มี กระเป๋าอานคู่หู อยู่ในช่องเก็บของ
  2. คลิกขวาที่สุนัข → ใส่กระเป๋าอาน ใส่กระเป๋าอานแล้ว
  3. ถ้าจะเปิด: เปิดกระเป๋าอาน (หรือช่องในเมนูวงล้อ หรือปุ่มในแท็บคำสั่ง)
  4. ถ้าจะถอด: ถอดกระเป๋าอานออก กระเป๋าอานจะร่วงลงพื้นพร้อมของที่อยู่ข้างใน

มันบรรทุกได้เท่าไร

ความจุมาจากค่าพื้นฐานคงที่บวกกับยีนความแข็งแกร่งของสุนัข ด้วยค่าเริ่มต้น:

สายพันธุ์ น้ำหนักที่บรรทุกได้
ปั๊ก 2 ถึง 3
Caramelo 4 ถึง 5
Golden Retriever 6 ถึง 7
German Shepherd, Border Collie, ร็อตไวเลอร์, โดเบอร์แมน, ลาบราดอร์, มาลินอยส์ 6 ถึง 8
Husky 13 ถึง 16

Husky กับปั๊กเป็นสองตัวที่มีโบนัสสายพันธุ์ในกระเป๋าอาน: Husky บรรทุกได้มากกว่า 50% ส่วนปั๊ก บรรทุกได้น้อยกว่า 40% สุนัขสองตัวในสายพันธุ์เดียวกันบรรทุกได้ไม่เท่ากันก็ได้

เซิร์ฟเวอร์ปรับสเกลทั้งหมดนี้ได้ด้วยตัวเลือกแซนด์บ็อกซ์ ตัวคูณกระเป๋าอาน ที่ 0 กระเป๋าอานจะเหลือแค่เครื่องประดับ

เก็บอะไรได้บ้าง

เกือบทุกอย่าง ขีดจำกัดอยู่ที่น้ำหนัก ไม่ใช่จำนวนชิ้น ข้อยกเว้นคือ:

  • กระเป๋าอานอีกใบ
  • ไอเทมที่สวมอยู่ (เสื้อผ้าที่ใส่ อาวุธในมือ)
  • กระเป๋าเป้และกระเป๋าต่าง ๆ ให้เก็บของที่อยู่ข้างในแทน ไม่ใช่ตัวกระเป๋า

ถ้าคุณเก็บแผนที่ที่ขีดเขียนไว้ เครื่องหมายจะหายไป: เครื่องหมายบนแผนที่จะไม่ถูกเก็บไว้ในกระเป๋าอาน

หน้าต่าง

รายการสองฝั่งวางเคียงกัน: ช่องเก็บของของคุณ อยู่ซ้าย (คลิกเพื่อฝากลงไป) และกระเป๋าอานอยู่ขวา (คลิกเพื่อเอาออกมา) ที่ด้านล่าง: ที่เก็บของ: 7/12

หาได้ที่ไหน

คราฟต์: เศษหนัง 2 ชิ้น + เข็ม + ด้าย (เข็มกับด้ายไม่ถูกใช้หมดไป) ใช้เข็มเย็บผ้าแบบไหนก็ได้ (แบบธรรมดา แบบกระดูก แบบทองเหลือง หรือแบบตีขึ้นรูป) และด้ายแบบไหนก็ได้ (ธรรมดา อะรามิด หรือเอ็นสัตว์) อยู่ในหมวดการตัดเย็บ ต้องมีงานตัดเย็บระดับ 1 และให้ XP งานตัดเย็บ 15 หน่วย

ของที่เก็บได้: ร้านขายสัตว์เลี้ยง กล่องของใช้สัตว์เลี้ยง ร้านอุปกรณ์แคมป์ ตู้ของนักล่าสัตว์ ชุดยังชีพ กล่องเครื่องมือในโรงรถ และลังในฟาร์ม

ถ้าสุนัขตายหรือถูกปล่อย กระเป๋าอานและของทั้งหมดจะร่วงลงพื้นตรงจุดที่มันอยู่

16. การผสมพันธุ์และลูกสุนัข

ไม่มีปุ่ม "ผสมพันธุ์"

การผสมพันธุ์เป็นแบบเฉื่อย: คุณจัดเงื่อนไขให้ครบแล้วรอ

ทุกชั่วโมงในเกม ตัวเมียที่เข้าเงื่อนไขซึ่งมีตัวผู้ที่เข้าเงื่อนไขอยู่ใกล้ จะมีโอกาสตั้งท้อง ค่าเริ่มต้นคือ 5% ต่อวัน (ตัวเลือกแซนด์บ็อกซ์ โอกาสผสมพันธุ์ต่อวัน)

เงื่อนไข

บังคับทุกข้อ และบังคับกับสุนัขทั้งสองตัว:

  1. ทั้งคู่เป็นสปีชีส์เดียวกัน: สุนัขกับสุนัข แมวกับแมว
  2. ทั้งคู่เป็นคู่หูของเจ้าของคนเดียวกัน
  3. ตัวผู้หนึ่งตัวและตัวเมียหนึ่งตัว โตเต็มวัยทั้งคู่
  4. ทั้งคู่ไม่ได้เปิด ห้ามผสมพันธุ์ ไว้
  5. อยู่ชั้นเดียวกัน และห่างกันไม่เกิน 40 ช่อง
  6. ทั้งคู่ไม่บาดเจ็บหนักและไม่ได้กินของเป็นพิษ
  7. ทั้งคู่ไม่มีความหิวหรือความกระหายอยู่ในแดนแดง
  8. ตัวเมียไม่ได้ตั้งท้อง และไม่ได้อยู่ในช่วงพัก 7 วันหลังคลอด
  9. ยังมีช่องว่างเหลือในลิมิตจำนวนสุนัข
  10. พื้นที่นั้นถูกโหลดอยู่ใกล้ตัวคุณ

พิธีการและการตั้งท้อง

ตัวเมียเดินไปหาตัวผู้ (Caramelo Rex กำลังไปหาคู่ผสมพันธุ์) แล้วตั้งท้องเมื่อไปถึงใกล้ ๆ: Caramelo Rex ตั้งท้องแล้ว

  • การตั้งท้องกินเวลา 4 วันในเกมโดยค่าเริ่มต้น
  • นาฬิกาเดินต่อแม้แม่สุนัขจะอยู่ไกลหรือคุณจะออฟไลน์
  • เหนือหัวมันและในเมนูจะขึ้น ตั้งท้อง และช่วงท้ายคือ ใกล้คลอด เป็นสีชมพู สองป้ายนี้ ขึ้นแม้จะปิดข้อความสถานะไว้

ถ้าเซิร์ฟเวอร์ตั้งลิมิตจำนวนสุนัขไว้และไม่มีช่องว่างเหลือ ครอกจะถูกตัดให้พอดีกับที่เหลือ และการตั้งท้องก็จบลงเหมือนเดิม ค่าเริ่มต้นคือไม่มีลิมิต

  • เชื้อสายคือค่าเฉลี่ยของพ่อแม่ Caramelo กับ German Shepherd ได้ 50/50 พันธุ์ผสมตัวนั้นกับ German Shepherd แท้ได้ 25/75
  • หน้าตาสุ่มโดยถ่วงน้ำหนักตามเชื้อสาย ลูกที่เป็น German Shepherd 75% น่าจะออกมาหน้าเหมือน German Shepherd
  • ยีนอยู่ตรงกลางระหว่างพ่อกับแม่ โดยแกว่งได้ราวบวกลบ 6% การผสมสุนัขสองตัวที่แข็งแรงที่สุดที่คุณมี แล้วทำซ้ำในทุกรุ่น จะดันค่าเฉลี่ยของเชื้อสายให้สูงขึ้นทีละน้อย
  • สุนัขที่มีมากกว่าหนึ่งสายพันธุ์จะขึ้นว่า พันธุ์ผสม และหน้าต่างจะแสดงสัดส่วน (50% Husky, 50% German Shepherd)
  • ประวัติสายพันธุ์ถูกบันทึกไว้: รุ่น ชื่อ และสายพันธุ์ของพ่อและแม่

17. สุนัขหลายตัวพร้อมกัน

คุณมีสุนัขได้หลายตัว แต่ออกไปกับคุณได้ทีละตัวเท่านั้น คือสุนัข ตัวหลัก ตัวที่เหลือ จะรออยู่เฉย ๆ

เรื่องนี้น่าจะเปลี่ยนในเวอร์ชันต่อ ๆ ไป

สุนัขตัวรองจะถูกหยุดไว้:

สุนัขตัวหลัก สุนัขตัวรอง
ตามคุณไป ใช่ ไม่ อยู่นิ่งตรงที่มันอยู่
รู้สึกหิวและกระหาย ใช่ ไม่ และไม่สะสมไว้ทีหลัง
กินจากชาม ใช่ ไม่ และไม่จำเป็นต้องกิน
เสียความซื่อสัตย์เอง ใช่ ไม่
สู้ เฝ้าระวัง ล่าสัตว์ ใช่ ไม่
รับการลูบ (และได้ความซื่อสัตย์) ใช่ ใช่
ผสมพันธุ์และมีลูกได้ ใช่ ใช่
นับเข้า moodle และโบนัสการค้นหา ใช่ ใช่ ถ้าอยู่ใกล้

ถ้าจะสลับ ให้คลิกขวาที่สุนัข → เลือก เมนูของสุนัขตัวรอง จะแสดงเฉพาะสิ่งที่ใช้กับมันได้เท่านั้น

แท็บ "คู่หูของฉัน": ทะเบียน

แสดงสุนัขทุกตัวที่ผูกพันกับคุณ พร้อมรูป ชื่อ สายพันธุ์ เพศ ทักษะ และสถานะปัจจุบัน:

สถานะ หมายความว่าอะไร
ตัวหลัก เป็นสุนัขตัวที่คุณกำลังใช้อยู่
อยู่ใกล้ๆ ถูกโหลดอยู่ใกล้ตัวคุณ
อยู่ในอ้อมแขน คุณกำลังอุ้มมันอยู่
อยู่ในรถยนต์ เก็บไว้ในรถ
อยู่ไกล ผูกพันอยู่ แต่อยู่นอกระยะ จะขึ้นว่า พบล่าสุด X ชม. ที่แล้ว
หายไป หายไปแล้ว ใช้ เรียกกลับมา จากตรงนี้
ยังไม่มีข้อมูล คุณยังไม่เคยเข้าไปใกล้มันเลยหลังผูกพันกับมัน

สามปุ่มต่อสุนัขหนึ่งตัว: เรียกกลับมา | สถานะ | เลือก

เรียกกลับมา กับสุนัขที่อยู่ใกล้คือการเทเลพอร์ตธรรมดา ส่วนกับสุนัขที่อยู่ไกล มันจะขอคำยืนยัน (เรียก Caramelo Rex กลับมาจากที่ไกลหรือไม่? เสียงผิวปากดังจะดึงดูดซอมบี้) แล้วทำให้สุนัขโผล่กลับมา พร้อมทักษะ ยีน ชื่อ และกระเป๋าอาน

สุนัขแต่ละตัวมีคูลดาวน์ 2 ชั่วโมงในเกม ถ้ายังอยู่ในช่วงนั้น: เพิ่งเรียก Caramelo Rex ไป รอสักครู่ก่อนเรียกอีกครั้ง

เมื่อสุนัขหายไป ม็อดจะเตือนว่า: Caramelo Rex หายไป! เปิด คู่หูของฉัน (ปุ่มอุ้งเท้า) เพื่อเรียกน้องกลับมา

18. หน้าต่างของสุนัข

เปิดได้สี่ทาง: ปุ่มรูปอุ้งเท้าที่อยู่ใต้แผงมือของคุณ ปุ่มลัด สถานะ ตัวเลือก สถานะ ในเมนูคลิกขวา หรือปุ่มในแท็บ คู่หูของฉัน

หน้าต่างนี้ปรับขนาดได้และจำตำแหน่งที่คุณวางไว้ ด้านบนเป็นภาพสุนัข 3 มิติที่ขยับอยู่จริง พร้อมชื่อ ของมัน เมื่ออยู่ในรถจะมีแถบ อยู่ในรถยนต์ ขึ้นมา

แท็บ "ทักษะและสถานะ"

  • ความซื่อสัตย์ พร้อมแถบวัด
  • ความต้องการ: ความหิว ความกระหาย พลังชีวิต ความเครียด
  • ทักษะ: ดมกลิ่น การต่อสู้ เชื่อฟัง การล่าสัตว์ ต้อนฝูงสัตว์ แต่ละอย่างมีแถบความคืบหน้าและ เลเวล X
  • คุณลักษณะ: ความแข็งแกร่ง ความก้าวร้าว ความอดทน แสดงเป็น ต่ำ / กลาง / สูง
  • สปีชีส์: สุนัขหรือแมว ตัวเล็กของแมวจะขึ้นว่า ลูกแมว
  • สายพันธุ์: ชื่อ อายุ (โตเต็มวัย หรือ ลูกสุนัข) และ (พันธุ์ผสม) เมื่อเข้าข่าย พร้อมคำอธิบาย สายพันธุ์เมื่อชี้เมาส์ค้าง
  • สังหาร: สุนัขฆ่าซอมบี้ไปกี่ตัว และล่าสัตว์ป่าไปกี่ตัว

ทุกอย่างในแท็บนี้มีคำอธิบายเมื่อชี้เมาส์ค้าง

แท็บ "คำสั่ง"

  • โหมด: ตามมา | อยู่นิ่ง | ป้องกัน
  • ป้องกันอันตราย: ระวังภัยขั้นสุด | ส่งเสียงเบาๆ | ระวังภัยแบบเงียบ
  • ป้องกันอัตโนมัติ (เปิด/ปิด)
  • การล่าสัตว์ (เปิด/ปิด)
  • ระยะการตาม: แถบเลื่อนจาก 2 ถึง 8 ช่อง ทีละครึ่งช่อง พร้อมตัวเลขกำกับอยู่ข้าง ๆ
  • ให้ดูแลปศุสัตว์ที่นี่
  • ท่าทาง: ปุ่มสี่ปุ่ม (ปุ่มที่ล็อกอยู่จะกดไม่ได้ และบอกเหตุผลเมื่อชี้เมาส์ค้าง)
  • เปิดกระเป๋าอาน
  • การกระทำ: เรียกกลับมา | เปลี่ยนชื่อ | ปล่อยกลับสู่ธรรมชาติ

เมื่ออยู่ในรถ ทุกอย่างที่ต้องให้สุนัขอยู่ในโลกจะกดไม่ได้ (ใช้ไม่ได้ขณะที่กำลังขับรถอยู่ , คู่หูกำลังอยู่ในรถกับคุณ) และแถวการกระทำจะเปลี่ยนเป็น ป้อนอาหาร | เปลี่ยนชื่อ | ป้อนน้ำ

แท็บ "คู่หูของฉัน"

ดูที่ สุนัขหลายตัวพร้อมกัน

แท็บ "ตั้งค่า"

ตัวเลือกเหล่านี้เป็นของผู้เล่นแต่ละคน และไม่กระทบใครอีกบนเซิร์ฟเวอร์:

  • หน้าต่าง: ข้อความสถานะ: เปิด/ปิด (ข้อความลอยเหนือหัวสุนัข) รูปภาพของอารมณ์: เปิด/ปิด (moodle ของสุนัข) และ ชื่อสัตว์เลี้ยง: เปิด/ปิด (ชื่อเหนือหัวสุนัข และ เจ้าของ: ชื่อผู้เล่น บนสุนัขของคนอื่น)
  • เสียง: ความดังของเสียงหลัก ปิดเสียง และแถบเลื่อนแยกของ เสียงเห่า เอฟเฟกต์ และ เสียงรอบข้าง
  • กินอาหารอัตโนมัติ: แถบเลื่อน กินอัตโนมัติเมื่อหิวหรือกระหาย
  • ปรับแต่งปุ่ม: ทั้ง 14 การกระทำ พร้อม เปลี่ยนปุ่ม และ ล้างปุ่ม
ถ้าเสียงเห่ารบกวน แถบเลื่อน เสียงเห่า จะลดเฉพาะเสียงนั้น โดยไม่ปิดกลไกใด ๆ

19. สิ่งที่ปรากฏบนหน้าจอ

Moodle ของสุนัข

Moodle ของสุนัขจะอยู่ทางซ้ายของแถว moodle ปกติของเกม แต่ละสายพันธุ์มีของตัวเอง รายละเอียดเต็มอยู่ในคู่มือสายพันธุ์

แบบที่สุนัขตัวไหนก็ขึ้นได้:

ไอคอน Moodle ขึ้นเมื่อไร ทำอะไร
หิว ความหิวสูง เป็นคำเตือนเท่านั้น
กระหายน้ำ ความกระหายสูง เป็นคำเตือนเท่านั้น
เมา กินอาหารที่ไม่ดีเข้าไป เป็นคำเตือนเท่านั้น
อ่อนแรง ไม่ได้กินโปรตีน 72 ชม. แรงกัดเหลือครึ่งเดียว และมีโอกาสขัดคำสั่งเพิ่ม 25% ดูที่ โปรตีน
พักผ่อนเต็มที่ คุณนอนข้างสุนัข บรรเทาความตื่นตระหนก ความเครียด ความเศร้า และความเบื่อหน่าย และคุณเหนื่อยช้าลง ค่าเริ่มต้นอยู่ได้ 2 ชั่วโมงในเกม
โศกเศร้า คู่หูที่ผูกพันกันตายไป ความเศร้าหนัก ๆ ที่จางลงภายในไม่เกิน 48 ชั่วโมงในเกม ดูที่ ความโศกเศร้า
ถ่ายพยาธิแล้ว ได้ยาถ่ายพยาธิ ป้องกันพยาธิได้ 30 วัน
ฉีดวัคซีนแล้ว ได้วัคซีน ไม่เป็นไข้หวัด แผลไม่ติดเชื้อ และไม่ท้องเสียจากอาหารหรือน้ำ
ป้องกันแล้ว: พยาธิหนอนหัวใจ ได้ยาพยาธิหนอนหัวใจ ไม่มีพยาธิหนอนหัวใจตัวใหม่ 30 วัน
ป้องกันแล้ว: หมัดและเห็บ ได้ยากำจัดหมัดและเห็บ ไม่มีการระบาดใหม่ 30 วัน
ป้องกันแล้ว: ภูมิแพ้ ได้ยาแก้แพ้ ไม่มีอาการแพ้ใหม่ 2 วัน
ใช้ได้กับ moodle ประจำสายพันธุ์ทุกตัว: ถ้าสุนัขไม่เชื่อฟัง ป่วย หรือหิวหรือกระหายสูง moodle จะ ดับไปจนกว่ามันจะได้รับการดูแลอีกครั้ง

ข้อความเหนือหัว

สุนัขจะซ้อนบรรทัดสถานะหลายบรรทัดไว้เหนือหัว มองเห็นได้ในระยะ 14 ช่อง และเฉพาะชั้นเดียวกัน ไล่จากบนลงล่าง: คำเตือนของการเฝ้าระวัง สถานะ (กลัว, ตกใจ, บาดเจ็บหนัก, ไม่เชื่อฟัง, บาดเจ็บ, ตื่นเต้น) สิ่งที่มันกำลังทำ (กิน ล่าสัตว์ ดมกลิ่น ดูแลปศุสัตว์) การตั้งท้อง และชื่อ ซึ่งอยู่ท้ายสุดเสมอ

ตัวเลือก ข้อความสถานะ: ปิด (แท็บตั้งค่า) ลบทุกอย่างยกเว้นชื่อ ส่วนตัวเลือก ชื่อสัตว์เลี้ยง: ปิด (แท็บเดียวกัน) ลบแค่ชื่อกับ เจ้าของ: ชื่อผู้เล่น ถ้าปิดทั้งสองอัน จะไม่มีอะไรถูกวาดเลย แต่ละอันมีผลเฉพาะกับผู้เล่นคนนั้น ส่วนตัวเลือกแซนด์บ็อกซ์ โชว์ชื่อของ สุนัข เป็นกฎของโลก และลบป้ายทั้งป้ายสำหรับทุกคน

สุนัขของผู้เล่นคนอื่นจะแสดงแค่ เจ้าของ: ชื่อผู้เล่น การตั้งท้อง และชื่อ

หมุดบนแผนที่

สุนัขที่ผูกพันกับคุณทุกตัวจะมีรอยอุ้งเท้าขึ้นบนแผนที่โลกและบนมินิแมป

  • รอยอุ้งเท้าสีน้ำตาลคือตัวหลัก ส่วนสีเทาคือสุนัขสำรอง
  • บนแผนที่โลก รอยอุ้งเท้าจะมีชื่อสุนัขอยู่ข้าง ๆ บนมินิแมปไม่มี และมันจะเกาะขอบจอโดยชี้ไป ทางที่สุนัขอยู่เมื่อสุนัขอยู่นอกจอ
  • ระหว่างที่สุนัขถูกโหลดอยู่ หมุดจะตามมันแบบสด ๆ เมื่อถูกอันโหลด หมุดจะค้างอยู่ที่ตำแหน่ง สุดท้ายที่เห็น

ใช้หาสุนัขที่หลุดไปข้างหลัง หรือหาสุนัขของคุณเองหลังจากคุณตาย หมุดนี้ไม่เคยกลายเป็นสัญลักษณ์ ที่ถูกบันทึกไว้บนแผนที่

ม็อดเพิ่มไอเทมแปดชิ้น: ชามอาหาร กระเป๋าอาน และยาอีกหกชนิด ไม่มีปลอกคอ ไม่มีขนมพิเศษ ไม่มีของเล่น ไม่มีบ้านสุนัข และไม่มีคอกที่สร้างได้ ส่วนอาหารสุนัขปกติของเกมหลัก ม็อดรู้จักมันอยู่แล้ว แต่ไม่ใช่ไอเทมของม็อด

โอกาสพบของแต่ละชิ้น

ภาชนะแต่ละใบที่คุณเปิดจะสุ่มของตัวเอง บ้านที่มีตู้หลายใบจึงให้โอกาสหลายครั้ง ค่าด้านล่างใช้กับ ตัวเลือกของดรอปในแซนด์บ็อกซ์ที่ค่าเริ่มต้น

ภาชนะ ยาอย่างใดอย่างหนึ่งในหกชนิด
ชั้นวางในร้านสัตว์เลี้ยง 59.6%
ลังอุปกรณ์สัตว์เลี้ยง 53.1%
ร้านขายยา คลังเวชภัณฑ์ คลินิก 48.2%
ตู้ยา คลังในโรงนา 36.9%
กล่องเครื่องมือในฟาร์ม 29.2%
ตู้ในห้องน้ำ โรงรถ คลังเวชภัณฑ์ทหาร 28.7%
เคาน์เตอร์ห้องน้ำ 17.5%

แยกตามชนิดยา บนชั้นวางในร้านสัตว์เลี้ยง ยาแก้แพ้และยากำจัดหมัดอยู่ที่ 17.9% ยาปฏิชีวนะและ ยาถ่ายพยาธิ 13.6% ยาพยาธิหนอนหัวใจ 11.5% และวัคซีน 9.3% ชามพบได้ใน 36.7% ของชั้นวางในร้าน สัตว์เลี้ยง ส่วนกระเป๋าข้างอยู่ที่ 17.9% ตัวคูณของดรอปในแซนด์บ็อกซ์ปรับทั้งหมดนี้ ภาชนะที่คุณ เปิดไปแล้วก่อนติดตั้งม็อดจะไม่ได้อะไรเลย เว้นแต่จะเปิดการเกิดใหม่ของดรอป

ชามอาหารคู่หู

สถานีให้อาหาร น้ำหนัก 1.5

มีสองสูตร ทำด้วยมือทั้งคู่และไม่ต้องใช้ทักษะ:

  • เครื่องครัว 1 ชิ้น (หม้อ กระทะ ถาดอบ กาน้ำ ถัง แก้ว ขวด...) ซึ่ง จะถูกทำลายไป
  • ชามสัตว์เลี้ยงของเกมหลัก 1 ใบ ซึ่งถูกทำลายเช่นกัน

พบเป็นของตกในชั้นวางร้านขายสัตว์เลี้ยง ลังเสบียงสัตว์เลี้ยง แผนกของใช้ในซูเปอร์มาร์เก็ต ร้านขายต้นไม้ ลังของฟาร์มและสวน ห้องเก็บของซูเปอร์มาร์เก็ต และครัว

กระเป๋าอานคู่หู

ดูที่ กระเป๋าอาน น้ำหนัก 1.0 และลดน้ำหนักของข้างในได้ดี

21. ผู้เล่นหลายคน

ม็อดทำงานเหมือนกันทั้งในโหมดร่วมมือและบนเซิร์ฟเวอร์เฉพาะ

สุนัขของคุณเป็นของคุณ

ความเป็นเจ้าของผูกกับบัญชีของคุณ ไม่ใช่กับตัวละคร และไม่ใช่กับช่องการเชื่อมต่อ

ผู้เล่นคนอื่นเห็นสุนัขได้ พร้อมชื่อและ เจ้าของ: ชื่อผู้เล่น เหนือหัวมัน

สิ่งที่ผู้เล่นคนอื่นทำไม่ได้:

สิ่งที่พยายามทำ เกิดอะไรขึ้น
อุ้มขึ้น อุ้มไม่ได้เพราะสุนัขตัวนี้เป็นของผู้รอดชีวิตคนอื่นแล้ว
ให้อาหารหรือทำให้เชื่องซ้ำ สุนัขตัวนี้เป็นของผู้รอดชีวิตคนอื่นแล้ว การตรวจเกิดขึ้นก่อนที่อาหารของคนนั้นจะถูกใช้ไป
สั่งงาน เปลี่ยนชื่อ ปล่อย หรือยุ่งกับกระเป๋าอาน ถูกบล็อกที่เซิร์ฟเวอร์
ฆ่า ตัวเลือกไม่ขึ้นมาด้วยซ้ำ และคู่หูเป็นอมตะ

เมื่อคุณหลุดออกจากเกม

เมื่อเปิดตัวเลือก เก็บสุนัขไว้ขณะเจ้าของออฟไลน์ ไว้ (เป็นค่าเริ่มต้น):

  • สุนัขของคุณจะออกจากโลก โดยสถานะและค่าความต้องการถูกหยุดไว้
  • เมื่อคุณกลับมา สุนัขที่อยู่ในโหมด ตามมา จะโผล่ข้างตัวคุณ ส่วนตัวที่อยู่ในโหมด อยู่นิ่ง และ ป้องกัน กับตัวสำรอง จะโผล่ตรงที่คุณทิ้งมันไว้ ทันทีที่พื้นที่นั้นถูกโหลด
  • สุนัขไม่ได้กลับมาพร้อมความหิว

ถ้าปิดไว้ สุนัขจะอยู่ในโลกต่อไป เป็นอมตะและไม่ทำอะไร

สำหรับแอดมิน

มี ทะเบียนคู่หู (แอดมิน) อยู่: ค้นหาตามผู้เล่น สถานะออนไลน์/ออฟไลน์ จำนวนสุนัข และปุ่มรีเฟรช และยังมีแผงปรับแต่งประสิทธิภาพเซิร์ฟเวอร์แบบสด ๆ อธิบายไว้ใน หัวข้อ 25. การปรับจูนเซิร์ฟเวอร์

22. ตัวเลือกแซนด์บ็อกซ์

หน้า Companion Dogs ในการตั้งค่าโลก มีทั้งหมด 38 ตัวเลือก

ในผู้เล่นหลายคนใช้การตั้งค่าของเซิร์ฟเวอร์: เปลี่ยนจากแผงแอดมินแล้วมีผลทันที กับทุกคน และถูก บันทึกไว้ ส่วนในโหมดเล่นคนเดียว หน้านี้เปิดได้ก็ต่อเมื่อรันเกมในโหมดดีบัก (-debug ในออปชันเริ่มเกมของ Steam) และที่นั่นก็มีผลทันทีเหมือนกัน ถ้าเล่นคนเดียวโดยไม่มีดีบัก ทางเดียวที่จะเปลี่ยนคือเริ่มโลกใหม่

การทำให้เชื่องและการเกิด

ตัวเลือก ค่าเริ่มต้น ทำอะไร
ความไว้ใจสำหรับรับเลี้ยง 100 ต้องให้อาหารเท่าไรกว่าสุนัขจะเป็นของคุณ
จำนวนสุนัขที่รับเลี้ยงได้สูงสุด 0 (ไม่จำกัด) เพดานจำนวนสุนัขที่ผูกพันกับคุณ
ตัวคูณสำหรับการเกิดของสุนัข 1.0 ปรับการเกิดทั้งหมด รวมถึงสุนัขจรจัดในเมือง 0 คือปิด
สุนัขป่าจะเป็นอัมตะ ปิด กันสัตว์ที่ยังไม่มีเจ้าของไม่ให้ตายก่อนที่คุณจะทำให้มันเชื่อง

การต่อสู้

ตัวเลือก ค่าเริ่มต้น ทำอะไร
คู่หูโจมตีซอมบี้ เปิด สวิตช์หลักของการต่อสู้
ตัวคูณความเสียหายของสุนัข 1.0 ปรับความเสียหาย ไม่ว่าตั้งเท่าไร Caramelo ก็ยังฆ่าซอมบี้ให้จบไม่ได้

การดูแลและความผูกพัน

ตัวเลือก ค่าเริ่มต้น ทำอะไร
ความต้องการ และ การดูแลรักษา เปิด สวิตช์หลักของความหิว ความกระหาย ความซื่อสัตย์ และความเครียด
อัตราความหิวและความกระหายน้ำ 1.0 ปรับทั้งสองอย่าง 0 คือหยุดสนิท
สุนัขต้องการโปรตีน เปิด ขาดเนื้อ ปลา ไข่ หรืออาหารสุนัข แล้วสุนัขจะ อ่อนแรง: ความเสียหายเหลือครึ่งเดียว และเครียดเพิ่มชั่วโมงละ 2
ชั่วโมงที่อยู่ได้โดยไม่มีโปรตีน 72 นับเป็นชั่วโมงในเกม: 72 คือสามวัน ตั้งได้ตั้งแต่ 6 ถึง 168
ค่าความซื่อสัตย์ที่ลดลงต่อวัน 12.0 ยิ่งสูง สุนัขยิ่งเรียกร้องความใส่ใจมากขึ้น
สร้างความสัมพันธ์ (ลูบ และ นอน) เปิด การลูบและการนอนข้างกันช่วยลดความเบื่อหน่ายและความเศร้าของคุณ
บัฟพักผ่อนเต็มที่ (เมื่อนอนใกล้สุนัข) เปิด บัฟที่ได้ตอนตื่นขึ้นมาข้างสุนัข
ระยะเวลาของบัฟพักผ่อนเต็มที่ (เป็นชั่วโมงในเกม) 2.0 บัฟอยู่ได้นานแค่ไหนหลังคุณตื่น
มูเดิลประจำสายพันธุ์ เปิด moodle เฉพาะตัวของแต่ละสายพันธุ์ (เพื่อนที่ดี กำลังใจดี จมูกดี อบอุ่น และอื่น ๆ)

การดูแลสัตวแพทย์

หัวข้อ 7. สุขภาพและโรค อธิบายแต่ละอันพร้อมผลที่เกิดขึ้นในเกม

ตัวเลือก ค่าเริ่มต้น ทำอะไร
การดูแลสัตวแพทย์ เปิด สวิตช์หลักของโรคและยาทั้งหมด
โรคและการละเลยอาจถึงตาย ปิด ถ้าปิด พลังชีวิตจะหยุดที่ 10% ถ้าเปิด สุนัขตายแล้วไม่กลับมา
โอกาสบาดเจ็บต่อการกัด (เปอร์เซ็นต์) 0.4 ต่อหนึ่งครั้งที่สุนัขกัดซอมบี้ ลดลง 5% ต่อเลเวลการต่อสู้
โอกาสเคล็ดต่อการกระโดดรั้ว (เปอร์เซ็นต์) 0.5 ต่อรั้วหนึ่งรั้วที่กระโดดข้าม
โอกาสเป็นพยาธิต่อการท้องเสีย 6 ชม. (เปอร์เซ็นต์) 10.0 ทอยทุก 6 ชั่วโมงที่ท้องเสีย
โอกาสท้องเสีย (เปอร์เซ็นต์) 25.0 ต่ออาหารใกล้เสียหรือน้ำสกปรกหนึ่งครั้ง
โอกาสเป็นไข้หวัด (เปอร์เซ็นต์) 15.0 ใช้กับสุนัขที่หิวจัด และกับทุกชั่วโมงที่อยู่ข้างสุนัขที่ป่วย
โอกาสเป็นพยาธิหนอนหัวใจ (เปอร์เซ็นต์) 1.5 ทุก 6 ชม. ติดต่อกันที่อยู่กลางแจ้ง
โอกาสแพ้อาหาร (เปอร์เซ็นต์) 5.0 ครั้งเดียวต่อสุนัขหนึ่งตัว
โอกาสติดหมัดหรือเห็บต่อการกัดหนึ่งครั้ง (เปอร์เซ็นต์) 0.2 ต่อหนึ่งครั้งที่สุนัขกัด

พฤติกรรม

ตัวเลือก ค่าเริ่มต้น ทำอะไร
ป้องกันอันตราย: แจ้งเตือนซอมบี้ เปิด สวิตช์หลักของการเฝ้าระวังในโหมดป้องกันอันตราย
เสียงสุนัขจะดึงดูดซอมบี้ เปิด เสียงเห่าดังคือเสียงจริงในเกม ส่วนเสียงขู่เบา ๆ ไม่ดึงดูด
สุนัขทำให้คุณสะดุดล้มได้ เปิด วิ่งชนสุนัขแล้วล้ม เหมือนชนซอมบี้ ถ้าปิด คุณจะวิ่งทะลุตัวมันไป

ทักษะและกิจกรรม

ตัวเลือก ค่าเริ่มต้น ทำอะไร
ตัวคูณค่าประสบการณ์ทักษะ 0.5 ความเร็วในการฝึก ถ้ารู้สึกช้าให้ขึ้นไป 1.0 หรือมากกว่า
การดูแลฟาร์ม (ต้อนฝูงสัตว์) เปิด สวิตช์หลักของโหมดดูแลคอกสัตว์
ท่าทางจากการเชื่อฟัง เปิด สวิตช์หลักของท่าทางทั้งสี่

กระเป๋าอาน

ตัวเลือก ค่าเริ่มต้น ทำอะไร
ตัวคูณกระเป๋าอาน 1.0 ปรับน้ำหนักที่กระเป๋าอานรับได้ ตั้งแต่ 0 ถึง 5 ถ้าเป็น 0 มันจะเป็นแค่ของตกแต่ง

ลูกสุนัข

ตัวเลือก ค่าเริ่มต้น ทำอะไร
การผสมพันธุ์และลูกสุนัข เปิด ถ้าปิด จะไม่มีลูกสุนัขเกิดเลยสักตัว
ระยะเวลาตั้งท้อง (วัน) 4 จำนวนวันในเกมจนกว่าจะคลอด
ระยะเวลาที่ลูกสุนัขเติบโต (วัน) 90 จำนวนวันจนกว่าจะโตเต็มวัย
โอกาสผสมพันธุ์ต่อวัน 5.0 โอกาสที่คู่หนึ่งจะตั้งท้องเอง 0 คือปิด

อินเทอร์เฟซและผู้เล่นหลายคน

ตัวเลือก ค่าเริ่มต้น ทำอะไร
โชว์ชื่อของสุนัข เปิด ถ้าปิด จะไม่มีใครเห็นชื่อบนหน้าจอ
เก็บสุนัขไว้ขณะเจ้าของออฟไลน์ เปิด ผู้เล่นหลายคน: สุนัขออกจากโลกเมื่อคุณหลุดออกจากเกม

23. ปัญหาที่พบบ่อย

สุนัขโผล่มาแบบไม่มีเท็กซ์เจอร์ บิดเบี้ยวไปหมด เปิดใช้งานม็อดในรายการ ม็อด ของเมนูหลัก แล้วปิดเกมให้สนิทก่อนจะโหลดเซฟ เป็นปัญหาที่พบบ่อยที่สุดในโหมดร่วมมือ

ใส่ม็อดแล้วแต่ไม่มีอะไรขึ้นในเซฟของผม ม็อดที่เพิ่มทีหลังจะไม่เข้าไปในโลกที่สร้างไปแล้ว และเกมก็ไม่เตือน ให้เช็กที่หน้าจอโหลดเซฟ ว่าม็อดถูกติ๊กไว้สำหรับโลกนั้นหรือยัง

สุนัขของผมไม่เชื่อฟัง ดูที่ข้อความ ถ้าเป็น ไม่ไว้ใจพอที่จะทำตามคำสั่งคุณ แปลว่าเรื่องความซื่อสัตย์: ให้อาหาร ให้น้ำ และลูบหัวมัน ถ้าเป็น วอกแวกและไม่สนใจคุณ แปลว่าฝึกมาไม่พอ: สั่งซ้ำอีกที ครั้งที่สอง จะผ่าน ถ้าเป็นความตกใจหรือบาดแผล ให้รักษามันก่อน

สุนัขของผมอ่อนแรงแล้วไม่หายสักที มันอยู่มาเกินสามวันในเกมโดยไม่ได้โปรตีน ให้มื้ออาหารจริงจังสักมื้อ หรือเทอาหารสุนัขลงใน ชาม สิ่งที่นับคือปริมาณ ดูที่ โปรตีน

สุนัขของผมไม่ฆ่าซอมบี้ ได้แค่ทำให้ล้ม Caramelo ทำได้แค่ทำให้ล้ม และไม่มีการตั้งค่าไหนเปลี่ยนเรื่องนี้ได้ คุณต้องจัดการซอมบี้เอง สายพันธุ์อื่นฆ่าได้เอง

สุนัขเห่าตลอดเวลาและลากซอมบี้มา เปลี่ยนการเฝ้าระวังเป็น ส่งเสียงเบาๆ ซึ่งไม่เห่า ถ้าอยากให้ไม่มีเสียงเห่าไหนดึงซอมบี้เลย ให้ปิดตัวเลือกแซนด์บ็อกซ์ เสียงสุนัขจะดึงดูดซอมบี้ มันมีผลกับทุกสายพันธุ์

สุนัขของผมหายไป / สุนัขติดอยู่อีกฝั่งของรั้ว ทั้งสองอย่างแก้ได้ด้วย เรียกกลับมา: เปิดหน้าต่างจากปุ่มอุ้งเท้าแล้วไปที่แท็บ คู่หูของฉัน เสียงผิวปากจะดึงดูดซอมบี้ รายละเอียดอยู่ใน สุนัขหลายตัวพร้อมกัน

สุนัขของผมไม่ตั้งท้องสักที เช็กรายการเงื่อนไขการผสมพันธุ์ ความหิวและความกระหายขวางก็ต่อเมื่อ เข้าเขตแดง และความซื่อสัตย์ไม่ถูกนับเลย เช็กด้วยว่า ห้ามผสมพันธุ์ ไม่ได้เปิดอยู่ สุนัขผสมกับสุนัขเท่านั้น และแมวผสมกับแมวเท่านั้น

ลูกสุนัขของผมไม่โตสักที เช็กว่า หยุดการเติบโต ไม่ได้เปิดอยู่กับมัน นอกจากนั้นก็แค่เรื่องเวลา: ค่าเริ่มต้นคือ 90 วัน ในเกม และนาฬิกาเดินแม้มันจะอยู่ไกล ถ้าครบกำหนดแล้ว ให้เข้าไปใกล้มัน การเปลี่ยนร่างเกิดขึ้นตอนที่ลูกสุนัขถูกโหลด

สุนัขไม่ขึ้นรถไปกับผม มีแต่สุนัขในโหมด ตามมา เท่านั้นที่ขึ้นรถ

ผมปล่อยให้สุนัขเฝ้าฐาน แล้วมันไม่ทำอะไรเลย ตอนนี้โหมดป้องกันทำงานเฉพาะตอนที่คุณอยู่ใกล้ โหมดเดียวที่ทำงานเองจากที่ไกลได้คือ ให้ดูแลปศุสัตว์ที่นี่ และมันต้องมีคอกสัตว์ที่กำหนดไว้

สุนัขเรียนรู้ช้าเกินไป ค่าเริ่มต้นของ ตัวคูณค่าประสบการณ์ทักษะ คือ 0.5 ให้ขึ้นไป 1.0 หรือมากกว่าในโลกใหม่

สุนัขของผมตาย สุนัขที่ตายแล้วไม่กลับมา ความหิว ความกระหาย และโรคที่ไม่ได้รักษาจะทำให้ตายได้ก็ต่อเมื่อเปิดตัวเลือกแซนด์บ็อกซ์ โรคและการละเลยอาจถึงตาย เท่านั้น ค่าเริ่มต้นปิดไว้ และพลังชีวิตจะหยุดที่ 10% กระเป๋าอานกับของข้างในจะตกอยู่ตรงที่มันล้ม

น้ำหนักที่ผมแบกได้เปลี่ยนไปหลังติดตั้งม็อด Companion Dogs ไม่ได้ยุ่งกับน้ำหนักสูงสุดที่คุณแบกได้ บนเซิร์ฟเวอร์มีรายละเอียดของเกมหลักอยู่อย่างหนึ่ง: ความจุของคุณจะค้างอยู่ที่ค่าต่ำ ๆ โดยไม่สนความแข็งแกร่ง จนกว่าตัวละครจะโดนดาเมจครั้งแรก

24. การเอาม็อดออกจากเซฟ (อ่านตรงนี้ก่อน)

การเอา Companion Dogs ออกจากเซฟที่มีสุนัขอยู่ จะทำให้สัตว์ที่ไม่ใช่ของม็อดหายไปด้วย: ปศุสัตว์ ในคอกของคุณ ไก่ และอะไรก็ตามที่อยู่ในส่วนนั้นของแผนที่ นี่คือวิธีที่ Project Zomboid เก็บสัตว์ และม็อดก็ป้องกันอะไรไม่ได้เมื่อมันถูกเอาออกไปแล้ว

ทำไมถึงเกิดขึ้น

เกมเก็บสัตว์ที่มีชีวิตทุกตัวของภูมิภาคใหญ่ ๆ บนแผนที่ไว้ในไฟล์เดียว เมื่อเปิดไฟล์นั้นโดยไม่มีม็อด มันจะเจอสุนัข จำไทป์ไม่ได้ เลิกอ่านส่วนที่เหลือของไฟล์ แล้วเติมสัตว์ใหม่ลงใน ภูมิภาคนั้นราวกับว่าคุณไม่เคยไปที่นั่นมาก่อน สัตว์ของคุณหายไปเพราะมันอยู่ใน ไฟล์เดียวกับสุนัข

ทุกอย่างที่ถูกเก็บไว้หลังสุนัขในภูมิภาคนั้นจะหายไป และไม่มากไปกว่านั้น ผลลัพธ์จึงต่างกัน ไปในแต่ละเซฟ

การเลิกติดตามเฉพาะ Rottweiler, Doberman, Labrador, Pug (หรือตัวไหนก็ตาม) แล้วเล่นต่อด้วยม็อดหลัก ก็ทำให้เกิดปัญหาเดียวกัน เพราะสุนัขสายพันธุ์นั้นยังถูกเขียนอยู่ในเซฟ

ถ้าสัตว์หายไปแล้ว

ติดตั้งม็อดกลับเดี๋ยวนี้ ก่อนจะเล่นต่อหรือเซฟ สัตว์น่าจะกลับมา เมื่อเกมเซฟทับไปแล้ว ไฟล์นั้นหายไปเลย และไม่มีไฟล์สำรองของมัน

วิธีเอาออกอย่างปลอดภัย

ขั้นที่ 1: เปิดแอดออนทุกตัวไว้ เช็กว่าแอดออนสายพันธุ์ทุกตัวที่คุณเคยใช้ในเซฟนั้น ถูกติ๊กอยู่ในรายการม็อดของเซฟนั้น (โหลด > เซฟนั้น > เลือกม็อด...) แอดออนที่ถูกปิดไว้ตัวเดียว ก็ทำให้เกิดปัญหาที่ว่ามาข้างบนแล้ว

ขั้นที่ 2: กำจัดสุนัขออกไป มีสองทางที่ปลอดภัย:

  • ฆ่ามัน ซากถูกเก็บในอีกรูปแบบหนึ่ง ซึ่งเกมอ่านได้แม้ไม่มีม็อด
  • อุ้มมันไว้ในช่องเก็บของ เกมรู้จักข้ามไอเทมนั้น: หายไปแค่สุนัข ที่เหลืออยู่ครบ

การปล่อยสุนัขหรือพามันไปไกล ๆ ไม่ช่วย: ข้อมูลของมันยังอยู่ในเซฟ และการย้ายมันไป ที่อื่นก็แค่เปลี่ยนว่าภูมิภาคไหนจะพัง

ขั้นที่ 3: เซฟเกม การเซฟคือสิ่งที่เขียนการล้างลงไป

ขั้นที่ 4: เอาม็อดออก

ล้างให้หมดจด (แอดมิน / โหมดดีบัก)

ขั้นตอนข้างบนครอบคลุมสุนัขของคุณเอง แต่ม็อดยังโปรยสุนัขจรจัดไว้ทั่วแผนที่ และไม่มีทาง หาให้ครบด้วยมือ ถ้าจะล้างทั้งเซฟรวดเดียวก็มีคำสั่งอยู่:

  1. เข้าเกมเป็นแอดมิน (ผู้เล่นหลายคน) หรือรันเกมในโหมดดีบัก (เล่นคนเดียว: เติม -debug ลงใน ออปชันเริ่มเกมของ Steam)
  2. คลิกขวาที่พื้น → Companion Dogs (ดีบั๊ก) → Tools → Delete ALL dogs (whole save)
  3. รอข้อความ sweep done แล้วเซฟเกม

คำสั่งนี้ลบสุนัขที่โหลดอยู่ทันที แล้วกวาดส่วนที่เหลือของเซฟในเบื้องหลัง โดยไม่ทำให้เกมค้าง ถ้ามันปฏิเสธพร้อมบอกชื่อสายพันธุ์ ให้เปิดแอดออนตัวนั้นในเซฟแล้วทำซ้ำ: ถ้าไม่มีนิยามของมัน การล้างจะลบสัตว์ของภูมิภาคนั้นไปด้วย

25. การปรับจูนเซิร์ฟเวอร์ (แอดมิน)

หัวข้อนี้สำหรับคนที่รันเซิร์ฟเวอร์ที่มีคนเยอะและสุนัขเยอะ แผงนี้ชื่อ Server tuning / performance: ด้านบนเป็นมาตรวัดสด ๆ ว่าม็อดกินเซิร์ฟเวอร์ไปเท่าไร ด้านล่างเป็นช่องที่เปลี่ยนค่าใช้จ่ายนั้น กฎของเกม (ความเสียหาย ความหิว ค่าประสบการณ์ เพดานจำนวนสุนัข) ไม่ได้อยู่ที่นี่ มันยังเป็นตัวเลือกแซนด์บ็อกซ์ อยู่ในหัวข้อ 22

แผงนี้เป็นภาษาอังกฤษไม่ว่าเกมจะตั้งภาษาอะไรไว้ เพราะป้ายของมันถูกฝังไว้ในโค้ด ตารางข้างล่างอ้างแต่ละอันตามที่มันขึ้นบนหน้าจอ

วิธีเปิดแผง

คลิกขวาที่พื้น → Companion Dogs (ดีบั๊ก) → Tools → Server tuning / performance ในผู้เล่นหลายคนต้องเป็นแอดมิน ส่วนในโหมดเล่นคนเดียวต้องรันเกมในโหมดดีบัก (-debug ในออปชัน เริ่มเกมของ Steam)

สิ่งที่ใช้ได้กับทุกช่อง

  • ค่าที่ใส่มีผลทันที กับทั้งเซิร์ฟเวอร์ และถูกบันทึกไว้ในเซฟ
  • ค่าที่อยู่นอกช่วงจะถูกดึงกลับเข้ามาในช่วง
  • ป้ายสีเขียวแปลว่าช่องนั้นตั้งไว้ต่างจากค่าเริ่มต้น
  • ทุกการเปลี่ยนแปลงจะลงล็อกพร้อมเครื่องหมาย [CD-TUNE] และชื่อของคนที่แก้ ตอนบูต เซิร์ฟเวอร์จะพิมพ์ รายการที่ใช้อยู่ พร้อม * บนอันที่แอดมินเปลี่ยน
  • Restore defaults คืนทุกอย่างกลับเป็นค่าเริ่มต้น รวมถึงการวัดและ client authority ด้วย

สวิตช์ Client authority คือการปรับที่มีผลมากที่สุดในหัวข้อนี้ เมื่อเปิด (ค่าเริ่มต้น) เครื่องของเจ้าของจะเป็นตัวขยับสุนัขและรายงานตำแหน่ง แล้วเซิร์ฟเวอร์ตรวจก่อนจะส่งต่อ นี่คือสิ่งที่ทำให้การเดินและการวิ่งลื่นไหล เมื่อปิด สุนัขทุกตัวกลับไปอยู่กับเซิร์ฟเวอร์ และไคลเอนต์เลิกส่งตำแหน่ง ซึ่งเป็นคำสั่งที่ถี่ที่สุดของม็อดบนเซิร์ฟเวอร์ที่คนเต็ม แลกมาด้วยการเคลื่อนไหวที่กระตุกสำหรับทุกคน และสุนัขทุกตัวกลับเข้าคิวหาเส้นทางของเซิร์ฟเวอร์ ซึ่งเป็นคิวรวมที่แบ่งกันใช้กับผู้เล่น
