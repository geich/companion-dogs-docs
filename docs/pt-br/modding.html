Companion Dogs: Manual de Modding

Como fazer o seu addon: uma raça nova, ou uma espécie inteira, como mod separado da Workshop que se encaixa no Companion Dogs.

Este manual é para quem escreve mod. Se você só quer jogar, os outros dois manuais é que servem: Funcionalidades para o que o cão faz, e Raças para as raças.

Ele assume que você já lê Lua e que tem um modelo com rig e animação para o seu bicho. O pipeline de arte não está aqui; a seção 3 lista o que o arquivo de modelo tem de cumprir, e nada além disso.

Isto é contrato público. Tudo que este manual nomeia existe para ser chamado de fora do mod. O que não está nomeado aqui é interno e pode mudar em qualquer versão, sem aviso.

1. O que é um addon

Um addon é um mod comum da Workshop que declara require=CompanionDogs e chama uma função no carregamento. Ele acrescenta uma raça (ou várias, se dividirem o mesmo corpo), e nada mais. Tudo que faz o bicho se comportar como companheiro já mora no mod base e é compartilhado.

O base é dono de:

  • a máquina de estados de animação, o animset e o esqueleto
  • seguir, pathing, combate, caça, pastoreio, sentinela, necessidades e upkeep
  • a interface inteira: a janela do cão, o radial, o menu de contexto, o canil, o marcador no mapa
  • domesticação, vínculo, cruzamento, filhotes e mestiços
  • as opções de sandbox e a replicação de multiplayer

O seu addon é dono de:

  • os números que fazem o seu bicho ser diferente de um caramelo
  • o modelo do corpo, a textura, o retrato e, se tiver, o ícone do moodle
  • onde ele é encontrado no mundo
  • o nome e a descrição, em cada idioma que você entregar

Essa divisão é o ponto todo. Um pacote de raça são algumas centenas de linhas de Lua, porque a parte difícil já está rodando.

Uma raça, uma aparência. Uma raça é um conjunto de números mais uma aparência. Se você quer duas cores do mesmo bicho se comportando de formas diferentes, são duas raças. Se quer duas cores que se comportam igual, ainda são duas raças para o base (dois nomes, duas entradas no canil), e você as escreve a partir de uma tabela compartilhada, como o CD: Cats faz com as cinco pelagens dele.

2. As versões da API

CD.API_VERSION é um número simples. Ele só cresceu acrescentando coisa, então um addon escrito contra uma versão antiga continua carregando num base mais novo sem uma única mudança.

API Versão do base O que entrou
1 0.6.3 CD.registerBreed, o registry de spawn, moodle de raça
2 0.6.6 huntFetchLevel, huntDeliverTimeoutMin, o hook CD.onHuntDelivered
3 0.6.8 sentinelMult, barkNoiseMult, loyaltyDecayMult, o hook CD.onUpkeepStress
4 0.6.9 alertModeLocked
5 0.7.0 skills, canBreed, huntMaxPrey, descKey, voices, CD.registerVoices

O número em que guardar é a API mais baixa de que o seu addon realmente precisa, e a versão do base naquela tabela é a que você anuncia na sua página da Workshop. Tire dessa tabela, e não do que o base era enquanto você escrevia: um campo que só existe na versão de desenvolvimento é um campo que os seus jogadores não têm.

Campo ausente é ignorado em silêncio. Isso está bom quando o campo é um número: num base antigo o seu bicho simplesmente late no volume normal. Não está bom quando o campo é um bloqueio, porque aí um gato que nunca deveria brigar sai brigando. Ou seja: número pode degradar, bloqueio não. Se o seu bicho depende de um bloqueio, guarde na API que o trouxe e deixe o addon ficar inerte em qualquer coisa mais velha.

3. O que você precisa antes de começar

Um modelo skinado. O seu bicho precisa do .glb dele em media/models_X/Skinned/, e esse arquivo tem de carregar o conjunto COMPLETO dos 21 clips Rac_*. Clip não é herdado entre arquivos de modelo: um modelo com quinze clips dá um bicho que congela na primeira vez que alguém pedir um dos outros seis. O modelo também tem de ficar abaixo de 60 ossos e ter o nó de topo em identidade, senão a engine estoura uma vez por frame e o bicho aparece como um borrão preto.

Se você ainda não tem modelo, dá para escrever e testar todo o resto apontando o CD.applyDogModel para um dos corpos do base. O bicho vai parecer um caramelo, mas todo sistema deste manual roda.

Uma textura de corpo, e um retrato para a janela do canil.

Uma decisão, antes de qualquer linha: o seu bicho é uma raça ou uma espécie? Raça é um cão com números diferentes. Espécie é um bicho que simplesmente não tem alguns dos trabalhos. A diferença não é cosmética, ela muda quais campos você escreve, e a seção 7 é sobre isso.

4. Os arquivos de um addon

Este é o CD: Pug, o menor addon publicado, com as partes que importam:

CompanionDogsPug/
  42/
    mod.info
    icon.png
    poster.png
    media/
      models_X/Skinned/Pug_Body.glb
      scripts/models_pug.txt
      textures/Body/Pug.png
      textures/CDPortrait_pug.png
      lua/shared/CompanionDogsPug_Breed.lua
      lua/shared/Definitions/animal/PugDefinitions.lua
      lua/shared/Definitions/animal/CompanionDogsPug_Parts.lua
      lua/client/CompanionDogsPug_Moodle.lua
      lua/shared/Translate/EN/IG_UI.json
      lua/shared/Translate/PTBR/IG_UI.json
  common/

E o mod.info:

id=CompanionDogsPug
name=CD: Pug
description=Pugs for Companion Dogs. REQUIRES the Companion Dogs mod (0.6.8 or newer).
poster=poster.png
icon=icon.png
require=CompanionDogs
modversion=0.1.0
pzversion=42.19.0
versionMin=42.18.0

require=CompanionDogs é a linha importante. Ela garante que todo o Lua do base rodou antes do seu, em cada fase: shared primeiro, depois client, depois server. Sem ela os seus arquivos podem carregar primeiro, e aí toda chamada CD. é índice em nil.

O versionMin não consegue dizer "precisa do Companion Dogs 0.6.8". Aquele campo é o gate da versão do jogo e nada mais, e não existe campo de mod.info para versão de dependência. O piso do base é garantido pela guarda da seção seguinte, e anunciado ao jogador na sua descrição. Escreva lá, por extenso, ou o único sintoma que o jogador recebe é um bicho que nunca aparece.

5. A guarda de versão

Ponha isto no topo de todo arquivo Lua do seu addon, com o número de que o seu addon precisa:

local CD = CompanionDogs
if not (CD and CD.registerBreed and (CD.API_VERSION or 0) >= 3) then return end

Com o base ausente ou velho demais, o arquivo retorna na linha dois. O addon então não faz nada: sem raça, sem spawn, sem moodle, sem uma linha no log. Esse silêncio é deliberado. Um addon que carrega pela metade é pior que um que não carrega, porque o jogador fica com um bicho que tem nome e não tem comportamento.

A guarda é por arquivo, e cada arquivo guarda no que usa. O PugDefinitions.lua precisa dos helpers de modelo, então guarda neles:

if not (CompanionDogs and CompanionDogs.applyDogModel and CompanionDogs.DOG_SOUNDS) then return end

Nunca crie o global. CompanionDogs = CompanionDogs or {} num addon transforma um base ausente numa tabela meio construída, e toda guarda dali para baixo passa quando não deveria. Leia o global, nunca escreva nele.

6. Registrando a raça

Uma chamada, num arquivo shared:

CD.registerBreed({
    key = "pug",
    engineBreed = "pug",
    typePrefix = "pug",
    nameKey = "IGUI_PD_Breed_pug",
    litter = { 1, 2 },
    xpMult = { scent = 1.5, combat = 1, obedience = 2.0, hunt = 1.2, herding = 1.0 },
    combatPower = 0.15,
    lethalityCurve = { min = 0.40, max = 1.3 },
    canKill = false,
    canKnockdown = false,
    combatStressMult = 0.9,
    panicThreshold = 0.70,
    bagMult = 0.6,
    sentinelMult = 1.35,
    barkNoiseMult = 1.5,
    alertModeLocked = true,
    loyaltyDecayMult = 0,
    geneRange = {
        strength       = { 0.00, 0.10 },
        aggressiveness = { 0.05, 0.20 },
        resistance     = { 0.00, 0.15 },
        stress         = { 0.55, 0.85 },
    },
    spawns = {
        { id = "pughouse", class = "house", suffix = "|pg", breed = "pug",
          chance = function() return CD.strayChancePerHouse() / CD.PUG_HOUSE_RARITY end },
    },
})

Essa chamada insere a raça, registra os três tipos de animal dela, reconstrói a ordem de cruzamento para o seu bicho entrar na mestiçagem, e registra os passos de spawn.

Definição inválida devolve nil em vez de estourar, então um erro nunca derruba o load junto. Toda recusa imprime uma linha nomeada, então leia o log na primeira vez que registrar uma raça.

Campos obrigatórios

Campo O que é
key o identificador da sua raça, único em todo o ecossistema. Nunca muda depois do release.
typePrefix prefixo dos três tipos de animal: <prefixo>pup, <prefixo>female, <prefixo>male. Escolhe a mesh do corpo.
nameKey chave de tradução do nome de exibição.
xpMult velocidade de aprender por habilidade: scent, combat, obedience, hunt, herding. 1.0 é o normal.
combatPower o quanto ele bate. O caramelo é 0.20, uma raça de briga passa de 1.0.
lethalityCurve { min, max }, como o dano cresce de Combate 0 até Combate 10.
geneRange faixa de nascimento dos quatro genes: strength, aggressiveness, resistance, stress. Cada um é { mínimo, máximo } dentro de 0 a 1.

Campos opcionais

Campo Padrão O que faz
engineBreed o key nome de raça entregue à engine, que escolhe a textura. Único por raça.
descKey IGUI_PD_BreedDesc_<key> chave da descrição. Aponte várias raças para uma chave só quando elas dividem a descrição.
litter valor do base { mínimo, máximo } de filhotes por parto.
canKill true false faz ele desgastar zumbi mas nunca desferir o golpe final.
canKnockdown false true deixa ele derrubar zumbi.
combatStressMult 1 o quanto uma briga custa de estresse para ele.
panicThreshold valor do base nível de estresse em que ele para de lutar. panicImmune = true significa nunca.
bagMult 1 multiplicador da capacidade do alforje.
puppySize 0.6 escala visual absoluta do filhote. Raça pequena tem de setar isto, senão o filhote nasce do tamanho de adulto.
sentinelMult 1 multiplica o raio final de sentinela.
barkNoiseMult 1 escala o raio e o volume do latido de alarme. Ele escala o ruído, não cria ruído: com a opção de sandbox desligada, nenhuma raça atrai zumbi com latido.
loyaltyDecayMult 1 multiplica o decaimento diário de lealdade. 0 significa que o vínculo nunca cai.
alertModeLocked false o bicho fica preso em alerta total: o dono não consegue pôr em quieto nem em silencioso, por lugar nenhum. Use quando o alarme alto for o desenho.
huntFetchLevel 6 nível de Caça a partir do qual ele traz o abate para o dono.
huntDeliverTimeoutMin 5 game-minutes que ele insiste na entrega antes de desistir.
idleAnimMs valor do base duração da janela da animação ociosa, em milissegundos. Ajuste quando os seus clips forem mais curtos que os do cão, senão o clip em loop recomeça e é cortado no meio do gesto.
restAnim true false mantém o bicho em pé no Ficar e no Guarda, em vez de deitado.
voices sons de cão { bark, growl, idle, wildbark, pet }. Ver abaixo.
skills, canBreed, huntMaxPrey tudo ligado os bloqueios estruturais. Seção 7.

Número e flag que você acrescentar à definição são lidos de volta com CD.breedNumber(animal, campo) e CD.breedFlag(animal, campo). Prefira essas duas a ler CD.getBreedDef(animal).campo na mão: elas tratam o campo ausente por você, e continuam funcionando quando o base mudar.

A voz

Uma espécie diferente não fala a mesma língua. Sem voices, o seu gato late:

CD.registerVoices({
    CDCatMeow = "bark", CDCatGrowl = "bark", CDCatPurr = "bark",
    CDCatPet = "fx", CDCatMeowAmbient = "ambient",
})
voices = { bark = "CDCatMeow", growl = "CDCatGrowl", idle = "CDCatPurr",
           wildbark = "CDCatMeowAmbient", pet = "CDCatPet" },

CD.registerVoices não é enfeite opcional. Sem ele os sons até tocam, mas ignoram o slider de categoria do jogador e o volume de efeitos do jogo, que é uma falha que ninguém reporta porque nada parece quebrado. Chave que você deixar de fora de voices cai no som de cão, que é o que você quer numa raça de cão e nunca é o que você quer em outra espécie.

7. Desligando um sistema inteiro

As cinco habilidades são os cinco sistemas, um para um:

Habilidade O sistema que ela é
scent o sentinela: perceber zumbi e avisar você
combat brigar, o modo Guarda e a autoproteção
obedience a árvore de truques
hunt a caça, mais o bônus de forrageio que ele dá ao dono
herding cuidar de gado num curral

Espécie não é um cão com números piores. É um bicho que não tem alguns daqueles trabalhos. Então ela declara o que não tem:

skills = { combat = false, herding = false },
canBreed = false,
huntMaxPrey = "tiny",

Ausente ou true significa que o bicho tem aquela habilidade, então você só escreve as que está tirando.

Desligar uma habilidade faz três coisas de uma vez: o sistema nunca roda, a habilidade nunca ganha experiência, e a barra e os comandos dela somem da interface. As três juntas. Esconder só a barra deixaria a habilidade crescendo onde ninguém vê; travar só o sistema deixaria uma barra presa em zero para sempre.

canBreed = false está fora da tabela porque cruzar não tem barra nem experiência. E é total: o bicho não concebe, nunca é escolhido como parceiro, e não cruza nem com a própria raça.

huntMaxPrey é um teto dentro de uma caça que existe, que é coisa diferente de hunt = false. Aceita "tiny" (camundongo, rato, esquilo), "small" (coelho, guaxinim) ou "large" (cervo, o padrão, sem teto). Presa acima do teto é invisível para o seu bicho: ele não persegue e nem sequer aponta. Valor fora dessa escada cai em "large" e imprime uma linha nomeada no log.

Bicho bloqueado não ganha botão desabilitado. A opção sai do radial, do menu de contexto e da janela, e a recusa no server é silenciosa. Um halo dizendo que a ordem foi ignorada seria mentira, porque isso não é desobediência. Explique o desenho na descrição da sua raça. É por isso que nenhum desses campos traz chave de tradução nova junto.

8. As definições de animal

A engine amarra a mesh ao tipo de animal, e não à raça, então a sua raça precisa dos três tipos dela. Esta é a parte mecânica de um addon, e o caminho mais curto é copiar o arquivo de um addon que já existe e renomear.

As três peças, num arquivo shared dentro de Definitions/animal/:

AnimalDefinitions.stages["pug"] = {}
AnimalDefinitions.stages["pug"].stages = {}
AnimalDefinitions.stages["pug"].stages["pugpup"] = {}
AnimalDefinitions.stages["pug"].stages["pugpup"].ageToGrow = 3 * 30
AnimalDefinitions.stages["pug"].stages["pugpup"].nextStage = "pugfemale"
AnimalDefinitions.stages["pug"].stages["pugpup"].nextStageMale = "pugmale"
AnimalDefinitions.breeds["pug"].breeds["pug"].texture = "Pug"
AnimalDefinitions.breeds["pug"].breeds["pug"].textureMale = "Pug"
AnimalDefinitions.breeds["pug"].breeds["pug"].rottenTexture = "Raccoon_Rotting"
AnimalDefinitions.breeds["pug"].breeds["pug"].invIconMale = "CDDogPaw_64"
AnimalDefinitions.breeds["pug"].breeds["pug"].invIconMaleDead = "CDDogPawDead_64"
local pugfemale = {}
CD.applyDogModel(pugfemale, "Pug_Body")
CD.applyDogBehaviour(pugfemale)
pugfemale.female = true
pugfemale.babyType = "pugpup"
pugfemale.minSize = 1.5
pugfemale.maxSize = 2.0
pugfemale.minWeight = 5
pugfemale.maxWeight = 8
pugfemale.wildFleeTimeUntilDeadTimer = CD.STRAY_NO_BLEEDOUT
pugfemale.breeds = AnimalDefinitions.breeds["pug"].breeds
pugfemale.stages = AnimalDefinitions.stages["pug"].stages
pugfemale.genes = AnimalDefinitions.genome["dog"].genes
AnimalDefinitions.animals["pugfemale"] = pugfemale

Os helpers que o base te dá:

Helper O que ele preenche
CD.applyDogModel(t, "Body_Model") modelo do corpo, esqueleto, texturas de abate e o animset
CD.applyDogBehaviour(t) toda flag de comportamento da engine que um companheiro precisa
CD.applyDogAvatar(t) a câmera do retrato na janela do bicho
CD.DOG_SOUNDS a tabela compartilhada de passos e foley
CD.STRAY_NO_BLEEDOUT o valor que impede um vira-lata assustado de sangrar até morrer
CD.defineDogParts(typePrefix, engineBreed) as parts de abate dos três estágios

Quatro regras que não são óbvias:

O animset tem de continuar "raccoon". O CD.applyDogModel seta isso. Um animset forkado não carrega a máquina de estados dele, e um bicho sem máquina de estados é um bicho congelado no lugar.

Reaproveite o genoma: AnimalDefinitions.genome["dog"].genes. Não escreva o seu.

Nunca declare mate. Com ele a engine roda o acasalamento nativo dela dentro de qualquer zona de animais, que ignora o bloqueio de cruzamento do mod e as opções de sandbox, e produz filhote sem vínculo. O base limpa o campo no boot como rede de segurança, mas não conte com isso.

As parts são obrigatórias. Três linhas num arquivo só delas:

if CompanionDogs and CompanionDogs.defineDogParts then
    CompanionDogs.defineDogParts("pug", "pug")
end

Sem elas, abater o seu bicho derruba o código vanilla, porque ele indexa a definição de parts por tipo e raça e cai num nil.

Bicho pequeno precisa da câmera do retrato ajustada. O zoom do retrato no CD.applyDogAvatar é calibrado para cão, e zoom de avatar é magnificação: quanto menor o bicho, maior o número. Divida o zoom pela razão de porte contra um cão e multiplique os offsets por ela, senão o seu bicho fica minúsculo no rodapé do próprio retrato.

9. O script do modelo

Um arquivo em media/scripts/, que é o que conta ao jogo que o seu modelo existe:

module Base
{
    model Pug_Body
    {
        mesh = Skinned/Pug_Body,
        shader = animalEffect,
        static = false,
        animationsMesh = PugAnim,
        attachment head
        {
            offset = -0.0061 0.1671 0.0507,
            rotate = -179.0 -5.0 95.0,
            bone = Dummy01,
        }
    }

    animationsMesh PugAnim
    {
        meshFile = Skinned/Pug_Body,
        keepMeshAnimations = true,
    }
}

keepMeshAnimations = true é o que mantém utilizáveis os clips que estão dentro do seu arquivo de modelo. Sem isso o modelo carrega e nunca anima.

O attachment head é onde chapéu e afins ficam. Se você quer que o alforje sirva no seu bicho, acrescente saddlebags_l, saddlebags_r e saddlebags_c do mesmo jeito, no osso da coluna. Esses números se acham olhando o bicho em jogo e cutucando os valores, e não medindo o modelo: uma bolsa matematicamente centralizada continua parecendo torta num corpo com pelo.

10. Onde o bicho aparece

Vira-lata é sorteado por prédio, por chunk, na primeira vez que aquele chunk carrega. Você descreve os seus sorteios como uma lista de passos, ou dentro da definição da raça em spawns, ou com CD.registerStraySpawns(lista).

spawns = {
    { id = "pughouse", class = "house", suffix = "|pg", breed = "pug", indoor = 85,
      chance = function() return CD.strayChancePerHouse() / CD.PUG_HOUSE_RARITY end },
    { id = "pugpetvet", class = "petvet", suffix = "|pv", breed = "pug",
      chance = function() return CD.PUG_PETVET_CHANCE * CD.dogSpawnMultiplier() end },
},
Chave O que é
id nome do passo, para os seus próprios logs
class a classe de prédio em que ele sorteia
chance uma função que devolve uma porcentagem. Função, e não número, para poder acompanhar o multiplicador de sandbox ao vivo.
suffix chave do store persistido. Única em todo o ecossistema, e nunca muda.
breed a key da raça a nascer
gate função opcional que devolve booleano, conferida antes do sorteio. O husky usa CD.isWinter.
indoor porcentagem de chance de nascer dentro do prédio em vez da rua. Padrão 35.

Multiplique a sua chance por CD.dogSpawnMultiplier(), ou divida CD.strayChancePerHouse() por uma raridade sua. De um jeito ou de outro a opção de sandbox do jogador continua valendo, o que não acontece se você escrever um número cru.

indoor é preferência e não promessa: prédio sem tile interno livre naquele chunk cai de volta num tile lá fora.

As classes de prédio

O base registra quatro, e você pode usá-las direto:

Classe O que casa
house prédio residencial que não é loja
police delegacia e afins
petvet pet shop e clínica veterinária
farm prédio de fazenda, e é permitido fora da cidade

Se nenhuma servir, registre a sua:

CD.registerBuildingClass("mineshaft", function(def) return def:isX() end,
                         { skipUrbanGate = true })

A função de match recebe a definição do prédio e roda dentro de uma chamada protegida, então um erro nela não derruba a carga do chunk. skipUrbanGate deixa a classe sortear em chunk que não é urbano, que é o que uma fazenda ou uma cabana de floresta precisa. Deixe exclusive quieto: as classes do base são exclusivas entre si, e classe de addon existe para ser aditiva, casando por cima delas.

Sufixos já tomados

O sufixo é parte da chave sob a qual fica salvo "este prédio já foi sorteado". Dois mods usando o mesmo sufixo corrompem o sorteio um do outro.

Todo sufixo começa com uma barra vertical. Estes já estão em uso:

  • Base: o sufixo vazio, e g, h, hv, bc
  • Rottweiler: rw, r
  • Doberman: db, dm
  • Labrador: lb, lk
  • Pug: pg, pv
  • Cats: ct, cv, ctw, cvw, cto, cvo, ctc, cvc, ctx, cvx

Escolha um que ninguém esteja usando, e depois nunca mais toque nele.

11. O moodle da raça

Moodle é arquivo de client. Você acrescenta uma tabela em CD.DogMoodles, e o base desenha, acompanha e limpa:

CD.DogMoodles[#CD.DogMoodles + 1] = {
    id = "shadow",
    breed = "pug",
    nameKey = "IGUI_PD_Moodle_Shadow",
    descKey = "IGUI_PD_Moodle_Shadow_desc",
    icon = "CD_Moodle_Shadow",
    fg = "CD_MoodShadowFG",
    tintR = 0.92, tintG = 0.52, tintB = 0.68,
    condition = function(player, dog)
        if not dog or dog:isDead() then return 0 end
        if CD.getBreed(dog) ~= "pug" then return 0 end
        if CD.isDisloyal(dog) then return 0 end
        return 1
    end,
    apply = function(player, dog, elapsedMin)
        CD.relieveMood(player, CD.moodleReliefPerMin() * elapsedMin)
    end,
}

condition devolve o nível, ou 0 para "não aparece". apply é chamada com os game-minutes desde a última chamada, então multiplique o seu efeito por elapsedMin em vez de supor um tick fixo.

Entregue o ícone em seis tamanhos, de 32 a 128 pixels. A interface escolhe o tamanho pela escala do jogador, e tamanho faltando é um quadrado vazio.

Moodle próprio é desenhado como overlay, e não pelo sistema de moodle do jogo, que não aceita entrada nova vinda de mod. Isso já está resolvido para você, mas é por isso que o moodle aparece na faixa do próprio mod e não entre os do vanilla.

12. Hooks

Duas listas de funções que o base chama no server. Acrescente nelas a partir de um arquivo shared. Cada handler roda dentro da própria chamada protegida, então um addon quebrado não derruba o base junto.

CD.onHuntDelivered, da API 2, chamada logo depois de o bicho largar o abate aos pés do dono:

CD.onHuntDelivered[#CD.onHuntDelivered + 1] = function(animal, owner)
    -- server side, so this is the right place to write mod data
end

CD.onUpkeepStress, da API 3, chamada a cada ciclo de upkeep, depois de o base somar o estresse das necessidades e antes de gravar. Devolva um número, que é somado ao total:

CD.onUpkeepStress[#CD.onUpkeepStress + 1] = function(animal, needsStress)
    return CD.pugHeatRatio(animal) * CD.PUG_HEAT_STRESS_MAX
end

Este é o único jeito de um addon influir no estresse contínuo do bicho. O upkeep recomputa e sobrescreve o valor todo ciclo, então qualquer coisa que você escreva por fora se perde no tick seguinte. É a ferramenta certa para condição que vem do ambiente: calor, frio, chuva.

A regra de multiplayer, numa linha: o client nunca escreve ModData. Escrita do lado do client atropela a cópia do server no sync seguinte, e o sintoma aparece minutos depois, em outro lugar. Faça o trabalho num arquivo de server, ou num destes hooks, que já rodam lá.

13. Chaves de tradução

Entregue um IG_UI.json por pasta de idioma, em media/lua/shared/Translate/<LANG>/. O base entrega quatorze: EN, PTBR, CH, CN, DE, ES, FR, IT, JP, KO, RU, TH, UA, VI.

As chaves de que uma raça precisa:

Chave Onde aparece
IGUI_PD_Breed_<key> o nome da raça, em toda a interface do mod
IGUI_PD_BreedDesc_<key> a descrição na ficha do bicho
IGUI_Breed_<engineBreed> o nome da raça nas telas do próprio jogo
IGUI_AnimalType_<type> uma para cada um dos seus três tipos
as chaves do seu moodle nome e descrição, se você tiver moodle 
{
    "IGUI_Breed_pug": "Pug",
    "IGUI_AnimalType_pugmale": "Pug (male)",
    "IGUI_AnimalType_pugfemale": "Pug (female)",
    "IGUI_AnimalType_pugpup": "Pug (puppy)",
    "IGUI_PD_Breed_pug": "Pug",
    "IGUI_PD_BreedDesc_pug": "The house dog: the first companion whose worth is not fighting."
}

Duas coisas que vão te morder. Um sinal de porcentagem literal numa string traduzida derruba a tela que a mostra, porque o formatador o lê como placeholder. E um arquivo de idioma com byte order mark não compila, com um erro que nomeia um arquivo diferente do que está quebrado.

14. O que o save guarda

Três dos seus identificadores são escritos em arquivo de save e lidos de volta para sempre:

  • key, o identificador de raça guardado em cada bicho seu
  • typePrefix, que forma os tipos de animal que a engine guarda
  • suffix, a chave do store de "já foi sorteado", um por passo de spawn

Nenhum dos três pode ser renomeado depois do release. Renomear um key deixa órfão todo bicho vivo daquela raça. Renomear um suffix faz todo prédio de todo save existente sortear de novo, e um mundo jogado por meses de repente enche do seu bicho.

A única vez em que esse re-sorteio é útil é quando ele é o ponto: o CD: Cats deu sufixos novos às quatro pelagens novas de propósito, justamente para elas começarem a aparecer em mundos que já estavam rodando, enquanto o gato preto original manteve o sufixo histórico e não re-sorteou.

Remover um addon de um save que tem bicho vivo daquela raça perde o bicho. A engine descarta um animal cujo tipo ela não conhece mais. O base não crasha, o vínculo e o canil degradam limpo, mas o bicho se foi. Avise na sua página da Workshop, como todo addon publicado faz.

Raça desconhecida degrada em vez de falhar. Se o seu addon estiver ausente, o base cai na raça padrão para qualquer pergunta que lhe façam, então um save aberto sem o seu mod é legível.

15. Antes de publicar

  • A guarda está em todo arquivo Lua, e nomeia a API que você de fato usa.
  • O piso de versão do base está escrito na sua descrição, por extenso. O versionMin não diz isso.
  • Você leu o log no primeiro load. Fora isso o CD.registerBreed recusa em silêncio, e toda recusa imprime uma linha nomeada.
  • O CD.defineDogParts está sendo chamado. Abata um bicho seu e veja que não crasha.
  • O seu key, o typePrefix e os sufixos de spawn são únicos, e você está feliz com eles para sempre.
  • Raça pequena seta puppySize, e você viu um filhote para provar.
  • Se for outra espécie, o CD.registerVoices está sendo chamado e o voices está preenchido, senão ela late.
  • O ícone do moodle existe nos seis tamanhos.
  • Toda pasta de idioma que você entrega tem todas as chaves. Chave faltando mostra a chave crua na tela.
  • Você testou em multiplayer, e não só em single player. Posição, propriedade e ModData se comportam de forma diferente lá.
  • A sua página da Workshop avisa para não remover o addon de um save com bicho vivo.

16. Erros comuns

"O meu bicho nunca aparece." Quase sempre a guarda: o seu addon precisa de uma API que o base instalado não tem, então ele está inerte de propósito. Confira o seu número de API contra a tabela da seção 2.

"Ele aparece, mas fica congelado." O animset não é "raccoon", ou faltam clips no seu modelo. Os dois saem como um bicho parado para sempre.

"Ele vira um borrão preto e o log enche." Mais de 60 ossos no modelo.

"Abater ele crasha." O CD.defineDogParts não foi chamado.

"O filhote nasce do tamanho de um adulto." Raça pequena que não setou puppySize. O valor é absoluto e é reaplicado a cada sweep, então a faixa de tamanho do tipo não te salva.

"Duas raças minhas vivem virando uma na outra." Elas dividem o engineBreed. O prefixo escolhe a mesh e pode ser dividido por uma família; o engineBreed escolhe a textura e é o que desempata dentro daquela família, então tem de ser único por raça.

"O som toca mas ignora o controle de volume." O CD.registerVoices não foi chamado para aquele som.

"Funciona em single player e se comporta mal em servidor." Alguma coisa está escrevendo ModData no client. Mova para o server.

"Ele brigou com zumbi mesmo eu tendo desligado o combate." O base em que ele está rodando é mais velho que a API 5, onde o campo ainda não existia e foi ignorado em silêncio. Este é exatamente o caso em que a guarda tem de bloquear, e não degradar.
