Companion Dogs: 機能マニュアル

犬が何をしてくれるのか、どう指示を出すのか、どう世話をするのかをまとめたガイドです。

犬種の話（どれを選ぶか、それぞれの得意分野、ムードルと資質）はもう一方のマニュアルにあります: 犬種。

このマニュアルで引用符に入っている文字は、日本語版のゲーム画面に出るとおりの表記です。ゲームを英語にすると名称は変わりますが、メニューの中の位置は同じです。

インストール：まずはここから

このMODには Project Zomboid 42.19 以降（Build 42）が必要です。それより古いバージョンでは読み込まれません。

MODがセーブに入っているかどうかは、左側のバーにある肉球ボタンで確認できます:

このボタンがなければ、そのセーブで Companion Dogs は動いておらず、犬は1匹も出現しません。

インストール

  1. Steam でMODをサブスクライブします: Companion Dogs。
  2. Zomboid のメニューで MOD を開き、Companion Dogs を有効にします。
  3. ゲームを完全に終了し（デスクトップまで戻ります）、もう一度起動します。

再起動しないと、犬はテクスチャなしか潰れた形で出てきます。MODが入る前にゲームがモデルを読み込んでしまうためです。

すでにセーブがある場合

進行中のセーブにも後から追加できます。既存のセーブは自分専用のMODリストを持っているので、そこに Companion Dogs を入れる必要があります:

  1. メインメニュー > ロード。
  2. セーブをクリックして選択します。
  3. 右下の 詳細... > MODの選択...。
  4. Companion Dogs（と使う犬種アドオン）にチェックを入れて確定します。
  5. セーブを読み込み、犬を探しに行く前に肉球ボタンを確認します。

あなたの世界の建物はまだ1軒も抽選されていないので、歩き回るにつれて犬が現れます。すでに探索済みの場所でも出てきます。

セーブからMODを外す前に、24章を読んでください。

専用サーバー

<サーバー名>.ini（Zomboid/Server/ にあります）に2行足すだけです:

WorkshopItems=3740052292
Mods=CompanionDogs

この2つは別のリストで、どちらも必要です。WorkshopItems にはWorkshopアイテムの数字のID、Mods には MODのIDを書きます。複数書くときはセミコロン区切りで、空白は入れません。

MOD Mods= WorkshopItems=
Companion Dogs（必須） CompanionDogs 3740052292
CD: Rottweiler CompanionDogsRottweiler 3762296152
CD: Doberman CompanionDogsDoberman 3770795385
CD: Labrador CompanionDogsLabrador 3779327129
CD: Pug CompanionDogsPug 3787202559
CD: Belgian Malinois CompanionDogsMalinois 未公開

本体と公開済みの犬種アドオンを入れると、こうなります:

WorkshopItems=3740052292;3762296152;3770795385;3779327129;3787202559
Mods=CompanionDogs;CompanionDogsRottweiler;CompanionDogsDoberman;CompanionDogsLabrador;CompanionDogsPug
  • どちらのリストでも本体をアドオンより先に書きます。Companion Dogs より先に読み込まれた犬種アドオンは犬種を登録できません。
  • .ini をいじったら、サーバーを完全に再起動してください。
  • プレイヤーは接続時に自動でMODをダウンロードします。手動でサブスクライブする必要はありません。必要なのはサーバーと同じゲームバージョンだけです。

Co-opのホスト

Co-op はあなたのPCで動くサーバーなので、メインメニューのMODリストは引き継ぎません。

手順1：自分のゲームでMODを有効にします。メインメニュー > MOD > Companion Dogs と使う犬種アドオンにチェック。ゲームを完全に終了して、もう一度起動します。

手順2：サーバー設定にMODを入れます:

  1. メインメニュー > ホストサーバー > 設定管理...。
  2. 使う設定を選び、選択した設定を編集 をクリックします。
  3. 左のリストで SteamWorkshop（この名前はどの言語でも英語のままです）を開きます。 インストールされているWORKSHOPアイテムをリストに追加: で Companion Dogs を選びます。まだサブスクライブしていないなら 別のWORKSHOPアイテムをIDでリストに追加: に 3740052292 と打ってEnterを押します。
  4. 同じ左のリストで Mods を開き、同じ要領で CompanionDogs を追加します。
  5. 保存 をクリックします。

この2つのリストが専用サーバーの WorkshopItems= と Mods= にあたります。画面から編集しているだけで、書き込み先は Zomboid\Server\<設定名>.ini です。IDも順番も前の節の表と同じで、本体が犬種アドオンより先です。

手順3：開始 ボタンでサーバーを起動します。参加した人は自動でMODをダウンロードします。

うまくいかないときは、犬がテクスチャなしか潰れて出るなら手順1が抜けています。誰の画面にも肉球ボタンがなく、世界に犬が1匹もいないなら手順2が抜けています。

1. 5分でわかる：野良犬から相棒へ

  1. 犬を見つけます。カラーメロの野良犬が街や住宅街をうろついています。
  2. 食べ物を持ち歩きます。腐っておらず空腹を満たせるものなら何でも構いません。
  3. 犬を右クリックして 食べ物やります (仲良くする) を選びます。
  4. 懐くまで繰り返します。大袋のドッグフードならほぼ一発、小さなビスケットなら4回ほどかかります。
  5. 名前を付けます。ここから先は勝手についてきます。

そのあとの日課はこうです:

  • 毎日ごはんと水をやります。標準では、放置しても体力は10%で止まります。サンドボックス設定の 病気や放置による死亡 をオンにすると犬は死に、二度と戻りません。
  • 撫でてやります。忠誠度を保てるうえ、あなたの退屈と悲しみも軽くなります。
  • 手のパネルの下にある肉球ボタンで犬のウィンドウを開きます。犬に関するものは全部その中にあります。

2. 犬を見つけて手懐ける

犬はたいてい建物の外側の空いたタイルに現れます。道路、庭、空き地などです。外に空きタイルが1つも残っていないときだけ屋内に出ます。

サンドボックス設定の 犬の出現率倍率 がこれらの確率をまとめて増減させます。0にすると出現が止まります。

アドオンの犬種はSteamの別MODで配布されていて、それぞれ独自の出現場所を持っています: CD: Rottweiler、 CD: Doberman、 CD: Labrador、 CD: Pug、 CD: Belgian Malinois（未公開）。それぞれの特徴は犬種マニュアルにあります。

手懐け方

野良犬を右クリックします。出てくる選択肢は 食べ物やります (仲良くする) の1つだけです。

  • 必要なのは食べ物だけです。スキルも特性も首輪も道具も要りません。
  • 食べ物はバッグの中に入っていても構いません。MODが勝手に見つけます。
  • 食べ物が複数種類あるとサブメニューが開き、それぞれのアイコンと個数が並びます。
  • 食べ物が何もないと選択肢はグレーになります: インベントリに食料アイテムが必要です。

必要な食べ物の量

与えた食べ物が満たす空腹の量が、そのまま信頼度になります。空腹を60減らすアイテムなら信頼度は 60です。手懐けに必要な信頼度は標準で100です（サンドボックス設定 手懐けに必要な信頼度）。

MODは必要な分だけかじらせ、残りはインベントリに返します。

運の要素はありません。

ゲージが満ちるまではこう出ます: カラーメロがプレーヤーに懐き始めています… 満ちるとこうなり: カラーメロがプレーヤーの相棒になりました！、名前を付ける入力欄が開きます。

体に悪い食べ物

犬に悪い食べ物はメニューで赤く表示され、 犬に悪い食べ物です。食べると体調を崩し、信頼を損ないます。 と警告が出ます。

  • 種類で判定：菓子、砂糖、コーヒー、紅茶、カカオ、チョコレート、唐辛子、ナッツ類。
  • 名前で判定：玉ねぎ、にんにく、リーキ、あさつき、エシャロット、ぶどう、レーズン、チョコレート、カカオ、コーヒー、ピーナッツ。グレープフルーツは問題ありません。

野良犬に悪い食べ物をやると信頼度が15下がり、加算は一切ありません。相棒にやると忠誠度が20下がり、ストレスが上がって、ゲーム内時間で120分のあいだ中毒になります。

相棒になった瞬間に起きること

  • 自動護衛をオンにした状態で追従モードに入ります。
  • 空腹、喉の渇き、ストレスがゼロになります。
  • 遺伝の資質はこのときに抽選され、以後変わりません。
  • 無敵になります。ゾンビも車も銃弾も炎も殺せません。放置と、手当てされない傷の感染（7章の「傷と包帯」を参照）で死ぬのは、サンドボックス設定の 病気や放置による死亡 をオンにしたときだけです。標準では体力は10%で止まります。
  • マイコンパニオン の登録簿に入り、マップにも表示されるようになります。

別の犬を手懐けても前の犬は離れません。新しい犬がアクティブになり、前の犬は控えに回って待機モードに入ります。複数の犬を同時に飼うを参照してください。

頭数の上限

サンドボックス設定の プレイヤー1人あたりの最大頭数 は初期値0、つまり無制限です。サーバーが上限を設けている場合、そこに達すると仲良くする選択肢が赤くなって使えなくなります: 相棒の上限に達しています（5）。（数字は設定された上限です）。手放すか失えば枠が空きます。

MODはゲームのエモートメニューに相乗りします。Qを長押しすると、あなたの犬の犬種名と肉球アイコンが付いた新しいカテゴリが出ます。このカテゴリは近くにアクティブな犬がいるときだけ現れます。

4. 3つのモード：従う、待て、見張れ

犬は常にこの3つのどれかにいます。見張り、狩り、自動護衛はモードの上に重ねる設定です。

従う

初期状態です。あなたの後ろを歩きます。距離が2マス開くと歩き出し、6マスを超えるか、あなたが走り出すと走ります。

  • あなた（犬ではなく）を中心とした半径5マスの中でゾンビと戦い、8マスで対象を離します。
  • 低い柵を越え、階段を上り、階を移動して追いかけてきます。
  • 一緒に車に乗り込む唯一のモードです。
  • あなたが24マス以上離れると、建物の反対側で立ち往生しないよう、あなたの後ろに引き寄せられます。

コマンドタブの 追従距離 スライダーは2マスから8マスまで、0.5刻みで動きます。初期値の2は犬をぴったり足元に付かせます。広げるとキッチンや廊下や戸口であなたの邪魔にならなくなり、大型犬ほど効果があります。設定は犬ごとで、その個体に保存されます。ゲームを終了して再開しても、犬舎に預けても、ワールドを移っても残ります。距離を広げると走り出す位置が遠くなるので、ゾンビに届くまで時間がかかります。

カラーメロはプレーヤーの後をついてきて、近づいたゾンビと戦います。見張り機能も働き続けます。標準設定で、移動中の相棒の状態です。

待て

その場に止まり、動きません。1分ほど止まったままだと伏せます。

  • においを嗅ぎ続け、ゾンビを知らせます。
  • 目の前にゾンビがいても追わず、戦いません。
  • あなたが車に乗ると置いていかれます。
カラーメロはその場にとどまり、ついてきません。ゾンビを察知して警告はしますが、追いかけたり戦ったりはせず、ただ座って見張るだけです。安全な場所に待機させておくのに向いています。

見張れ

今いる地点を持ち場として記録し、そこを守ります。

  • 持ち場から半径10マスのゾンビと戦い、追いかけたあと戻ります。
  • 追い詰められるとあなたの後ろに下がります。
  • 今のところ、あなたが近くにいる間だけ働きます。
カラーメロはこの正確な地点に居座って守ります。より広い範囲のゾンビと交戦し、警告を発し、追跡の後は持ち場に戻ります。囲まれた場合はプレーヤーの後ろに下がります。

6. 戦闘

自分から戦う条件

犬は勝手に攻撃を始めません。きっかけを待ちます:

  • 追従中は、自動護衛がオンで、しかもゾンビがあなたか犬を狙っているか、あなたがすでに戦っている場合だけです。ゾンビはあなたから5マス以内にいる必要があります。
  • 見張り中は、持ち場から10マス以内なら常に戦います。
  • 近くを攻撃 の命令では、半径12マスから相手を探し、ゲーム内時間で2分間追いかけます。

攻撃するのは敵対的なゾンビだけです。他のMODの友好NPC（Bandits、A-Life）には手を出しません。

壁越しには噛みつかない

犬は歩いてたどり着ける相手にしか向かいません。柵の向こうや閉じた部屋の中にいるゾンビは無視します。向かおうとして2秒半のあいだ前進できなければ、その相手をあきらめ、12秒のあいだ無視します。

ダメージの大きさ

ダメージは4つの掛け算で決まります。犬種の生まれ持った力、戦闘レベル、筋力の遺伝、そしてサンドボックスの倍率です。

  • カラーメロは自力でゾンビを倒せません。体力を10%残したところで止まり、これはサンドボックスをどういじっても変わりません。
  • ほかの犬種はとどめまで刺せます。
  • 衰弱した犬、つまり3日間タンパク質を摂っていない犬は、ダメージが半分になります。そのせいでとどめを刺せず、ゾンビに張り付いたままになりがちです。

犬種ごとのダメージ表は犬種マニュアルにあります。

一撃ごとにゾンビを転ばせる確率があり、10%から始まって戦闘が最大で50%まで上がります。

自動護衛

犬ごとにオンオフします。オンにすると、あなたが無防備なあいだ犬が護衛につきます:

  • 睡眠中
  • 読書中
  • 地面に座っているとき
  • 食事中
  • 釣り中

犬はあなたのそばに位置を固定し、近づくものを迎え撃ちます。あなたが動けば位置も付いてきます。行動が終われば自分から追従に戻ります。

  • 見張り中の犬はこのために持ち場を離れません。
  • この戦い方は犬にストレスを与え、忠誠度も上がりません。

手懐けた時点ではオンになっています。

あなたの銃弾は当たらない

相棒の犬は、あなたの銃でも他のプレイヤーの銃でも、どんな状況でも体力を失いません。

  • 自動照準の対象から外れているので、狙いを付けても犬に吸い付きません。
  • シングルプレイでは発砲の瞬間にMODが犬を弾の判定から外し、弾は後ろのゾンビへまっすぐ飛びます。

そのために犬が動く必要はなく、あなたに反撃することもありません。

マルチプレイで遠くから撃つと、他のプレイヤーの犬が反応しているように見えることがありますが、体力は減っていません。

負傷、後退、パニック

  • 戦っても犬の体力はその場では減らず、ストレスがたまるだけです。噛みつくたびに、わずかな確率で出血します。
  • 体力が減るのは、放置（空腹か喉の渇きが0.8超）、有害な食べ物、狩りで鹿に反撃されたとき、そして健康の節にある症状です。放置と手当てされない感染が死につながるのは、サンドボックスで 病気や放置による死亡 をオンにしたときだけです。オフ（初期値）なら体力は10%で止まります。
  • 負傷の状態は、体力30%未満で 負傷、10%未満で 重傷 です。重傷の犬はついてくるだけで戦いません。
  • 体力が10%以下になると、あなたの後ろに下がります。
  • ストレスが高いとパニックに入り、戦わず、見張らず、芸もしません。呼べば走ってはきます。ストレスがしきい値をかなり下回るまでパニックは解けません。

討伐数

犬はそれぞれ自分の記録を持っていて、ウィンドウで見られます: 討伐数：ゾンビ 14体、獲物 3匹。

犬が倒したゾンビはキャラクター画面のあなたの記録にも加算されます。

自然回復

犬は自然に回復します。ゲーム内時間で8時間ほどで体力ゲージが1本埋まります。空腹か喉の渇きがゲージの半分を超えると回復は止まります。

傷と包帯

  • ゾンビを噛むたびに0.4%の確率で開いた傷を負います。戦闘レベルが上がるごとにこの確率は0.02ポイント下がり、レベル10で半分の0.2%になります。すでに負傷していたり、ストレスが高いと確率は上がります。ゲーム内時間で2時間に1回より多く傷を負うことはありません。
  • 犬はどの犬種でも足を引きずって歩き、少し遅くなります。歩きは10%、走りは25%遅くなります。名前とウィンドウとムードルに 出血 の表示が付き、包帯を巻くと 負傷 に変わります。犬のウィンドウの 健康状態 タブには、傷ついた脚を塗り分けた犬のシルエット、部位の一覧、今ある症状が出ます。そこを右クリックすると手当てのメニューが開きます。状態タブの健康の節には症状、包帯の有無、やるべきことが出ます。動物福祉が5以上なら、どちらにも治り具合が表示されます。
  • 負傷すると、治るまで狩りと見張りを断ります。従う、待て、攻撃はそのままです。
  • 傷を開いたまま戦い続けると、噛みつくたびに脚を折ることがあります。確率は傷を負う確率と同じです。脚を骨折しました！ の警告が出て、脚の骨折 の表示とムードルが付き、歩幅は半分になり、どんな状況でも走らなくなります。治るまでは、包帯を巻いていても3日かかります。
  • 出血したまま包帯を巻かないと体力が減り（1日でゲージの90%、1日と少しで1本まるごと）、包帯を巻くまで回復しません。ゼロになると死にます。これはどの段階でも同じで、感染した傷も包帯がなければ出血と感染が同時に進みます。
  • 包帯なしでも12時間で出血は自然に止まり、表示は 開いた傷 に変わります。傷は開いたままで、感染することもあります。包帯を巻けば出血はその場で止まります。

  • 手当ては犬を右クリックして 傷を治療する、または状態タブの健康の節で症状を右クリックします。包帯か裂いたシーツがインベントリにあれば使えます。アルコール消毒された包帯を使うか、消毒液、消毒シート、アルコール綿を持っていれば滅菌済みの包帯になります（それらも一緒に消費されます）。応急医療が高いと手当てが早く終わります。手当てすると忠誠度が上がります。包帯は犬に残り、包帯を外す を使ったときか傷がふさがったときに、汚れた状態であなたのインベントリへ戻ります。傷ついた脚には、出血中は赤い切り傷が、包帯を巻くとガーゼの帯が見えます。本体MODの全犬種でも犬種アドオンでも同じで、どれも傷ついた脚を引きずります。汚れた包帯でも役に立ちます。
  • きれいな傷は2日でふさがり、包帯があれば1日です。じっとしている犬（待て、または家で控えている犬）は最速で治り、働いている犬は半分の速さ、戦闘中の犬は治りません。農場の世話をしている犬は家で控えている犬と同じ速さです。犬舎に預けた犬だけは、世界から出るので止まります。

感染：発熱、危篤、そして死

  • 感染は放っておくと悪化します。感染から12時間で、包帯の有無にかかわらず発熱が始まります。 発熱 の表示が付き、歩きが20%遅くなり、体力の減りが速まります（感染だけなら1日でゲージの 4分の1、発熱なら半分）。危篤かどうかは体力だけで決まり、感染していて体力が10%を切ると、犬は伏せたまま起き上がらず、従う、来て、攻撃を断ります。体力がゼロになれば死にます。 病気や放置による死亡 がオフ（初期値）なら、どの病気も、空腹も喉の渇きも、体力を10%より下げません。
  • 包帯は感染を治さず、発熱も止めません。放置した場合、感染は発症から2日で自然に消えます。 Companion Dogs 抗生物質 なら12時間に縮まり、ゲーム本体の抗生物質も同じ時間で治します。同じ成分で、足りないのは犬の体重に合った量だけです。そのため人間用は、与えた瞬間に25%の確率で胃を壊します（ワクチン接種済みの犬にはこの心配はありません）。抗生物質が効いているあいだ、発熱は進みません。感染が治っても傷は開いたままで、普通のペースでふさがります。
  • Companion Dogs ワクチン を打つと90日間、傷は感染せず、悪い食べ物や汚れた水でも胃を壊さず、インフルエンザにもかかりません。ムードルは ワクチン接種済み です。

捻挫

  • 柵を越えるたびに0.5%の確率で脚を捻挫します（負傷中やストレスが高いともっと上がります）。傷のときと同じように足を引きずって遅くなりますが（歩き-10%、走り-25%）、戦うことはできます。狩りと見張りは断ります。
  • 治るのは休養だけです。待てか控えなら半日、あなたについて回り続けるなら丸1日かかります。戦闘中は回復が止まります。脚の骨折は別で、柵も越えず、戦いもしません。

胃の不調と寄生虫

  • 手渡しで腐った食べ物をやると必ず胃を壊します。傷みかけの食べ物と、ゲーム本体の汚れた水（あなたを中毒にする水）はそれぞれ25%で、水は餌皿でも手渡しでも同じ扱いです。判定は犬ごとに 12時間に1回です。きれいな水を入れ直せば止まります。
  • 1日から2日続き、時計が進むのは犬が水を飲んでいるあいだだけです（喉の渇きが半分未満）。そのあいだは空腹と喉の渇きが倍の速さで進み、体力は回復せず、繁殖もせず、狩りと見張りを断ります。表示は 胃の不調 です。
  • ゲーム本体の草の束を 傷を治療する のメニューからやると、胃の不調の残り時間が8時間縮み、悪い食べ物による中毒も短くなります。
  • 寄生虫は胃の不調の副作用ではなく、その成れの果てです。胃の不調のまま6時間過ごすごとに10%の確率で寄生虫が住み着くので、草で早めに治せばそこで断ち切れます。寄生虫が付くと空腹が40%速く進み、放っておいても決して治りません。Companion Dogs 駆虫薬 を1回やれば解決します。錠剤は効き始めるまでに4時間かかり、そのあと30日間は、胃の不調が続いていても新しい寄生虫が住み着きません。寄生虫が付く前に、予防として与えることもできます。保護が続くあいだ、犬は残り日数付きの 駆虫済み ムードルを表示し、ウィンドウの表にも同じ数字が出ます。

インフルエンザ

  • かかり方は2つです。ひどく空腹な犬（0.8超）は1日15%で発症し、病気の犬から1マスの距離にいる健康な犬は接触1時間ごとに15%です。ワクチン接種済みの犬はかからず、うつしもしません。
  • 2日から4日続き、自然に治ります。そのあいだずっと発熱します。犬は水を20%多く飲み、歩きが20% 遅くなり、体力は回復せず、繁殖もせず、狩りと見張りを断ります。表示とムードルは 発熱、さらにムードル インフルエンザ が付きます。
  • すでにかかっている犬に Companion Dogs ワクチン を打つと、感染の広がりはその場で止まり、そこから1日で治ります。抗生物質は獣医用でも人間用でも、1回分が終わったところでインフルエンザを 40%短くします。休養は効きません。時計はじっとしていても付いて回っても同じです。水は効きます。発熱で喉が渇くからです。

フィラリア

  • 蚊が刺すのは屋外だけです。屋根の下から出たまま6時間続くごとに1.5%の判定があり、屋内に入ると数え直しになります。このMODで一番重い病気です。
  • 3日から6日続き、自然に治ります。その間、1日に体力ゲージの4分の1を削り、発熱させ、歩きを65%、走りを45%まで落とします。犬は攻撃も、芸も、狩りも、見張りも断ります。発症したその場で狩りと見張りの任務を投げ出します。ムードルは フィラリア症 です。
  • コンパニオンドッグ用フィラリア予防薬 を使えば18時間で治ります。同じ1回分が 30日間の予防にもなり、健康な犬に与えられます。現実でもそうやって防ぎます。

アレルギー、ノミ、ダニ

  • 犬はそれぞれ、受け付けない肉の種類を1つだけ持つことがあります。犬の一生に一度の抽選で、5%の確率で鶏、牛、魚、またはほかの肉にアレルギーを持って生まれます。以後、その肉を食べるたびに症状が出ます。どの食べ物かはウィンドウの表に出ます。
  • 症状は12時間から24時間続きます。犬は体をかき、ストレスがたまり、負傷したときのように動きます（歩き-10%、走り-25%）。放っておいても治ります。コンパニオンドッグ用アレルギー薬 なら 6時間で収まり、2日間予防します。表示とムードルは アレルギー です。
  • ノミとダニは接近戦で付きます。犬が噛みつくたびに0.2%の確率でどちらかが付きます（負傷中やストレスが高いともっと上がります）。2日間は1時間ごとに悪さをして、そのたびにストレスと3%のアレルギー発症確率を与えます。ダニはそのほぼ倍です。そのあとはおとなしくなりますが、自然にいなくなることはありません。
  • コンパニオンドッグ用ノミ・ダニ駆除薬 は両方を12時間で落とし、30日間予防します。表示とムードルは ノミ と ダニ です。

薬：どこで手に入り、どうやるか

  • 全部で6種類あり、どれも1箱で複数回ぶんです。抗生物質は12回、駆虫薬は8回、ワクチンは6回、アレルギー薬は24回、ノミ・ダニ駆除薬は12回、フィラリア予防薬は6回です。治療1回につき1回ぶん使います。
  • 出てくる場所は薬棚、薬局、病院、店の棚、軍の倉庫、ペットショップ、ペット用品の箱、家の浴室、ガレージ、農場です。動物病院では、ワクチンとフィラリア予防薬は机でも4.8%、犬小屋でも1つあたり2.4%の確率で見つかります。
  • どれも同じ 傷を治療する のサブメニューか、ウィンドウの健康の節から与えます。症状を右クリックすると、持っているもので何ができるかが出ます。
  • 薬は飲ませた瞬間には治りません。数時間かかる治療が始まり、それが終わってはじめて病気が消えます。そのあいだウィンドウには 治療中 の行が出ます。予防も兼ねる薬なら、残り日数付きで 保護中 の行が出ます。
  • 飼い主の応急医療と動物福祉は、合計してレベルごとに治療を5%短くし、予防を2.5%伸ばします。病気の犬を手当てすると応急医療の経験値が入ります。健康な犬への予防投与では入りません。
  • 飼い主がそばで眠っていると、健康な犬の体力回復が倍になります。感染している犬には効きません。

放置したときの階段

犬をほったらかしにすると、こうなります:

  2. 忠誠度の減りが3倍の速さになります。
  3. 半分を超えると自然回復が止まります。
  4. 0.8を超えると、ゲーム内時間で8時間ほどかけて体力が減ります。標準では10%まで、 病気や放置による死亡 を入れているとゼロまで落ちます。
  5. 忠誠度が下限を割り、犬は 不服従 になります。
  6. ストレスが上がってパニックに入り、戦わず、見張らず、芸もしなくなります。
  7. その設定を入れていると、体力がゼロになって死にます。

死は取り消せません。カラーメロが死亡しました。 サドルバッグと中身は全部地面に落ちます。ほかに犬がいれば、その犬が自動でアクティブになります。

喪失

絆を結んだ犬が死ぬと、キャラクターは喪に服します。犬の名前が入った 喪失感 のムードルが出て、悲しみが一気に上がります。これをオフにする設定はありません。

9. 忠誠度

忠誠度は0から100までで、犬がどれだけあなたを信頼しているかを表します。

  • 放っておくと1日に12ポイントほど下がり、空腹や喉の渇きがあると3倍の速さで下がります。
  • 上がるのは、ごはん、水（+2）、撫でること（+2）だけです。
  • いちばん速いのはごはんですが、上がり幅は満たした空腹の量に比例します。腹ぺこの犬に食べさせると、一度に何十ポイントも戻ります。忠誠度が落ちているなら、腹を空かせてから食べさせてください。
  • 餌皿から食べても忠誠度は上がりません。

不服従の下限

ある値を下回ると犬は 不服従 になり、従うことも戦うことも芸もしなくなります: カラーメロはもうプレーヤーに信頼していません…

この下限は服従が上がるほど下がります。30から始まり、1レベルごとに1.5下がって、10を下回ることはありません。服従10の犬なら、忠誠度が15を割るまで不服従になりません。

命令を断られるとき

理由は4つあり、この優先順で判定されます:

状況 表示されるもの
忠誠度が下限を下回っている レックスはプレーヤーを十分に信頼しておらず、従いません。
ストレスがパニック域 レックスはパニック状態で戦えません。
体力が10%以下 レックスは重傷すぎて戦えません。
訓練の失敗 レックスは気を取られて言うことを聞かない。

10. 餌皿：あなたがいなくても食べて飲む

餌皿を置いておけば、アクティブな犬は自分で食べて飲みます。

空腹と喉の渇きを感じるのはアクティブな犬だけです。複数の犬を同時に飼うを参照してください。

使い方

  1. 餌皿を手に入れます（クラフトか拾得。MODのアイテムを参照）。
  2. インベントリで右クリック → 餌皿を設置。自由に置ける設置カーソルが出て、Rキーで向きを変えられます。
  3. 餌皿を右クリック → 皿に食べ物を追加 または 皿に水を追加。

餌皿に入るのは食べ物か水のどちらかで、両方は入りません。入れ替えるときは ボウルを空にする を使います。

モデルを見れば中身が分かります。空ならグレー、フードなら茶色、水なら青です。

餌皿に入れられるもの

腐っておらず空腹を満たせるものならほぼ何でも入ります。肉、缶詰、調理済みの料理、野菜、果物、卵、ドッグフード、それに草と干し草も入ります。

除かれるのは体に悪い食べ物のリストで、メニューでは赤く表示されます。

未開封のドッグフードの缶はリストに出ません。先に缶を開けてください。

餌皿は100ポイントまで貯められます:

アイテム ポイント
ドッグフードの袋 60
開けたドッグフードの缶 30
干し草 12
草 7

肉、魚、卵、ドッグフードを入れた分はタンパク質として記録され、犬がその部分を食べたときに、手渡しでやったのと同じようにタンパク質の時計へ反映されます。野菜だけの餌皿は空腹を満たすだけで、それ以上のことはしません。

入れるものが残り容量より大きい場合、餌皿は満杯まで入って残りが手元に戻ります。80ポイントの餌皿にドッグフードの袋を入れると、餌皿は100になり、袋は40ぶんの価値でインベントリへ戻ります。メッセージ ボウルにはそれを全部入れる余裕がありません。 が出るのは、餌皿が完全に満杯のときだけです。

犬の使い方

  • 空腹か喉の渇きが0.5に達すると自分で向かいます（設定タブのスライダー 空腹／喉の渇きがこの値に達すると食べる でキャラクターごとに調整できます）。
  • 半径16マスから餌皿を探します。MODの餌皿でも、ゲーム本体の飼い葉桶でも構いません。
  • 1回でゲージの半分が埋まります。食べているのはゲーム内で3分ほどです。
  • 餌皿へ向かっているあいだと食べているあいだは、ゾンビもほかの何もかも無視します。止められるのはあなたの命令だけです。空腹でパニックになっていた犬は、食べればパニックが解けます。

犬の頭の上には 食事へ向かっている、食事中、水へ向かっている、水を飲んでいる と出ます。

餌皿から食べても忠誠度は上がりません。

餌皿はあなたの飲み水にはならず、雨で満ちることもありません。流し台や蛇口からも入れられません。そこでゲームが出す給水の操作は餌皿には効きません。水が入る手段は 皿に水を追加 だけで、水の入った容器をインベントリに持っている必要があります。

寝ている間に探してくる（服従 10）

アイテムを手に持ってセットします: カラーメロは寝ている間に釘抜き金づちを探します。 頭の上にはずっと 探索中: 釘抜き金づち の表示が残ります。

  • ゲーム内1日に1回です。あなたが起きた直後、犬がそばにいるときに発動します。
  • 成功率はアイテムの珍しさで決まり、100%にはなりません。いちばんありふれたアイテムでも1晩あたり最大50%です（平均で2日ほど待つ計算です）。斧くらいの珍しさなら15%前後、刀のような希少品だと 2%前後です。
  • 成功すると 眠っている間にカラーメロが釘抜き金づちを持ち帰りました。 と出て、アイテムはサドルバッグの中に入り、緑の表示 持ち帰り: 釘抜き金づち が付きます。
  • 失敗すると カラーメロは釘抜き金づちを持たずに戻りました。 と出て、赤い表示 手ぶらで帰還 が付きます。

セットする時点で弾かれるものが2つあります:

  • 重すぎるアイテム: カラーメロは鍛冶用金床を運べません。
  • ゲームの戦利品テーブルに存在しないアイテム: カラーメロはそれをどこで探せばいいか分かりません。

13. 狩り

狩りモードは初期状態でオフで、犬ごとにオンにします。切り替えはラジアルメニュー、キー、コマンドタブのボタンから。 レックスは近くの獲物を狩ります。

狩れる相手

獲物 必要な狩りレベル
ウサギ、アライグマ、ネズミ、リス 3
鹿（子鹿、雌鹿、雄鹿） 6

それ以外の野生動物は指し示すだけで、狩りません。

実際の動き

レベル0、1、2では指し示すだけで、獲物には触れません。一度吠えてから獲物の近くまで小走りで行き、止まってポインティングの姿勢を取り、数分そのまま指し続けます。そのあとあきらめて戻ります。通知: カラーメロが近くで獲物を見つけました…

序盤はこうやって狩りを覚えます。

レベル3になると小型の獲物を仕留め始めます。

  • 空腹なら獲物をその場で食べます。あなたの取り分はありませんが、犬の空腹は満たされ、丸ごと1匹の新鮮な肉なのでタンパク質の時計がゼロに戻ります。
  • 空腹でなければ、あなたの手柄として仕留め、狩りが終わった場所に皮を剥げる死骸を残します。通知は カラーメロが獲物を仕留めました！ です。

レベル6になると仕留めた獲物をあなたのところまで運んでくるようになり、獲物を運んでいる の表示と カラーメロが仕留めた獲物をプレーヤーのところへ運んできました。 のメッセージが付きます。

鹿だけは別扱いです。鹿はどのレベルでもどの犬種でも運びません。犬は鹿を瀕死まで削り、そのまま押さえてあなたがとどめを刺しに来るのを待ちます: カラーメロが鹿を負傷させました。とどめを刺してください！ と出て、獲物を押さえている の表示が付きます。ゲーム内20分たってもあなたが来なければ犬が自分で仕留め、手柄はあなたのままです。鹿が逃げた場合は追跡します: カラーメロが手負いの獲物を追跡しています…

ラブラドールはレベル3から獲物を届け、途中で放り出すまでの粘りも長めです。詳しくは犬種マニュアルを見てください。

鹿は反撃してきます。4回に1回ほどの突進が犬を傷つけてストレスを上げますが、死ぬまでには至りません。

制限

  • 獲物がいるのは森と野原で、街にはいません。
  • 追従モードでしか働きません。
  • 範囲は32マスです。離れすぎるとあきらめて戻り、ゲーム内20分休みます（表示は 狩り：休憩中）。
  • 時間の早送り中、あなたが寝ているあいだ、車内、そしてあなたが命令を出してから5分間は狩りません。
  • すでにゾンビと戦っている犬は狩りを考えません。逆に、通りかかっただけのゾンビでは狩りを中断しません。あなたが戦闘に入るか自動護衛が発動すると獲物を放します。あなたの命令はどれも狩りをその場で打ち切ります。
  • 狩りは犬の腹を減らします。
  • 追跡中の吠え声はゾンビを引き寄せ、これはオフにできません。

採集のボーナス

2つのボーナスは、どちらもゲームの探索モードがオンのときだけ現れます。

a) 採集ポイントを見つけます（狩りモードのときだけ）。近くに獲物がいないと、犬は動物系の採集ポイントを探し、そこまで行って吠え、その場所を指し示します: カラーメロが何かを見つけました！探索モードをオンにすると確認できます。 表示は 採集物を探している。

拾うのはあなたです。

b) あなたの採集範囲を広げます（犬種を問わず、常に働きます）。自分の犬がそばにいて、忠実で、空腹も喉の渇きもひどくなければ、それだけで効きます:

  • 狩り0で範囲が6マス広がり、狩り10で12マス広がります。
  • 動物、昆虫、足跡、死骸のカテゴリがかなり見つけやすくなります。

ゴールデンレトリバーはさらに4マス上乗せします。

14. 家畜の世話

このモードでは、犬が囲いに残って群れの面倒を自分で見ます。

割り当て方

  1. 指定された動物エリア（ゲーム本体の囲い）を作ります。
  2. その中に犬を連れて行きます。
  3. 右クリック → ここで家畜の世話をさせる。
  4. 確認します。犬の選択が解除されて、もうついてこなくなる旨の説明が出ます。

囲いがないとこう出ます: レックスが家畜の世話をするには、ここに指定された動物用の囲いが必要です。

犬がそこですること

  • 囲いを見回ります。
  • 群れを落ち着かせます。これがこの仕事の本体で、ストレスを危険な値の下に抑えます。ストレスの高い動物は乳も羊毛も出さず、流産し、ゾンビが来ると散り散りになります。
  • 半径12マスのゾンビを音を立てずに片付けます。
  • あなたがマップの反対側にいても働き続けます。

通知は レックスが囲いの近くにいるゾンビを察知しました！ と レックスが見守っている群れがストレスを感じています！ です。頭の上の表示は 家畜の世話 です。

押さえておくこと

  • 任務中は空腹、喉の渇き、忠誠度の減少がすべて止まります。
  • ほかのことは一切しません。あなたのために戦わず、狩らず、見張らず、餌皿も使いません。
  • 訓練不足の犬、忠誠度の低い犬、パニック中の犬は、落ち着かせるどころか群れを不安にさせます。
  • もう一度その犬を選択するとモードは解除されます。

ボーダー・コリーは牧畜をほかの犬種の2倍の速さで覚えますが、この仕事はどの犬種でもこなせます。

15. サドルバッグ：荷物を運ぶ犬

装着のしかた

  1. 犬用サドルバッグ をインベントリに入れます。
  2. 犬を右クリック → サドルバッグを装着。サドルバッグを装着した。
  3. 開くとき: サドルバッグを開く（ラジアルメニューのスライスや、コマンドタブのボタンからでも開けます）。
  4. 外すとき: サドルバッグを外す。中身が入ったまま地面に落ちます。

積める量

容量は固定の基礎値に犬の筋力遺伝子を足して決まります。標準設定では次のとおりです:

犬種 積載量（重量）
パグ 2～3
カラーメロ 4～5
ゴールデンレトリバー 6～7
ジャーマンシェパード、ボーダー・コリー、ロットワイラー、ドーベルマン、ラブラドール、マリノア 6～8
ハスキー 13～16

サドルバッグに犬種ボーナスがあるのはハスキーとパグの2犬種だけで、ハスキーは50%多く運び、パグは 40%少なく運びます。同じ犬種の2頭でも積める量は違います。

サーバー側はサンドボックス設定の サドルバッグ倍率 でこれら全体を調整できます。0にするとサドルバッグはただの飾りになります。

しまえるもの

ほとんど何でも入ります。制限は重量だけで、アイテムの数ではありません。例外は次のとおりです:

  • ほかのサドルバッグ。
  • 装備中のアイテム（着ている服、手に持った武器）。
  • リュックやバッグ類。バッグそのものではなく、中身をしまってください。

書き込んだ地図をしまうと、書き込みは失われます: 地図の書き込みは鞍袋に保存されません。

ウィンドウ

2つのリストが左右に並びます。左が プレーヤーの所持品（クリックで預ける）、右がサドルバッグ（クリックで取り出す）です。下部には 積載: 7/12 と出ます。

入手のしかた

クラフト: 革ひも2 + 針 + 糸（針と糸は消費されません）。裁縫針はどれでも使えますし（普通の針、骨の針、真鍮の針、鍛造の針）、糸もどれでも構いません（普通の糸、アラミド糸、腱の糸）。カテゴリは裁縫で、裁縫レベル1が必要です。裁縫の経験値が15入ります。

拾い物: ペットショップ、ペット用品の箱、キャンプ用品店、狩猟用ロッカー、サバイバルキット、ガレージの工具、農場の箱に出ます。

犬が死んだり野生に戻されたりすると、サドルバッグも中身も、その犬がいた場所の地面に落ちます。

16. 繁殖と子犬

"交配させる"ボタンはありません

繁殖は放っておいて進みます。条件を整えて待つだけです。

ゲーム内で1時間ごとに、条件を満たしたメスは、近くに条件を満たしたオスがいれば妊娠する可能性があります。標準は1日あたり5%です（サンドボックス設定の 1日あたりの繁殖確率）。

条件

2頭ともに、すべて必要です:

  1. 同じ種であること。犬は犬と、ネコはネコとだけです。
  2. どちらも同じ飼い主の相棒であること。
  3. オスとメスで、どちらも成体であること。
  4. どちらも 繁殖を禁止 が入っていないこと。
  5. 同じ階にいて、互いに40マス以内であること。
  6. どちらもひどい負傷や中毒の状態でないこと。
  7. どちらも空腹と喉の渇きが危険域に入っていないこと。
  8. メスが妊娠中でなく、出産後7日の休みも終わっていること。
  9. 犬の上限に空きがあること。
  10. その場所があなたの近くで読み込まれていること。

交配と妊娠期間

メスはオスのところまで歩いていき（レックスが交配相手へ向かっています）、近づいたところで妊娠します: レックスが妊娠しました。

  • 妊娠期間は標準でゲーム内4日です。
  • メスが遠くにいても、あなたがオフラインでも、時計は進みます。
  • 頭の上とメニューに、ピンク色で 妊娠中 が出て、終わりが近づくと 出産間近 になります。この2つはステータステキストを切っていても表示されます。

出産

母親の犬種 産まれる数
カラーメロ 2～4
ボーダー・コリー 1～3
ジャーマンシェパード、ゴールデンレトリバー、ハスキー 1～2

レックスが子犬を産みました。そのあと母親はゲーム内7日休んでから、また妊娠できるようになります。

サーバーに犬の上限があって空きが足りない場合、産まれる数はその枠に収まるまで減らされ、妊娠そのものは同じように終わります。標準は上限なしです。

子犬が受け継ぐもの

  • 血統は両親の平均です。カラーメロとジャーマンシェパードなら50/50。その雑種と純血のシェパードなら25/75になります。
  • 見た目は血統を重みにした抽選で決まります。75%シェパードの子犬は、たいていシェパードに見えます。
  • 遺伝子は両親の中間に、上下6%ほどのぶれが乗ります。手持ちで一番強い2頭を掛け合わせ、世代ごとに繰り返せば、血統の平均は少しずつ上がっていきます。
  • 2つ以上の犬種が混ざった犬は ミックス と表示され、ウィンドウにその比率が出ます（ハスキー50%、ジャーマンシェパード50%）。
  • 血統書も残ります。世代と、父親と母親の名前と犬種です。

子犬を育てる

  • 生まれたときは待機状態（待てモード）で、忠誠度は50、スキルはゼロ、見た目もはっきり小さいです。
  • 生まれた時点から犬の上限に数えられます。
  • 成体になるまでゲーム内90日かかります。読み込まれていない間に期限が来た場合は、あなたが近づいた時点で成体になります。
  • 大きくなっても名前、絆、遺伝子、スキルはそのままです: レックスが成犬になりました。
  • 成長を止める を入れている間、子犬はその大きさのまま固定されます。 永遠に大人にならない犬？現実にもこの設定が欲しいよ :D

23. よくある不具合

「犬がテクスチャなしで、ぐしゃぐしゃに出てきた。」メインメニューのMods一覧でmodを有効にして、セーブを読み込む前にゲームを完全に終了してください。協力プレイで一番よく起きる問題です。

「modを入れたのに、セーブに何も出てこない。」あとから足したmodは、すでに作ったワールドには入りませんし、ゲームは何も教えてくれません。セーブの読み込み画面で、そのワールドにmodのチェックが入っているか確認してください。

「犬が言うことを聞かない。」メッセージを見てください。「十分に信頼しておらず」なら忠誠度です。餌をやり、水をやり、撫でてください。「気を取られて言うことを聞かない」なら訓練不足で、もう一度命令すれば 2回目は通ります。パニックか負傷なら、先にそちらを治してください。

「犬が衰弱になって戻らない。」ゲーム内で3日以上タンパク質を摂っていません。まともな食事を出すか、ドッグフードを餌皿に入れてください。効くのは量です。タンパク質を見てください。

「犬がゾンビを倒さず、転ばせるだけ。」カラーメロは転ばせるだけで、これはどの設定でも変わりません。とどめはあなたが刺します。ほかの犬種は自力で倒します。

「犬がしょっちゅう吠えてゾンビを連れてくる。」見張りを静かにすれば吠えません。どの吠え声もゾンビを引かないようにするなら、サンドボックスの「犬の物音がゾンビを引き寄せる」を切ってください。全犬種に効きます。

「犬がいなくなった。」 / 「犬が柵の向こう側で動けなくなっている。」どちらも呼び寄せるで片付きます。肉球ボタンでウィンドウを開き、「マイコンパニオン」タブに行ってください。口笛はゾンビを引き寄せます。詳しくは複数の犬を同時に飼うにあります。

「犬が妊娠しない。」繁殖の条件を確認してください。空腹と喉の渇きが邪魔をするのは赤いときだけで、忠誠度は関係ありません。「繁殖を禁止」が入っていないかも見てください。犬は犬とだけ、ネコはネコとだけ交配します。

「子犬が大きくならない。」その子犬に「成長を止める」が入っていないか確認してください。あとは時間だけで、標準はゲーム内90日、時計は犬が遠くにいても進みます。期限がもう過ぎているなら、犬に近づいてください。読み込まれた時点で成体になります。

「犬が一緒に車に乗ってくれない。」乗るのは従うの犬だけです。

「拠点を見張らせておいたのに何もしなかった。」見張れモードは、いまのところあなたが近くにいるときしか働きません。離れていても働く唯一のモードは「ここで家畜の世話をさせる」で、こちらは指定された囲いが要ります。

「犬の覚えが遅すぎる。」「スキル経験値倍率」の標準は0.5です。新しいワールドで1.0以上に上げてください。

「犬が死んだ。」死んだ犬は戻りません。空腹、喉の渇き、手当てされない病気で死ぬのは、サンドボックス設定の「病気や放置による死亡」がオンのときだけです。標準ではオフで、体力は10%で止まります。サドルバッグと中身は倒れた場所の地面に残ります。

「modを入れたら持てる重さが変わった。」 Companion Dogsはあなたの最大重量に触りません。サーバーではゲーム本体の癖があり、筋力を無視した低い値に容量が固定されたまま、キャラクターが最初のダメージを受けるまで戻りません。

24. セーブからmodを外す（先に読んでください）

犬がいるセーブからCompanion Dogsを外すと、modと関係のない動物まで消えます。囲いの家畜、鶏、そのあたりの地域にいたものです。Project Zomboidの動物の保存のしかたがそうなっていて、外されたあとのmodには手の打ちようがありません。

なぜ起きるか

ゲームはマップの広い地域にいる生きた動物を、ひとつのファイルにまとめて保存します。modなしでそのファイルを開くと、犬を見つけ、その種類が分からず、残りを読むのをあきらめて、その地域を一度も行ったことがない場所として作り直します。あなたの動物が消えるのは、犬と同じファイルに入っていたからです。

失われるのはその地域で犬より後ろにあったものだけで、それ以上ではありません。だから結果はセーブごとに違います。

ロットワイラー、ドーベルマン、ラブラドール、パグ（ほかのどれでも同じです）だけ購読を外して、基本modのまま遊び続けた場合も同じことが起きます。その犬種の犬がセーブに残っているからです。

もう動物が消えてしまったら

遊び続ける前、セーブする前に、いますぐmodを入れ直してください。動物はたいてい戻ってきます。ゲームが上書き保存してしまうと、そのファイルは失われ、バックアップもありません。

安全に外す手順

その1：アドオンはすべて有効なままにします。そのセーブで使ったことのある犬種アドオンが全部、そのセーブのmod一覧（「ロード」 > そのセーブ > 「MODの選択...」）でチェックされているか確認してください。アドオンを1つ切るだけで、上に書いた問題が起きます。

その2：犬を手放します。安全なやり方は2つです。

  • 殺す。死体は別の形式で保存され、modがなくてもゲームが読めます。
  • インベントリに入れて持つ。ゲームはこのアイテムを飛ばせるので、消えるのは犬だけで残りは無事です。

犬を野生に戻したり遠くへ連れて行ったりしても解決しません。犬の記録はセーブに残りますし、別の場所へ移すのは、どの地域が壊れるかを変えるだけです。

その3：ゲームをセーブします。掃除を書き込むのはセーブです。

その4：modを外します。

まるごと掃除する（管理者／デバッグモード）

ここまでの手順はあなたの犬をカバーしますが、modはマップに野良犬も撒いていて、それを全部手で見つけることはできません。セーブ全体を一度に掃除するコマンドがあります。

  1. 管理者としてログインする（マルチプレイ）か、ゲームをデバッグモードで起動します（ソロ：Steamの起動オプションに-debugを足します）。
  2. 地面を右クリック → コンパニオンドッグ（デバッグ） → Tools → Delete ALL dogs (whole save)。
  3. sweep doneのメッセージを待ってからゲームをセーブします。

このコマンドは読み込み済みの犬をその場で消し、残りのセーブは裏で掃除するので、プレイが止まることはありません。犬種の名前を挙げて拒否された場合は、そのアドオンをこのセーブで有効にしてからやり直してください。定義がないまま掃除すると、その地域の動物が消えます。

25. サーバーの詳細調整（管理者）

この節は、人も犬も多いサーバーを運営する人向けです。パネルの名前は「Server tuning / performance」で、上段がmodのサーバー負荷の生の計測、下段がその負荷を変える項目です。ゲームのルール（ダメージ、空腹、経験値、犬の上限）はここにはなく、22節のサンドボックスのオプションのままです。

パネルはゲームの言語に関係なく英語のままです。ラベルがコードに直書きだからです。以下の表では、画面に出るとおりの名前で書いています。

パネルの開き方

地面を右クリック → コンパニオンドッグ（デバッグ） → Tools → 「Server tuning / performance」。マルチプレイでは管理者である必要があり、ソロではデバッグモード（Steamの起動オプションに-debug）でゲームを起動します。

すべての項目に共通すること

  • 値はその場で、サーバー全体に効き、セーブにも保存されます。
  • 範囲の外の値は範囲内に丸められます。
  • 緑色のラベルは、標準と違う値が入っている項目です。
  • 変更はすべて[CD-TUNE]の印と、変えた人の名前つきでログに出ます。起動時にはサーバーが有効な一覧を出力し、管理者が変えたものには*が付きます。
  • 「Restore defaults」はすべてを標準に戻します。計測とクライアント権限も含みます。

いじる前に計測を読む

「Measurement: off (click to start)」をクリックして、最初の集計が出るまで最大20秒待ちます。主役はこの行です。

companionTick: 12.40 ms/s load   0.062 ms/tick   200.0 ticks/s   (4000 ticks in 20s)

大事なのはms/s loadの数字で、1秒あたり何ミリ秒をmodがサーバーから使っているかを表します。調整のあとに下がってほしいのはこれです。その下には読み込み済みの犬の数、mod内の領域ごとの負荷のバー（時間は重複しないので足し算になり、一番長いバーが手を入れる場所です）、そして 1秒あたりのイベント数を並べたcounters:の行が続きます。2つのカウンターはそれだけで多くを語ります。spawn.qfullがゼロより上なら出現待ちの列があふれていますし、netauth.grantと netauth.revokeが同時に高ければ、犬の制御がサーバーとクライアントの間を行き来しています。オレンジのCOARSE CLOCKが出たら、マシンの時計の分解能が足りていません。カウンターだけを読み、時間の数字は無視してください。

「Client authority」のスイッチが、この節で一番効く調整です。オン（標準）なら飼い主のマシンが犬を動かして位置を報告し、サーバーが確認してから中継します。歩きも走りもなめらかになるのはこれのおかげです。オフにすると犬はすべてサーバーに戻り、クライアントは位置の送信をやめます。犬の多いサーバーではこれがmod最多のコマンドです。その代わり動きは全員にとってかくかくになり、犬はすべてサーバーの経路探索の列に戻ります。この列は全体で1本で、プレイヤーと共用です。
